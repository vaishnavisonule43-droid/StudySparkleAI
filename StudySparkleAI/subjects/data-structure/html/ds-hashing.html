🔐 Hashing

Learn the basic concepts of Hashing in Data Structure.

What is Hashing?

Hashing is a technique used to store and search data quickly. It uses a special function called a hash function to convert a key into an index of a hash table.

Definition: Hashing is a data structure technique that maps a key to a specific location in a hash table using a hash function.

Hash Table

A hash table is a data structure that stores data in the form of key-value pairs. The position of data is decided using a hash function.

Hash Function

A hash function takes a key as input and produces an index where the data should be stored in the hash table.

Example:

If the hash table size is 10 and the key is 25:

Hash Function = Key % Table Size

25 % 10 = 5

Therefore, key 25 will be stored at index 5.

Collision

A collision occurs when two different keys produce the same index in a hash table.

Example:

Suppose the hash table size is 10.

25 % 10 = 5

35 % 10 = 5

Both keys get the same index 5, so a collision occurs.

Collision Resolution Techniques

Collision resolution techniques are used to handle collisions in a hash table.

  • Separate Chaining
  • Linear Probing
  • Quadratic Probing
  • Double Hashing

Applications of Hashing

  • Database indexing
  • Password storage
  • Searching data quickly
  • Compiler symbol tables
  • Caching
  • Data retrieval

Advantages of Hashing

  • Fast searching
  • Fast insertion
  • Fast deletion
  • Efficient data storage

Disadvantages of Hashing

  • Collisions can occur
  • Good hash function is required
  • Hash tables may require extra memory
