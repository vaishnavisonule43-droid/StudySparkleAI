🔗 Linked List

Learn the basic concepts of Linked List in Data Structure.

1. What is a Linked List?

A Linked List is a linear data structure in which elements are stored in separate nodes. Each node contains data and a link to another node.

Unlike an array, linked list elements are not required to be stored in continuous memory locations.

2. Definition

Linked List: A linked list is a collection of nodes where each node contains data and a pointer that stores the address of another node.

3. What is a Node?

A node is the basic building block of a linked list. It contains two main parts:

  • Data: Stores the actual value.
  • Link / Pointer: Stores the address of the next node.
[ Data | Next ] → [ Data | Next ] → NULL

4. Why do we use Linked Lists?

  • Dynamic size.
  • Easy insertion and deletion.
  • Memory is allocated when required.
  • Does not require continuous memory locations.
  • Useful for implementing stacks and queues.

5. Array vs Linked List

Array Linked List
Fixed size Dynamic size
Continuous memory Non-continuous memory
Insertion can be difficult Insertion is easier
Deletion can be difficult Deletion is easier

6. Types of Linked List

🔹 1. Singly Linked List

In a singly linked list, each node contains data and a pointer to the next node.

[10 | •] → [20 | •] → [30 | NULL]

The last node points to NULL.

🔹 2. Doubly Linked List

In a doubly linked list, each node contains three parts: previous pointer, data and next pointer.

NULL ← [10] ⇄ [20] ⇄ [30] → NULL

It allows movement in both forward and backward directions.

🔹 3. Circular Linked List

In a circular linked list, the last node points back to the first node. Therefore, the list forms a circle and does not end with NULL.

🔸 3.1 Circular Singly Linked List

A Circular Singly Linked List is a type of linked list in which each node contains data and a next pointer. The last node points back to the first node.

[10] → [20] → [30] ↑ ↓ └──────────────┘
  • Each node contains Data and Next.
  • The last node points to the first node.
  • There is no NULL at the end.
  • Traversal can continue in a circular manner.

🔸 3.2 Circular Doubly Linked List

A Circular Doubly Linked List is a type of linked list in which each node contains Previous, Data and Next. The last node is connected to the first node and the first node is connected back to the last node.

[10] ⇄ [20] ⇄ [30] ↑ ↓ └──────────────┘
  • Each node contains Previous, Data and Next.
  • Last node's Next points to the first node.
  • First node's Previous points to the last node.
  • Traversal is possible in both directions.

7. Basic Operations on Linked List

  • Traversal
  • Insertion
  • Deletion
  • Searching
  • Updating

🔄 Traversal

Visiting every node of a linked list one by one is called traversal.

Start → 10 → 20 → 30 → NULL

➕ Insertion

Adding a new node to a linked list is called insertion.

A node can be inserted at the beginning, at the end, or at a specific position.

❌ Deletion

Removing a node from a linked list is called deletion.

A node can be deleted from the beginning, end, or a specific position.

🔍 Searching

Searching means finding a particular value or node in the linked list.

✏️ Updating

Updating means changing the data stored in an existing node.

8. Advantages of Linked List

  • Dynamic size.
  • Easy insertion and deletion.
  • Memory is allocated as required.
  • Does not require continuous memory.
  • Useful for implementing other data structures.

9. Disadvantages of Linked List

  • Extra memory is required for pointers.
  • Direct access using index is not possible.
  • Searching can take more time.
  • Implementation is more complex than arrays.

10. Real-Life Examples

  • Music playlist
  • Browser history
  • Undo and redo operations
  • Image slideshow
  • Navigation systems

11. Node Structure in C

struct Node
{
    int data;
    struct Node *next;
};

Here, data stores the value and next stores the address of the next node.

12. Linked List Memory Representation

Nodes of a linked list can be stored at different memory locations. The pointer connects one node to another.

Head ↓ [10 | •] → [20 | •] → [30 | NULL]
