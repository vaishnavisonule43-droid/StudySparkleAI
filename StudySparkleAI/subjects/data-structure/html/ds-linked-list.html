Introduction to Linked List

Definition

A linked list is a linear data structure made of separate elements called nodes. Each node stores data and one or more links (pointers) that connect it to another node. Nodes do not need to be stored next to each other in memory.

💡

In simple words: Think of a linked list as a chain. Each link contains some information and a direction to the next link.

▦

Why do we use it?

It can grow or shrink while a program runs. Inserting or removing a node can be efficient because nodes do not have to be shifted like array elements.

⌁

Important property

A linked list is accessed by following links from the first node, called head. It normally does not provide direct index access like an array.

BUILDING BLOCK

Node Structure

A node in a singly linked list contains two parts:

PART 1DataStores the value
PART 2Next pointerStores the address of the next node

C structure

struct node {
    int data;
    struct node *next;
};
  • data: stores the value of the node.
  • next: stores the address of the next node.
  • head: pointer that stores the address of the first node.
  • NULL: indicates that a pointer does not point to a valid node.

FOUR MAIN TYPES

Types of Linked List

Select a type to see how its links work. The animated diagram highlights the direction in which nodes can be visited.

TYPE 01

Singly Linked List

Each node points to the next node. The last node points to NULL.

1. Singly Linked List

Each node contains data and one next pointer. Traversal is possible only in the forward direction.

2. Doubly Linked List

Each node contains prev, data and next. It supports forward and backward traversal but needs extra memory.

3. Circular Singly Linked List

The last node points back to the first node instead of NULL. Traversal can continue in a loop.

4. Circular Doubly Linked List

Each node has previous and next links. The last node connects to the first, and the first connects back to the last.

CORE CONCEPTS

Basic Operations

01

Traversal

Visit each node one by one from the head until the end (NULL in a normal singly list).

temp = head;
02

Insertion

Add a new node at the beginning, end, or a particular position by adjusting links.

newnode->next = head;
03

Deletion

Remove a node and connect the previous node to the node after it. Free removed memory in C.

free(temp);
04

Searching

Compare each node's data with the required value until found or the list ends.

temp->data == key
05

Updating

Find a node and replace its stored data with a new value.

temp->data = value;
06

Counting

Traverse the list and increase a counter for every node visited.

count++;

EXAM PREPARATION

Basic Algorithms

Algorithm: Traversal in a Singly Linked List

  1. Start.
  2. Set temp = head.
  3. While temp != NULL, display temp->data.
  4. Move to the next node using temp = temp->next.
  5. Stop when temp == NULL.

Insert at beginning

newnode->next = head;
head = newnode;

The new node points to the old first node, then head is moved to the new node.

Delete from beginning

temp = head;
head = head->next;
free(temp);

Save the old head, move head forward, and release the old node's memory.

Insert after a node

newnode->next = temp->next;
temp->next = newnode;

Set the new node's next link first, then connect the previous node to it.

Search a value

temp = head;
while (temp != NULL) {
    if (temp->data == key) break;
    temp = temp->next;
}

The loop stops when the value is found or the end is reached.

Time Complexity

OperationTypical timeReason
Access by positionO(n)Walk through nodes from the head
SearchO(n)May inspect every node
Insert at headO(1)Change a small number of pointers
Delete at headO(1)Move head to the next node
Insert at endO(n)Usually find the last node first; O(1) with a tail pointer
Delete at end (singly)O(n)Find the node before the last node

Here, n is the number of nodes. Complexity can vary depending on whether a tail pointer or a direct node reference is available.

C PROGRAMMING

Simple C Program: Display a Linked List

This beginner-friendly program creates three nodes and displays their data. It uses dynamic memory allocation with malloc().

#include <stdio.h>
#include <stdlib.h>

struct node {
    int data;
    struct node *next;
};

int main(void) {
    struct node *head, *second, *third, *temp;

    head = malloc(sizeof(struct node));
    second = malloc(sizeof(struct node));
    third = malloc(sizeof(struct node));

    if (head == NULL || second == NULL || third == NULL) {
        printf("Memory allocation failed");
        free(head);
        free(second);
        free(third);
        return 1;
    }

    head->data = 10;
    head->next = second;

    second->data = 20;
    second->next = third;

    third->data = 30;
    third->next = NULL;

    temp = head;
    while (temp != NULL) {
        printf("%d -> ", temp->data);
        temp = temp->next;
    }
    printf("NULL\n");

    free(third);
    free(second);
    free(head);
    return 0;
}

EVALUATION

Advantages and Disadvantages

✓ Advantages

  • Size can grow or shrink dynamically.
  • Insertion and deletion can be efficient when the correct node is already known.
  • Does not require one continuous block of memory.
  • Useful for implementing stacks, queues, graphs and other structures.

! Disadvantages

  • No direct index access; nodes must be traversed.
  • Extra memory is needed for pointer fields.
  • Pointer handling makes code more complex.
  • Incorrect pointer changes can cause memory errors or lost nodes.

Applications

Stacks and queuesGraph adjacency listsHash-table chainingPlaylistsUndo / redo systemsMemory management

PRACTISE

Important Exam Questions

1. Define a linked list. Explain its node structure.

A linked list is a linear data structure consisting of nodes connected through pointers. A singly linked-list node contains data and a pointer to the next node.

2. Explain the different types of linked lists.

The main types are singly, doubly, circular singly and circular doubly linked lists. They differ in the number and direction of links and whether the end connects back to the beginning.

3. Write the advantages and disadvantages of a linked list.

Advantages include dynamic size and efficient pointer-based insertion/deletion. Disadvantages include extra pointer memory, sequential access and more complex pointer management.

4. Explain insertion and deletion in a singly linked list.

Insertion creates a node and adjusts links so it becomes part of the list. Deletion changes links to bypass the target node and releases its memory when dynamically allocated.

5. Compare arrays and linked lists.

Arrays provide direct index access and commonly use contiguous memory. Linked lists use connected nodes, support dynamic growth, and require traversal to reach a position.

6. Explain traversal and searching with an algorithm.

Start from head, process each node, and move using the next pointer. Searching compares each node's data with the required key until a match or NULL is reached.
