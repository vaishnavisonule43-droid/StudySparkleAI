Stack

Learn Stack with easy notes, examples, operations and an interactive animation.

1. Definition of Stack

A stack is a linear data structure in which insertion and deletion are performed from only one end called the TOP.

Stack follows the LIFO principle, which means Last In, First Out. The element inserted last is removed first.

2. Real-Life Example

A pile of plates is an example of a stack. The plate placed last on the top is removed first.

3. LIFO Principle

LIFO stands for Last In, First Out. The last inserted element is the first element to be deleted.

Example:

Push 10 → Push 20 → Push 30

Pop removes 30 first.

4. Basic Operations of Stack

Push

Adds a new element to the top of the stack.

Pop

Removes the top element from the stack.

Peek / Top

Displays the top element without removing it.

isEmpty

Checks whether the stack has no elements.

isFull

Checks whether an array-based stack is full.

5. Stack Overflow

Stack overflow occurs when we try to insert an element into a fixed-size stack that is already full.

6. Stack Underflow

Stack underflow occurs when we try to remove an element from an empty stack.

7. Types of Stack

  • Static Stack: Uses a fixed-size array.
  • Dynamic Stack: Can grow or shrink as elements are added or removed, depending on its implementation.

8. Applications of Stack

  • Function calls and recursion.
  • Undo and redo operations.
  • Expression evaluation.
  • Checking balanced parentheses.
  • Backtracking and browser history.

9. Advantages of Stack

  • Simple to implement.
  • Push and pop are efficient operations.
  • Useful in function calls and expression evaluation.
  • Helps manage data in LIFO order.

10. Disadvantages of Stack

  • Only the top element can be accessed directly.
  • Fixed-size stacks can overflow.
  • Removing an element from an empty stack causes underflow.

11. Time Complexity

12. Example of Stack Operations

  1. Push 10: Stack contains 10.
  2. Push 20: Stack contains 10, 20.
  3. Push 30: Stack contains 10, 20, 30.
  4. Pop: 30 is removed.
  5. Peek: 20 is the top element.

13. Conclusion

Stack is a linear data structure that follows LIFO. It is useful when data must be processed in reverse order.
