01 · Fundamentals

What is a Stack?

A Stack is a linear data structure in which insertion and deletion take place at the same end, called the TOP.

Definition: A Stack is a linear data structure that follows the LIFO (Last In, First Out) principle.

Imagine a pile of plates. You place a new plate on the top, and you normally remove the top plate first. A stack works in the same way.

Core Principle

Remember LIFO

Push 10→ Push 20→ Push 30
Pop order: 30 → 20 → 10

The last inserted element is the first element removed.

04 · Internal Working

How Stack Operations Work

Push Algorithm

  1. Check whether the stack is full.
  2. If full, report Stack Overflow.
  3. Otherwise, increase TOP by one.
  4. Insert the new element at STACK[TOP].

Pop Algorithm

  1. Check whether the stack is empty.
  2. If empty, report Stack Underflow.
  3. Otherwise, read the element at STACK[TOP].
  4. Decrease TOP by one.

Peek Algorithm

  1. Check whether the stack is empty.
  2. If empty, report that no top element exists.
  3. Otherwise, return STACK[TOP] without changing TOP.
Important: Push changes the stack size by +1, Pop changes it by -1, and Peek does not change the stack.
05 · Implementation

Types of Stack Implementation

1. Array-Based Stack

Elements are stored in a continuous array. A TOP variable tracks the last inserted element.

  • Simple to implement.
  • Fast access to the top element.
  • Fixed arrays have limited capacity.

2. Linked-List-Based Stack

Each node stores data and a pointer to the next node. TOP points to the first node.

  • Can grow dynamically as memory permits.
  • Does not require a fixed array capacity.
  • Each node requires extra pointer memory.
Feature Array Stack Linked List Stack
Memory allocation Array storage Node-by-node allocation
Capacity Fixed for a fixed array Limited by available memory
Extra memory Usually low overhead Pointer needed per node
Push / Pop O(1) O(1) at the head
06 · Errors and Edge Cases

Stack Overflow and Underflow

Stack Overflow

Overflow occurs when we try to push an element into a full fixed-capacity stack.

Example: Capacity is 3 and the stack already contains 10, 20, 30. Pushing 40 causes overflow.

Stack Underflow

Underflow occurs when we try to pop an element from an empty stack.

Example: The stack is empty and Pop is performed.

Note: A dynamically allocated stack may not have a predetermined fixed capacity, but an allocation can still fail when memory is exhausted.

07 · Performance

Stack Time Complexity

Operation Time Complexity Reason
Push O(1) amortized Add at the top; a resizing array may occasionally copy elements.
Pop O(1) Remove the top element.
Peek O(1) Read the top element.
isEmpty O(1) Check the size or TOP index.
Search O(n) May need to inspect every element.

For a fixed-size array stack, Push is O(1) in the usual implementation. For a dynamically resizing array, Push is O(1) amortized and O(n) for a resizing operation.

08 · Expression Processing

Infix, Prefix and Postfix Expressions

Stacks are widely used to convert and evaluate mathematical expressions.

Notation Example Meaning
Infix A + B Operator is between operands.
Prefix + A B Operator comes before operands.
Postfix A B + Operator comes after operands.
Example: Infix: (2 + 3) × 4
Postfix: 2 3 + 4 *
Evaluation: 2 + 3 = 5, then 5 × 4 = 20.

      10 · Function Calls

      Call Stack and Recursion

      When a function calls another function, the program stores information about the active function calls in a call stack. This information can include return addresses, parameters, and local execution state.

      main()→functionA()→functionB()

      When functionB finishes, its call frame is removed first. Execution returns to functionA, then eventually to main().

      Recursion Example in C

      C · Factorial Using Recursion 
      #include <stdio.h>

int factorial(int n)
{
    if (n <= 1)
        return 1;

    return n * factorial(n - 1);
}

int main()
{
    printf("%d", factorial(4));
    return 0;
}
      Call flow: factorial(4) → factorial(3) → factorial(2) → factorial(1)
      Return flow: 1 → 2 → 6 → 24
      Stack Overflow in recursion: Very deep or infinite recursion can exhaust the program's call stack.

      12 · Advantages and Limitations

      Advantages of Stack

      • Push and Pop are generally fast.
      • Simple to understand and implement.
      • Useful for recursion and expression processing.
      • Helps manage reversible actions and backtracking.

      Disadvantages of Stack

      • Only the top element is directly accessible in a standard stack.
      • Searching for an arbitrary element can take O(n) time.
      • A fixed-size stack can overflow.
      • Deep recursion may exhaust the call stack.
