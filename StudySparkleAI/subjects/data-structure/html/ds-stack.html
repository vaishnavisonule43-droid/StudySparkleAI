Learn the basic concepts of Stack in Data Structure.

What is Stack?

A Stack is a linear data structure in which elements are inserted and removed from the same end.

Definition: Stack follows the LIFO principle, which means Last In, First Out.

Example

A real-life example of a stack is a stack of plates. The plate placed last on the top is removed first.

LIFO Principle

LIFO stands for Last In, First Out. The element inserted last is removed first.

Example:

If we push: 10 → 20 → 30

Then the first element removed will be: 30

Stack Operations

1. Push

Push is used to add an element to the top of the stack.

2. Pop

Pop is used to remove the top element from the stack.

3. Peek

Peek is used to view the top element without removing it.

4. IsEmpty

IsEmpty checks whether the stack contains any element or not.

Applications of Stack

  • Function Calls
  • Undo and Redo Operations
  • Expression Evaluation
  • Parentheses Matching
  • Browser Back Button
  • Recursion

Advantages of Stack

  • Easy to implement.
  • Insertion and deletion are fast.
  • Follows the LIFO principle.
  • Useful in recursion and function calls.

Disadvantages of Stack

  • Only the top element can be accessed directly.
  • Random access is not possible.
  • Stack overflow can occur when the stack is full.
