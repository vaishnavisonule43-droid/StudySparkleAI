01 • BASICS

1. Introduction to Data Structure

What is Data?

Definition: Data means raw facts and figures that can be processed to obtain useful information.

Data can include numbers, names, marks, addresses and other values. For example, student marks are data. When we calculate their total and percentage, we get useful information.

What is a Data Structure?

Definition: A data structure is a way of organizing and storing data in a computer so that it can be accessed and processed efficiently.

In programming, we work with different types of data. If the data is not organized properly, it can become difficult to search, update or manage it. Data structures help us organize data systematically.

Simple Example

Suppose we want to store the marks of five students. We can use an array to store all the marks under one variable name. 

int marks[5] = {70, 80, 65, 90, 75};

Here, the array stores five integer values. We can access each mark using its index.

Real-Life Examples

  • Array: Storing student marks.
  • Stack: Managing undo operations.
  • Queue: Managing people waiting in a line.
  • Linked List: Connecting a sequence of records.
  • Tree: Organizing files and folders.
  • Graph: Representing connections between cities.
02 • IMPORTANCE

2. Need of Data Structure

Data structures are needed to organize large amounts of data and perform operations efficiently.

Why Do We Need Data Structures?

  1. Organize Data: They help us store data in a proper format.
  2. Easy Searching: They help us find required data.
  3. Fast Processing: They can make operations faster.
  4. Easy Updating: They help us add, remove or change data.
  5. Memory Management: They help us use computer memory effectively.
  6. Handle Large Data: They help manage large collections of information.
Remember: Data structures make data easier to store, access, search and process.
03 • CLASSIFICATION

3. Classification of Data Structure

Data structures can be classified into two main categories: primitive and non-primitive data structures.

Data Structure

Primitive

Integer, Character, Float, Boolean

Non-Primitive

Array, Linked List, Stack, Queue, Tree, Graph

3.1 Primitive Data Structure

Definition: Primitive data types are the basic data types provided by a programming language.

Examples of primitive types in C include:

Data Type Purpose Example
int Stores integer values int age = 18;
char Stores a character char grade = 'A';
float Stores decimal values float price = 12.5f;
double Stores floating-point values with greater precision double value = 12.567;

3.2 Non-Primitive Data Structure

Definition: Non-primitive data structures organize collections of data or relationships between data elements.

Examples include:

  • Array: Stores elements of the same declared type.
  • Linked List: Connects elements using links.
  • Stack: Follows the LIFO principle.
  • Queue: Usually follows the FIFO principle.
  • Tree: Organizes data hierarchically.
  • Graph: Represents connections between elements.

05 • MEMORY

5. Static and Dynamic Data Structures

5.1 Static Data Structure

Definition: A static data structure has a size that is fixed for its lifetime after it is created.

In C, a normal fixed-size array is an example. Its declared capacity does not automatically increase when more elements are needed. 

int marks[5];

This array has capacity for five integers.

5.2 Dynamic Data Structure

Definition: A dynamic data structure can change its size during program execution, depending on how it is designed and used.

Linked lists are common examples. Nodes can be created or removed as required. Dynamic memory allocation in C can be performed using functions such as malloc() and free().

Difference Between Static and Dynamic

Static Dynamic
Size or capacity is fixed. Size can change during execution.
Capacity is decided in advance. Memory can be allocated as needed.
Example: Fixed-size array. Example: Linked list.
06 • BASIC OPERATIONS

6. Basic Operations on Data Structures

The following are common operations performed on data structures.

6.1 Traversal

Definition: Traversal means visiting each element of a data structure one by one.

6.2 Insertion

Definition: Insertion means adding a new element to a data structure.

6.3 Deletion

Definition: Deletion means removing an element from a data structure.

6.4 Searching

Definition: Searching means finding a required element in a data structure.

6.5 Sorting

Definition: Sorting means arranging data in a particular order, such as ascending or descending order.

6.6 Updating

Definition: Updating means changing an existing value in a data structure.

6.7 Merging

Definition: Merging means combining two similar collections of data into one.
Operation Meaning
Traversal Visit elements one by one.
Insertion Add an element.
Deletion Remove an element.
Searching Find an element.
Sorting Arrange elements in order.
Updating Change an element's value.
Merging Combine collections.
07 • PRACTICAL USES

7. Applications of Data Structure

1. Database Management

Data structures help organize, retrieve and manage information.

2. Operating Systems

They are used in process scheduling, memory management and other operating system tasks.

3. Computer Networks

Graphs can represent connections between computers and network devices.

4. Artificial Intelligence

Trees, graphs, queues and other structures are used in many search and problem-solving algorithms.

5. Web Browsers

Stacks can help implement features such as back and forward navigation.

6. Banking Systems

Data structures can help organize customer and transaction records.

7. Searching and Sorting

Data structures help algorithms organize data and find required information.

08 • BENEFITS

8. Advantages of Data Structure

  • Better Organization: Data can be stored in a systematic way.
  • Efficient Searching: Suitable structures can help find data faster.
  • Easy Modification: Data can be inserted, deleted or updated.
  • Better Memory Use: Appropriate structures can use memory effectively.
  • Code Reusability: Common data structures can be reused in different programs.
  • Better Performance: Choosing the right structure can improve program efficiency.

Limitations

  • Some data structures are difficult to implement.
  • Different structures may require extra memory.
  • Choosing an unsuitable structure can reduce efficiency.
  • Some operations require more time than others.
