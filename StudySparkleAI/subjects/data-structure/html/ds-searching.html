🔍 Searching

Learn the basic concepts of Searching in Data Structure.

What is Searching?

Searching is the process of finding a particular element from a collection of data.

Definition: Searching is an operation used to find the location of a specific element in a data structure.

Example

Suppose an array contains:

10, 20, 30, 40, 50

If we want to find 30, the searching operation checks the elements until 30 is found.

Types of Searching

1. Linear Search

Linear Search checks each element one by one from the beginning until the required element is found.

Example: Searching 30 in 10, 20, 30, 40, 50

10 → 20 → 30 Found

2. Binary Search

Binary Search works on a sorted array. It repeatedly divides the search area into two halves.

Example: Searching 40 in 10, 20, 30, 40, 50

The middle element is checked first and the search continues in the required half.

Linear Search

Linear Search compares the target element with every element one by one.

Steps

  1. Start from the first element.
  2. Compare the element with the target.
  3. If the element matches, searching is completed.
  4. If it does not match, move to the next element.
  5. Repeat until the element is found or the array ends.

Binary Search

Binary Search is a faster searching technique that works only on sorted data.

Steps

  1. Find the middle element.
  2. Compare the middle element with the target.
  3. If it matches, the element is found.
  4. If the target is smaller, search the left half.
  5. If the target is larger, search the right half.
  6. Repeat until the element is found.

Linear Search vs Binary Search

Feature Linear Search Binary Search
Data Sorted or Unsorted Must be Sorted
Method Checks one by one Divides into halves
Speed Slower Faster
Time Complexity O(n) O(log n)

Applications of Searching

  • Searching a contact in a phone.
  • Finding a record in a database.
  • Searching a file in a computer.
  • Finding products in an online store.
  • Searching information in large data sets.

Advantages of Searching

  • Helps to find required data quickly.
  • Useful for managing large amounts of data.
  • Different searching methods can be used according to the data.
