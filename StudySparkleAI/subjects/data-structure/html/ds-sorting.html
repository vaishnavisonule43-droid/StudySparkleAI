🔢 Sorting

Learn the basic concepts of Sorting in Data Structure.

What is Sorting?

Sorting is the process of arranging data in a particular order, such as ascending or descending order.

Definition: Sorting is a technique used to arrange elements in a specific order to make data easier to read, search and manage.

Example

Unsorted: 40, 10, 30, 20, 50

Ascending: 10, 20, 30, 40, 50

Descending: 50, 40, 30, 20, 10

Types of Sorting

1. Bubble Sort

Bubble Sort repeatedly compares adjacent elements and swaps them if they are in the wrong order.

2. Selection Sort

Selection Sort finds the smallest element and places it at the correct position.

3. Insertion Sort

Insertion Sort builds the sorted array one element at a time.

4. Merge Sort

Merge Sort divides the array into smaller parts, sorts them and then merges them together.

5. Quick Sort

Quick Sort selects a pivot element and divides the array around the pivot.

Bubble Sort

Bubble Sort compares adjacent elements. If the first element is greater than the second element, they are swapped.

Steps

  1. Compare two adjacent elements.
  2. Swap them if they are in the wrong order.
  3. Continue comparing the remaining elements.
  4. Repeat the process until the array is sorted.
Example:

30, 10, 20

Compare 30 and 10 → Swap
10, 30, 20

Compare 30 and 20 → Swap
10, 20, 30

Applications of Sorting

  • Arranging student marks.
  • Arranging products by price.
  • Organizing names alphabetically.
  • Searching data efficiently.
  • Arranging records in databases.

Advantages of Sorting

  • Makes data easier to understand.
  • Helps in faster searching.
  • Makes data organization easier.
  • Useful for processing large amounts of data.
