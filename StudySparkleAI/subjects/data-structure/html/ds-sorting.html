What is Sorting?

Sorting is the process of arranging data elements in a particular order, usually ascending (smallest to largest) or descending (largest to smallest).

✦
Exam definition

Sorting is a technique used to arrange data elements in a specific order so that data becomes easier to read, search and process.

Example: arranging numbers

UNSORTED
4010302050
↓
ASCENDING ORDER
1020304050
DESCENDING ORDER
5040302010
Remember: Ascending = increasing order. Descending = decreasing order.

Types of Sorting Algorithms

Choose a card to jump to the explanation.

🫧

Bubble Sort

Compares adjacent elements and swaps them if needed.

Average: O(n²) 🎯

Selection Sort

Selects the smallest remaining element for the next position.

Average: O(n²) 🃏

Insertion Sort

Inserts each next element into the sorted part.

Average: O(n²) 🧩

Merge Sort

Divides the array, sorts parts and merges them.

Average: O(n log n) ⚡

Quick Sort

Uses a pivot to partition smaller and larger values.

Average: O(n log n)

Bubble Sort

Bubble Sort repeatedly compares two adjacent elements. If they are in the wrong order, it swaps them. After each pass, the largest unsorted element moves to the end.

🫧
Simple definition

Bubble Sort compares adjacent elements and swaps them when they are in the wrong order.

Example: sort 30, 10, 20

1. Compare 30 and 10

30 is greater than 10, so swap them.

103020
2. Compare 30 and 20

30 is greater than 20, so swap them.

102030
3. Result

The array is now sorted.

102030

Algorithm steps

  1. Start from the first element.
  2. Compare adjacent elements.
  3. Swap them if the left element is greater.
  4. Continue through the unsorted part.
  5. Repeat until sorted; an optimized version stops if no swaps occur.
Best case*O(n)AverageO(n²)WorstO(n²)Stable?Yes
*Best case O(n) when early stopping is used.

Selection Sort

Selection Sort searches the unsorted part for the smallest element, then swaps it with the first element of that part. It repeats until every position is filled.

🎯
Simple definition

Selection Sort repeatedly selects the smallest element from the unsorted part and places it in its correct position.

Example: 29, 10, 14, 37

1. Find the smallest value

The smallest is 10. Swap it with 29.

10291437
2. Search the remaining part

In 29, 14, 37, the smallest is 14. Place it next.

10142937
3. Final result
10142937

Algorithm steps

  1. Assume the first unsorted element is the minimum.
  2. Compare it with all other elements in the unsorted part.
  3. Remember the index of the smallest element.
  4. Swap the minimum with the first unsorted element.
  5. Move the sorted boundary right and repeat.
Best caseO(n²)AverageO(n²)WorstO(n²)Stable?No*
*The usual swap-based implementation is not stable.

Insertion Sort

Insertion Sort keeps a sorted section at the beginning. It takes the next element (the key), shifts larger elements one position right and inserts the key into its correct place.

🃏
Simple definition

Insertion Sort builds a sorted array one element at a time by inserting each element into its correct position.

Example: 30, 10, 20

1. Take key 10

30 is greater than 10, so shift 30 right and insert 10.

103020
2. Take key 20

Shift 30 right and insert 20 after 10.

102030
3. Result
102030

Algorithm steps

  1. Assume the first element is sorted.
  2. Select the next element as the key.
  3. Shift sorted elements greater than the key one position right.
  4. Insert the key into the empty position.
  5. Repeat until all elements are processed.
Best caseO(n)AverageO(n²)WorstO(n²)Stable?Yes

Merge Sort

Merge Sort follows the divide and conquer technique. It divides the array into halves until each part has one element, then merges the parts in sorted order.

🧩
Simple definition

Merge Sort divides an array into smaller parts, sorts those parts and merges them to create a sorted array.

Example: 38, 27, 43, 10

38274310
↓ Divide
38, 2743, 10
↓ Divide again
38274310
↓ Sort and merge
27, 3810, 43
↓ Final merge
10, 27, 38, 43

Algorithm steps

  1. Divide the array into two halves.
  2. Keep dividing until each sub-array has one element.
  3. Compare the first available elements of the sub-arrays.
  4. Merge them in sorted order.
  5. Continue merging until one sorted array remains.
Best caseO(n log n)AverageO(n log n)WorstO(n log n)Stable?Yes
Key point: Merge Sort has predictable performance but usually needs extra memory for merging arrays.

Quick Sort

Quick Sort also uses divide and conquer. It chooses a pivot, places smaller values on one side and larger values on the other, then sorts the two parts.

⚡
Simple definition

Quick Sort sorts data by selecting a pivot and partitioning elements into groups smaller and larger than the pivot.

Example: 30, 10, 40, 20 (pivot = 20)

SMALLER THAN PIVOT
10
PIVOT20
GREATER THAN PIVOT
3040

After sorting the left and right groups, the result is 10, 20, 30, 40.

Algorithm steps

  1. Choose a pivot element.
  2. Partition the array into smaller and larger values around the pivot.
  3. The pivot reaches its correct position.
  4. Apply Quick Sort to the left and right partitions.
  5. Stop when a partition has zero or one element.
Best caseO(n log n)AverageO(n log n)WorstO(n²)Stable?No*
*Common in-place Quick Sort is not stable. Repeatedly poor pivot choices can cause worst-case performance.

Sorting Algorithms Comparison

Time complexity describes how the amount of work grows as the number of elements (n) increases.

Algorithm Best Average Worst Stable?
Bubble Sort O(n)* O(n²) O(n²) Yes

Insertion Sort O(n) O(n²) O(n²) Yes

*Bubble best case assumes early stopping. Stability reflects common introductory implementations.
Easy memory trick: Bubble = neighbours; Selection = smallest; Insertion = insert key; Merge = divide and merge; Quick = pivot and partition.

Applications of Sorting

🎓Student records

Arrange marks or roll numbers.

🛒Online shopping

Sort products by price or rating.

🔤Names and words

Arrange names alphabetically.

🗄️Databases

Organize records by date or ID.

Advantages of Sorting

  • Makes data organized and easier to understand.
  • Can make searching more efficient; binary search requires sorted data.
  • Helps identify minimum, maximum and duplicate values.
  • Supports clear reports and organized database output.

Short exam questions

1. What is sorting?

Sorting is the process of arranging data elements in a specific order, such as ascending or descending order.

2. Which sorting algorithm uses a pivot?

Quick Sort uses a pivot to partition the array.

3. Which algorithms use divide and conquer?

Merge Sort and Quick Sort both use divide and conquer.

4. Which algorithm works well for nearly sorted data?

Insertion Sort is often efficient for small or nearly sorted arrays.

5. What is Quick Sort's worst-case complexity?

O(n²), often when pivot choices repeatedly create unbalanced partitions.
