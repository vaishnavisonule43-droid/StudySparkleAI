⭐ Priority Queue

Learn the basic concepts of Priority Queue in Data Structure.

1. What is a Priority Queue?

A Priority Queue is a special type of queue in which each element is associated with a priority. The element with higher priority is served before the element with lower priority.

Definition: A Priority Queue is a data structure in which elements are removed according to their priority rather than only their insertion order.

2. How does Priority Queue Work?

In a normal queue, the first element inserted is removed first. But in a priority queue, the element with the highest priority is removed first.

Example:

Suppose three patients have the following priorities:

Patient A → Priority 2

Patient B → Priority 1

Patient C → Priority 3

If 1 represents the highest priority, Patient B will be served first.

3. Types of Priority Queue

There are mainly two types of Priority Queue:

  • Ascending Priority Queue
  • Descending Priority Queue

🔹 1. Ascending Priority Queue

In an ascending priority queue, the element with the smallest priority value is removed first.

Example: 1 → 2 → 3 → 4

🔹 2. Descending Priority Queue

In a descending priority queue, the element with the largest priority value is removed first.

Example: 4 → 3 → 2 → 1

4. Basic Operations

  • Insertion: Adding an element with a priority.
  • Deletion: Removing the element with the highest priority.
  • Peek: Viewing the element with the highest priority.
  • isEmpty: Checking whether the priority queue is empty.

5. Simple Example

Element Priority
A 3
B 1
C 2

If smaller number means higher priority, the elements will be processed in this order:

B → C → A

6. Implementation of Priority Queue

A Priority Queue can be implemented using different data structures.

  • Array
  • Linked List
  • Heap

7. Priority Queue using Heap

Heap is commonly used to implement a priority queue because it provides efficient insertion and deletion operations.

Example:

A Min Heap can be used when the smallest value has the highest priority.

A Max Heap can be used when the largest value has the highest priority.

8. Real-Life Examples

  • Hospital emergency management
  • CPU process scheduling
  • Printer job scheduling
  • Network packet management
  • Emergency services

9. Advantages of Priority Queue

  • Important tasks can be processed first.
  • Useful for scheduling systems.
  • Efficient when implemented using a heap.
  • Useful for solving many algorithmic problems.

10. Disadvantages of Priority Queue

  • Implementation can be more complex than a normal queue.
  • Maintaining priorities may require extra processing.
  • Searching for a specific element may not be efficient.

11. Applications of Priority Queue

  • CPU scheduling
  • Dijkstra's shortest path algorithm
  • Prim's algorithm
  • Huffman coding
  • Network traffic management
  • Event-driven simulation

12. Normal Queue vs Priority Queue

Normal Queue Priority Queue
Follows FIFO order. Follows priority order.
First inserted element is served first. Highest priority element is served first.
Priority is not considered. Priority is considered.
Simple to implement. Can be implemented using heap, array or linked list.
