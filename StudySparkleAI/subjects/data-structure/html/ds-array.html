Introduction to Array

What is an Array?

📘
Definition

An array is a linear data structure that stores multiple elements of the same data type in consecutive memory locations. Each element is accessed using an index.

Suppose we need to store five students' marks. Instead of creating five separate variables, we can keep all values under one array name. This makes the data easier to access and process using loops.

Without an array

int mark1 = 70;
int mark2 = 80;
int mark3 = 65;
int mark4 = 90;
int mark5 = 75;

Using an array

int marks[5] = {70, 80, 65, 90, 75};

All five marks are stored in the array named marks. In C, the first index is 0.

Index 070
Index 180
Index 265
Index 390
Index 475

Important characteristics

  • Stores multiple elements under one variable name.
  • In C, indexing starts at 0.
  • All elements use the same declared data type.
  • Elements are stored in consecutive memory locations.
  • Accessing a known index takes O(1) time.
  • A normal fixed-size array does not automatically grow.

Array declaration in C

data_type array_name[size];
int numbers[5];
Remember: Size tells how many elements the array can hold; an index tells the position of an element.

Types of Array

1. One-dimensional array

A one-dimensional array stores values in a single list. Each element is accessed with one index. 

int numbers[5] = {10, 20, 30, 40, 50};
printf("%d", numbers[2]);

Output:

30

Uses: Marks, prices, temperatures and lists.

2. Two-dimensional array

A two-dimensional array stores values in rows and columns, like a table or matrix. 

int matrix[2][3] = {{1, 2, 3}, {4, 5, 6}};
printf("%d", matrix[1][2]);

Output:

6

matrix[1][2] means row index 1 and column index 2. Both indexes start from zero.

Row / Column Column 0 Column 1 Column 2
Row 0 1 2 3
Row 1 4 5 6

3. Multidimensional array

An array with three or more dimensions is called a multidimensional array. 

int data[2][3][4];

It can hold 2 × 3 × 4 = 24 integers.

Type Structure Example
1D Single list a[5]
2D Rows and columns a[2][3]
Multidimensional Three or more dimensions a[2][3][4]

Array Index and Accessing Elements

An index is the position number used to identify an element. In C, the first index is 0, not 1. 

int a[5] = {10, 20, 30, 40, 50};
printf("%d", a[2]);
Index 0 1 2 3 4
Value 10 20 30 40 50
  • a[0] is 10.
  • a[1] is 20.
  • a[2] is 30.
  • a[4] is 50.

Address formula

Address of A[i] = Base Address + (i × Size of Each Element)

If base address = 1000, each integer occupies 4 bytes, and index = 3:

Step 1

Index = 3

Step 2

Element size = 4 bytes

Step 3

Address = 1000 + (3 × 4) = 1012

The 4-byte size is an example assumption; the actual size of int depends on the C implementation.

Important: For an array of size 5, valid indexes are 0 through 4. Accessing an out-of-range index in C causes undefined behavior.

4.1 Traversal

🔎
Definition

Traversal is the process of visiting each array element one by one to display or process its value.

  1. Start from index 0.
  2. Read or process the current element.
  3. Move to the next index.
  4. Repeat until all elements have been visited.
#include <stdio.h>
int main()
{
    int a[5] = {10, 20, 30, 40, 50};
    int i;
    for(i = 0; i < 5; i++)
        printf("%d ", a[i]);
    return 0;
}

Output:

10 20 30 40 50

The loop starts at i = 0. After printing each value, i increases. When i becomes 5, the condition i < 5 is false and the loop stops. Time complexity: O(n).

4.2 Insertion

➕
Definition

Insertion is the process of adding a new element at a specified position in an array.

When inserting in the middle, move existing elements one position right to create space. The example below inserts 25 at index 2.

Step 1

Start from the last occupied element.

10203040
Step 2

Shift 40 and 30 one position to the right.

1020304040
Step 3

Put 25 at index 2.

1020253040 
#include <stdio.h>
int main()
{
    int a[10] = {10, 20, 30, 40};
    int n = 4, pos = 2, value = 25, i;
    for(i = n; i > pos; i--)
        a[i] = a[i - 1];
    a[pos] = value;
    n++;
    for(i = 0; i < n; i++)
        printf("%d ", a[i]);
    return 0;
}

Output:

10 20 25 30 40

The loop shifts elements from right to left, then places 25 at index 2. Time complexity: O(n) in the worst case. This example assumes free capacity and a valid index.

4.3 Deletion

➖
Definition

Deletion is the process of removing an element from a specified position in an array.

To delete 30 at index 2 from 10, 20, 30, 40, 50, shift 40 and 50 one position left. The logical size changes from 5 to 4. 

#include <stdio.h>
int main()
{
    int a[5] = {10, 20, 30, 40, 50};
    int n = 5, pos = 2, i;
    for(i = pos; i < n - 1; i++)
        a[i] = a[i + 1];
    n--;
    for(i = 0; i < n; i++)
        printf("%d ", a[i]);
    return 0;
}

Output:

10 20 40 50

After shifting, reduce the logical size by one. Time complexity: O(n) in the worst case.

4.4 Searching

🎯
Definition

Searching means checking whether a value exists in an array and finding its position.

Linear Search

Linear search compares the target with each element from the beginning. It stops when a match is found or all elements have been checked. 

#include <stdio.h>
int main()
{
    int a[5] = {10, 20, 30, 40, 50};
    int key = 40, i, found = 0;
    for(i = 0; i < 5; i++)
    {
        if(a[i] == key)
        {
            printf("Found at index %d", i);
            found = 1;
            break;
        }
    }
    if(found == 0)
        printf("Not found");
    return 0;
}

Output:

Found at index 3

Best case: O(1); worst case: O(n).

Binary Search

Binary search repeatedly divides the search interval in half. The array must be sorted first.

Step 1

Sorted array: 10, 20, 30, 40, 50. Target = 40.

Step 2

Middle index = 2, value = 30. Since 40 is greater, search the right half.

Step 3

Next middle index = 3, value = 40. Target found!

low = 0;
high = n - 1;
while(low <= high)
{
    mid = low + (high - low) / 2;
    if(a[mid] == key)
        break;
    else if(a[mid] < key)
        low = mid + 1;
    else
        high = mid - 1;
}

Time complexity: O(log n). Always use sorted data for binary search.

4.5 Updating

✏️
Definition

Updating means replacing an existing value at a particular index with a new value. 

int a[4] = {10, 20, 30, 40};
a[1] = 99;

New array: 10, 99, 30, 40. No shifting is required, so updating a known valid index takes O(1).

Sorting an Array

↕️
Definition

Sorting arranges array elements in a particular order, such as ascending or descending.

Order Example Meaning
Ascending 1, 3, 5, 8 Smallest to largest
Descending 8, 5, 3, 1 Largest to smallest

Bubble Sort

Bubble Sort compares adjacent elements. If they are in the wrong order, it swaps them. After each pass, the largest unsorted value moves towards the end.

Pass 1

Start 5, 3, 8, 1. Swap 5 and 3; then swap 8 and 1. Result: 3, 5, 1, 8.

Pass 2

Swap 5 and 1. Result: 3, 1, 5, 8.

Pass 3

Swap 3 and 1. Sorted: 1, 3, 5, 8.

#include <stdio.h>
int main()
{
    int a[5] = {5, 3, 8, 1, 4};
    int i, j, temp;
    for(i = 0; i < 4; i++)
    {
        for(j = 0; j < 4 - i; j++)
        {
            if(a[j] > a[j + 1])
            {
                temp = a[j];
                a[j] = a[j + 1];
                a[j + 1] = temp;
            }
        }
    }
    for(i = 0; i < 5; i++)
        printf("%d ", a[i]);
    return 0;
}

Output:

1 3 4 5 8

How swapping works

temp = a[j];
a[j] = a[j + 1];
a[j + 1] = temp;

The temporary variable saves the first value before it is overwritten. Bubble Sort has average and worst-case time complexity O(n²) and auxiliary space O(1).

Advantages and Disadvantages

✅

Advantages

Easy data management under one name.

Fast direct access using an index.

Simple traversal with loops.

Consecutive memory storage can improve locality.

Useful for building stacks, queues and heaps.

⚠️

Disadvantages

Normal C arrays have fixed capacity.

Insertion in the middle may require shifting.

Deletion in the middle may require shifting.

Elements share the same declared type.

Over-allocation can waste memory.

Time complexity of array operations

Operation Time Reason
Access by index O(1) Direct access
Traversal O(n) Visits all elements
Linear search O(n) May check every element
Binary search O(log n) Halves search range
Insertion in middle O(n) May shift elements
Deletion in middle O(n) May shift elements
Update by index O(1) Direct assignment
Bubble Sort O(n²) Repeated comparisons

Here, n is the number of elements. These are usual worst-case complexities unless otherwise stated.

Quick Revision and Important Questions

Important points

  • An array stores multiple elements of the same declared type.
  • The first index in C is 0.
  • For size n, valid indexes are 0 through n − 1.
  • Access by index takes O(1).
  • Traversal and linear search take O(n) in the worst case.
  • Binary search requires sorted data.
  • Insertion and deletion may require shifting.
  • Bubble Sort has O(n²) average and worst-case time.
