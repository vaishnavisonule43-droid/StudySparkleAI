01 • BASICS

1. Introduction to Array

What is an Array?

Definition: An array is a linear data structure that stores multiple elements of the same data type in consecutive memory locations. Each element is accessed using an index.

In programming, we often need to store several values of the same type. For example, if we want to store the marks of five students, we could create five separate variables. However, managing many variables becomes difficult. An array solves this problem by storing multiple values under one variable name.

Example without an Array

int mark1 = 70;
int mark2 = 80;
int mark3 = 65;
int mark4 = 90;
int mark5 = 75;

Here, five separate variables are required. If there are 100 students, creating and managing 100 separate variables is inconvenient.

Example using an Array

int marks[5] = {70, 80, 65, 90, 75};

Now, all five marks are stored in one array named marks. We can access each mark using its index.

Array Representation

Index 070
Index 180
Index 265
Index 390
Index 475

Important Characteristics

  • An array stores multiple elements under one name.
  • In C, array indexing starts from 0.
  • Array elements have the same declared data type.
  • Elements of an array are stored consecutively in memory.
  • Accessing an element by index takes constant time, O(1).
  • A normal fixed-size array cannot automatically grow when more elements are needed.

Declaration of an Array in C

data_type array_name[size];

For example, int a[5]; declares an array that can hold five integers.

Remember: The size of an array is the number of elements it can hold, whereas the index identifies the position of an element.
02 • CLASSIFICATION

2. Types of Array

2.1 One-Dimensional Array

A one-dimensional array stores elements in a single sequence or list. Each element is accessed using one index. 

int numbers[5] = {10, 20, 30, 40, 50};
printf("%d", numbers[2]);

Output:

30

The index 2 refers to the third element because indexing begins at zero.

Uses: Student marks, temperatures, prices and lists of numbers.

2.2 Two-Dimensional Array

A two-dimensional array stores data in rows and columns. It is useful for representing a matrix or a table. 

int matrix[2][3] = {
    {1, 2, 3},
    {4, 5, 6}
};

printf("%d", matrix[1][2]);

Output:

6

matrix[1][2] means row index 1 and column index 2. Both indexes start from zero.

Row / Column Column 0 Column 1 Column 2
Row 0 1 2 3
Row 1 4 5 6

2.3 Multidimensional Array

An array with three or more dimensions is called a multidimensional array. It can represent data arranged across multiple dimensions. 

int data[2][3][4];

This declaration represents an array with 2 blocks, 3 rows per block and 4 columns per row, giving a total capacity of 24 integers.

Comparison of Array Types

Type Structure Example
One-dimensional Single list a[5]
Two-dimensional Rows and columns a[2][3]
Multidimensional Three or more dimensions a[2][3][4]
03 • MEMORY AND INDEXING

3. Array Index and Accessing Elements

An index is the position number used to identify an element inside an array. In C, the first index is 0, not 1. 

int a[5] = {10, 20, 30, 40, 50};
Index 0 1 2 3 4
Value 10 20 30 40 50
  • a[0] returns 10.
  • a[1] returns 20.
  • a[2] returns 30.
  • a[4] returns 50.

Program to Access an Array Element

#include <stdio.h>

int main()
{
    int a[5] = {10, 20, 30, 40, 50};

    printf("Element = %d", a[2]);

    return 0;
}

Output:

Element = 30

How is the Address Calculated?

For a one-dimensional array, the address of an element can be calculated using this formula:

Address of A[i] = Base Address + (i × Size of Each Element)

Suppose the base address is 1000, each integer occupies 4 bytes, and we want the element at index 3.

Step 1: Index = 3

Step 2: Element size = 4 bytes

Step 3: Address = 1000 + (3 × 4)

Answer: Address = 1012

The 4-byte size is an example assumption. The actual size of int depends on the C implementation.

Important: If an array has size 5, its valid indexes are 0 through 4. Accessing an out-of-range index in C results in undefined behavior.
04 • BASIC OPERATIONS

4. Operations on Array

The common array operations are traversal, insertion, deletion, searching and updating. Each operation serves a different purpose.

4.1 Traversal

Definition: Traversal is the process of visiting each element of an array one by one to display or process its value.

Algorithm:

  1. Start from index 0.
  2. Read or process the current element.
  3. Move to the next index.
  4. Repeat until all elements have been visited.
#include <stdio.h>

int main()
{
    int a[5] = {10, 20, 30, 40, 50};
    int i;

    for(i = 0; i < 5; i++)
    {
        printf("%d ", a[i]);
    }

    return 0;
}

Output:

10 20 30 40 50

Explanation: Initially, i = 0, so the program prints a[0]. The loop then increments i and continues until i = 4. When i becomes 5, the condition i < 5 becomes false and the loop stops.

Time complexity: O(n), because all n elements are visited.

4.2 Insertion

Definition: Insertion is the process of adding a new element at a specified position in an array.

When inserting into the middle of an array, existing elements must be shifted to the right to create space. Insertion at the end may not require shifting, provided capacity is available.

Example: Insert 25 at index 2

Original array: 10, 20, 30, 40

Step 1: Start from the last element, 40.

Step 2: Move 40 one position right.

Step 3: Move 30 one position right.

Step 4: Place 25 at index 2.

Final array: 10, 20, 25, 30, 40

Algorithm:

  1. Check whether the array has available capacity.
  2. Start from the last occupied index.
  3. Shift elements right until the insertion index is free.
  4. Insert the new value.
  5. Increase the logical element count by one.
#include <stdio.h>

int main()
{
    int a[10] = {10, 20, 30, 40};
    int n = 4, pos = 2, value = 25, i;

    for(i = n; i > pos; i--)
    {
        a[i] = a[i - 1];
    }

    a[pos] = value;
    n++;

    for(i = 0; i < n; i++)
    {
        printf("%d ", a[i]);
    }

    return 0;
}

Output:

10 20 25 30 40

Explanation: The loop starts at index 4, copying the element at index 3 into index 4. It continues shifting elements until index 2 is available. The value 25 is then placed at index 2.

Time complexity: O(n) in the worst case, because many elements may need to be shifted.

This example uses a zero-based index and assumes the array has enough capacity.

4.3 Deletion

Definition: Deletion is the process of removing an element from a specified position in an array.

After an element is deleted, the elements to its right are shifted one position left so that there is no gap in the logical sequence.

Example: Delete the element at index 2

Original array: 10, 20, 30, 40, 50

The element at index 2 is 30. After deleting it, the result is 10, 20, 40, 50.

Algorithm:

  1. Check that the index is valid.
  2. Start at the index to be deleted.
  3. Copy each following element into the previous position.
  4. Decrease the logical element count by one.
#include <stdio.h>

int main()
{
    int a[5] = {10, 20, 30, 40, 50};
    int n = 5, pos = 2, i;

    for(i = pos; i < n - 1; i++)
    {
        a[i] = a[i + 1];
    }

    n--;

    for(i = 0; i < n; i++)
    {
        printf("%d ", a[i]);
    }

    return 0;
}

Output:

10 20 40 50

Explanation: The value at index 3 is copied to index 2. Then the value at index 4 is copied to index 3. The logical size is reduced from 5 to 4.

Time complexity: O(n) in the worst case.

4.4 Searching

Definition: Searching is the process of finding whether a given value exists in an array and identifying its position.

Linear Search

Linear search checks each element from the beginning. It stops when the target is found or when every element has been checked.

Example: Find 40 in 10, 20, 30, 40, 50.

Index 0: 10 is not 40.

Index 1: 20 is not 40.

Index 2: 30 is not 40.

Index 3: 40 matches the target. Stop searching.

#include <stdio.h>

int main()
{
    int a[5] = {10, 20, 30, 40, 50};
    int key = 40, i, found = 0;

    for(i = 0; i < 5; i++)
    {
        if(a[i] == key)
        {
            printf("Found at index %d", i);
            found = 1;
            break;
        }
    }

    if(found == 0)
    {
        printf("Not found");
    }

    return 0;
}

Output:

Found at index 3

Explanation: The variable key stores the target value. The loop compares the target with each array element. When a match is found, the program prints the index and break ends the loop.

Time complexity: Best case O(1); worst case O(n).

Binary Search

Binary search repeatedly divides the search interval into halves. It requires the array to be sorted before searching.

Sorted array: 10, 20, 30, 40, 50

Target: 40

Middle index = 2, value = 30. Since 40 is greater than 30, search the right half.

Next middle index = 3, value = 40. Target found.

#include <stdio.h>

int main()
{
    int a[5] = {10, 20, 30, 40, 50};
    int low = 0, high = 4, mid, key = 40;

    while(low <= high)
    {
        mid = low + (high - low) / 2;

        if(a[mid] == key)
        {
            printf("Found at index %d", mid);
            return 0;
        }
        else if(a[mid] < key)
        {
            low = mid + 1;
        }
        else
        {
            high = mid - 1;
        }
    }

    printf("Not found");
    return 0;
}

Output:

Found at index 3

Time complexity: O(log n) in the best standard worst-case analysis for binary search, compared with O(n) for linear search. Binary search works only when the data is sorted according to the searched order.

4.5 Updating

Definition: Updating means replacing the existing value of an element at a particular index with a new value. 
#include <stdio.h>

int main()
{
    int a[4] = {10, 20, 30, 40};
    int i;

    a[1] = 99;

    for(i = 0; i < 4; i++)
    {
        printf("%d ", a[i]);
    }

    return 0;
}

Output:

10 99 30 40

Explanation: The statement a[1] = 99; replaces the value 20 at index 1 with 99. No shifting is required.

Time complexity: O(1) when the index is known and valid.

05 • SORTING

5. Sorting an Array

Definition: Sorting is the process of arranging array elements in a specific order, such as ascending or descending order.

Ascending and Descending Order

Ascending order arranges values from smallest to largest. Descending order arranges them from largest to smallest.

Original 5 3 8 1
Ascending 1 3 5 8
Descending 8 5 3 1

Bubble Sort

Bubble Sort compares adjacent elements. If two adjacent elements are in the wrong order, they are swapped. Repeated passes gradually move larger values towards the end of the array.

Step-by-Step Example

Original array: 5, 3, 8, 1

Pass 1: Compare 5 and 3; swap. Compare 5 and 8; no swap. Compare 8 and 1; swap. Result: 3, 5, 1, 8.

Pass 2: Compare 3 and 5; no swap. Compare 5 and 1; swap. Result: 3, 1, 5, 8.

Pass 3: Compare 3 and 1; swap. Result: 1, 3, 5, 8.

Bubble Sort Program in C

#include <stdio.h>

int main()
{
    int a[5] = {5, 3, 8, 1, 4};
    int i, j, temp;

    for(i = 0; i < 4; i++)
    {
        for(j = 0; j < 4 - i; j++)
        {
            if(a[j] > a[j + 1])
            {
                temp = a[j];
                a[j] = a[j + 1];
                a[j + 1] = temp;
            }
        }
    }

    for(i = 0; i < 5; i++)
    {
        printf("%d ", a[i]);
    }

    return 0;
}

Output:

1 3 4 5 8

How the Swap Works

temp = a[j];
a[j] = a[j + 1];
a[j + 1] = temp;

The temporary variable stores the first value before it is overwritten. The second value is copied into the first position, and the saved value is then copied into the second position.

Time complexity: O(n²) in the average and worst cases for this basic implementation. Its auxiliary space complexity is O(1).

06 • REVISION

6. Advantages and Disadvantages of Array

Advantages

  • Easy data management: Multiple values can be stored under one variable name.
  • Fast indexed access: An element can be accessed directly using its index.
  • Simple traversal: Loops make it easy to process every element.
  • Memory locality: Consecutive storage often improves access efficiency.
  • Useful foundation: Arrays are used to implement other data structures and algorithms.

Disadvantages

  • Fixed capacity: A normal declared C array does not automatically expand.
  • Insertion cost: Inserting in the middle may require shifting many elements.
  • Deletion cost: Deleting from the middle may require shifting remaining elements.
  • Same declared type: Elements of a normal C array share the same element type.
  • Capacity planning: Allocating more space than needed may waste memory.

Time Complexity of Array Operations

Operation Time Complexity Reason
Access by index O(1) Direct index calculation
Traversal O(n) Visits all elements
Linear search O(n) May check every element
Binary search O(log n) Halves the search interval
Insertion in middle O(n) May shift elements
Deletion in middle O(n) May shift elements
Update by index O(1) Direct assignment
Bubble Sort O(n²) Repeated adjacent comparisons

Here, n represents the number of elements. The complexity shown is the usual worst-case complexity unless otherwise noted.

07 • PRACTICAL USES

7. Applications of Array

1. Student Record Systems

An array can store marks for multiple students and make it easy to calculate totals, averages and highest marks.

2. Matrix Operations

Two-dimensional arrays represent matrices used in mathematical calculations and scientific applications.

3. Searching and Sorting

Arrays store collections of values that can be searched for a target or sorted into a required order.

4. Image Processing

Images can be represented as grids of pixel values. Two-dimensional or multidimensional arrays can store those values.

5. Implementing Other Data Structures

Arrays can be used to implement stacks, queues, heaps and other structures.

6. Statistical Calculations

Arrays can store observations used to calculate totals, averages, minimum values and maximum values.

8. Quick Revision and Important Questions

Important Points to Remember

  • An array stores multiple elements of the same declared type.
  • In C, the first index is 0.
  • For an array of size n, valid indexes range from 0 to n - 1.
  • Access by index takes O(1) time.
  • Traversal and linear search take O(n) time in the usual worst case.
  • Binary search requires sorted data.
  • Insertion and deletion may require shifting elements.
  • Bubble Sort has O(n²) average and worst-case time complexity.
