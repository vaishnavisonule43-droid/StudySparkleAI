📊 Array in Data Structure

Learn the basic concepts of Array in Data Structure.

What is an Array?

An Array is a collection of elements of the same data type stored in continuous memory locations. Each element is identified by an index number.

Definition: An Array is a linear data structure that stores multiple elements of the same type using a single variable name.

Example of Array

Suppose we want to store marks of 5 students. Instead of creating five different variables, we can use one array.

Example:
marks[5] = {70, 85, 60, 90, 75}

Characteristics of Array

  • Stores multiple elements.
  • Elements are usually of the same data type.
  • Elements are stored in continuous memory locations.
  • Each element has an index number.
  • Array size is generally fixed after declaration.

Types of Array

1. One-Dimensional Array

A one-dimensional array stores elements in a single row or list.

Example:
int marks[5];

2. Two-Dimensional Array

A two-dimensional array stores elements in rows and columns. It is commonly used to represent a matrix.

Example:
int matrix[3][3];

Array Index

Index is the position number used to access an element of an array. In most programming languages, array indexing starts from 0.

Example:
Array: 10, 20, 30, 40, 50
Index: 0, 1, 2, 3, 4

Operations on Array

1. Traversal

Traversal means visiting each element of the array one by one.

2. Insertion

Insertion means adding a new element at a particular position in the array.

3. Deletion

Deletion means removing an element from the array.

4. Searching

Searching means finding a particular element in the array.

5. Updating

Updating means changing the value of an existing element.

Advantages of Array

  • Easy to understand and use.
  • Provides fast access to elements using index.
  • Stores multiple values using one variable name.
  • Useful for storing similar types of data.
  • Easy to traverse using loops.

Disadvantages of Array

  • Array size is generally fixed.
  • Insertion and deletion can be time-consuming.
  • Memory may be wasted if the full array is not used.
  • Usually stores elements of the same data type.

Applications of Array

  • Storing student marks.
  • Storing lists of numbers.
  • Representing matrices.
  • Searching and sorting data.
  • Storing data used in programs and algorithms.

Conclusion

Array is an important linear data structure used to store multiple elements of the same type. It provides easy and fast access to elements using their index.
