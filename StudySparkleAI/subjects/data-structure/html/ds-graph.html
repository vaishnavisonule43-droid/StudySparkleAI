📈 Graph in Data Structure

Learn the basic concepts of Graph in Data Structure.

What is a Graph?

A Graph is a non-linear data structure that consists of vertices and edges. It is used to represent relationships between different objects or entities.

Definition: A Graph is a collection of vertices and edges used to represent relationships between objects.

Basic Terms of Graph

1. Vertex

A vertex is a node or point in a graph that represents an object or entity.

2. Edge

An edge is a connection between two vertices.

Example: In a social network, people can be represented as vertices and their friendships can be represented as edges.

Types of Graph

1. Undirected Graph

In an undirected graph, edges do not have a specific direction. The connection works in both directions.

2. Directed Graph

In a directed graph, each edge has a specific direction from one vertex to another.

3. Weighted Graph

In a weighted graph, each edge has a value or weight. The weight can represent distance, cost or time.

4. Unweighted Graph

In an unweighted graph, edges do not have any specific weight or value.

Graph Representation

A graph can be represented in different ways in a computer. The two common methods are:

  • Adjacency Matrix
  • Adjacency List

1. Adjacency Matrix

An adjacency matrix uses a two-dimensional array to represent connections between vertices.

2. Adjacency List

An adjacency list stores the neighbouring vertices of each vertex in a list.

Graph Traversal

Graph traversal means visiting all the vertices of a graph in a systematic way.

1. Breadth First Search (BFS)

BFS visits vertices level by level. It uses a queue data structure.

2. Depth First Search (DFS)

DFS explores one path deeply before moving to another path. It can be implemented using a stack or recursion.

Applications of Graph

  • Social networking systems.
  • Google Maps and route finding.
  • Computer networks.
  • Airline and railway route systems.
  • Web page linking.
  • Network and communication systems.

Advantages of Graph

  • Represents relationships easily.
  • Useful for solving real-world problems.
  • Helps represent networks and connections.
  • Supports different traversal techniques.
  • Useful in path-finding and network problems.

Simple Example

Consider four cities: Pune, Nashik, Mumbai and Nagpur. Each city can be represented as a vertex, while roads connecting the cities can be represented as edges.

Cities → Vertices
Roads → Edges

Conclusion

Graph is an important non-linear data structure used to represent relationships and connections. It is widely used in computer networks, maps, social media and many other real-world applications.
