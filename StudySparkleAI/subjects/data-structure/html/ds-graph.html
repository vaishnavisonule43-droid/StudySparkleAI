Graph in Data Structure

Learn Graph concepts, types, representation and traversal techniques.

TOPIC 01

1. Introduction to Graph

Definition: A graph is a non-linear data structure consisting of vertices and edges. Vertices represent points, and edges connect them.

Basic Components

  • Vertex: A point or node in a graph.
  • Edge: A connection between two vertices.
  • Adjacent Vertices: Vertices connected by an edge.
  • Path: A sequence of connected vertices.

Example

Graph G = (V, E)
V = {A, B, C, D}
E = {(A, B), (A, C), (B, D), (C, D)}

Here, A, B, C and D are vertices. The connections between them are edges.

TOPIC 02

2. Types of Graph

1. Directed Graph

A directed graph has edges with a specific direction.

A → B

The edge shows a direction from A to B.

2. Undirected Graph

An undirected graph has edges without direction.

A — B

The connection between A and B works in both directions.

3. Weighted Graph

A weighted graph has a weight or cost assigned to its edges.

A — 5 — B

Here, 5 represents the weight of the edge.

4. Unweighted Graph

An unweighted graph has edges without assigned numerical weights.

5. Connected Graph

An undirected graph is connected if a path exists between every pair of vertices.

6. Complete Graph

A simple graph is complete when every pair of distinct vertices is connected by an edge.

TOPIC 03

3. Graph Terminology

Term Meaning
Vertex A point in a graph.

Degree Number of edges incident on a vertex in an undirected graph.
Path A sequence of connected vertices.
Cycle A path that starts and ends at the same vertex.
Loop An edge connecting a vertex to itself.
TOPIC 04

4. Graph Representation

A graph can be represented in memory using different methods. Two common methods are:

1. Adjacency Matrix

An adjacency matrix is a two-dimensional array used to represent connections between vertices.

Consider a graph with three vertices: A, B and C.

Vertex A B C
A 0 1 1
B 1 0 0
C 1 0 0

0: No edge exists.
1: An edge exists.

2. Adjacency List

An adjacency list stores the neighbouring vertices of each vertex.
A → B, C B → A C → A

This representation stores the neighbours of each vertex.

CONCEPT EXPLANATION

Understanding Graph Step by Step

1. What is a Vertex?

A vertex is a point or node in a graph. Each vertex represents an object, place or person.

Example: In a city map, each city can be represented as a vertex.

2. What is an Edge?

An edge connects two vertices. It shows the relationship or connection between them.

Example: A road connecting two cities can be represented as an edge.

3. What is a Neighbour?

Two vertices are neighbours when an edge directly connects them.

In the visualization, A is connected to B and C. Therefore, B and C are neighbours of A.

4. What is a Degree?

In an undirected graph, the degree of a vertex is the number of edges connected to it.

Degree = Number of edges connected to a vertex

In this graph, vertex A has degree 2 because it connects to B and C.

5. What is a Path?

A path is a sequence of vertices connected by edges.

A → B → D

This is a path from A to D through B.

6. What is a Cycle?

A cycle is a path that starts and ends at the same vertex without repeating other vertices in a simple cycle.

A → B → E → C → A

This example forms a cycle because it returns to A.

7. What is a Connected Graph?

An undirected graph is connected when every vertex can be reached from every other vertex through a path.

8. What is a Weighted Graph?

A weighted graph assigns a numerical value, such as distance or cost, to each edge.

City A — 10 km — City B

9. What is a Directed Graph?

A directed graph has edges with a specific direction. An edge from A to B does not automatically mean that an edge from B to A exists.

A → B
TRAVERSAL TECHNIQUES

How BFS and DFS Work

Breadth First Search (BFS)

BFS visits vertices level by level. It uses a queue, which follows the First In, First Out (FIFO) principle.

  1. Start from vertex A.
  2. Visit A and add its neighbours to the queue.
  3. Visit the next unvisited vertex in the queue.
  4. Continue until all reachable vertices are visited.
Remember: BFS explores nearby vertices first.

Depth First Search (DFS)

DFS explores one path as deeply as possible before returning to explore other paths.

  1. Start from vertex A.
  2. Visit an unvisited neighbour.
  3. Continue deeper along the current path.
  4. Return when no unvisited neighbour remains.
  5. Continue until all reachable vertices are visited.
Remember: DFS explores deeply before backtracking.
TOPIC 05

5. Graph Traversal

Graph traversal is the process of visiting vertices of a graph in a systematic way.

The two common graph traversal techniques are:

  • Breadth First Search (BFS)
  • Depth First Search (DFS)

1. Breadth First Search (BFS)

BFS visits vertices level by level. It uses a queue to manage the vertices waiting to be visited.

Steps of BFS

  1. Start from a selected vertex.
  2. Mark the vertex as visited.
  3. Add it to the queue.
  4. Visit its unvisited neighbours.
  5. Continue until the queue becomes empty.

2. Depth First Search (DFS)

DFS explores one path as deeply as possible before returning to explore other paths. It uses recursion or a stack.

Steps of DFS

  1. Start from a selected vertex.
  2. Mark the vertex as visited.
  3. Visit an unvisited neighbour.
  4. Continue exploring deeper vertices.
  5. Return when no unvisited neighbour remains.
TOPIC 06

6. Difference Between BFS and DFS

BFS DFS
Visits level by level. Explores deeply first.
Uses a queue. Uses a stack or recursion.
Finds shortest paths in unweighted graphs. Does not always find the shortest path.
Useful for level-wise exploration. Useful for exploring paths and connectivity.

TOPIC 09

9. Disadvantages of Graph

  • Graph implementation can be complex.
  • Adjacency matrices may use more memory for sparse graphs.
  • Large graphs can be difficult to manage.
  • Some graph algorithms require more processing time.
