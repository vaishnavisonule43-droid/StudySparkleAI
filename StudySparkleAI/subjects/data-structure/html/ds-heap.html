🌳 Heap

Learn the basic concepts of Heap in Data Structure.

What is Heap?

A Heap is a special tree-based data structure. It is a complete binary tree that follows a specific order between parent and child nodes.

Definition: A Heap is a complete binary tree in which the parent node follows a specific relationship with its child nodes.

Types of Heap

There are mainly two types of Heap:

  • Max Heap
  • Min Heap

Max Heap

In a Max Heap, the value of the parent node is greater than or equal to the values of its child nodes.

Example: If the parent is 50 and its children are 30 and 40, then the condition of Max Heap is satisfied because 50 is greater than both.

Min Heap

In a Min Heap, the value of the parent node is smaller than or equal to the values of its child nodes.

Example: If the parent is 10 and its children are 20 and 30, then the condition of Min Heap is satisfied because 10 is smaller than both.

Properties of Heap

  • Heap is a complete binary tree.
  • It follows the heap property.
  • It can be represented using an array.
  • It is useful for priority-based operations.

Heap Operations

1. Insertion

In insertion, a new element is added to the heap and then moved upward if necessary to maintain the heap property.

2. Deletion

In deletion, the root element is removed and the heap is rearranged to maintain the heap property.

3. Heapify

Heapify is the process of rearranging elements so that the heap property is maintained.

4. Peek

Peek returns the root element of the heap without removing it.

Heap Representation

A heap can be represented using an array. For an element at index i, its child nodes can be found using array index relationships.

For 0-based indexing:

Left Child = 2i + 1

Right Child = 2i + 2

Parent = (i - 1) / 2

Applications of Heap

  • Priority Queue
  • Heap Sort
  • Operating System scheduling
  • Graph algorithms
  • Finding minimum or maximum values

Advantages of Heap

  • Efficient access to minimum or maximum element.
  • Useful for implementing priority queues.
  • Insertion and deletion can be performed efficiently.
  • Heap Sort can be implemented using a heap.

Disadvantages of Heap

  • Searching for an arbitrary element is not very efficient.
  • Heap implementation can be more complex than simple arrays.
  • Maintaining the heap property requires extra operations.

Simple Example

Consider the following Max Heap:

50

/ \

30 40

/ \

20 10

Here, 50 is the largest element and it is present at the root. Every parent node is greater than or equal to its children, so it follows the Max Heap property.

Conclusion

Heap is an important tree-based data structure used to efficiently manage minimum and maximum elements. It is widely used in priority queues, heap sort and various algorithms.
