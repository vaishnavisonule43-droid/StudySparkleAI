📥 Queue

Learn the basic concepts of Queue in Data Structure.

What is Queue?

A Queue is a linear data structure in which elements are inserted from one end and removed from the other end.

Definition: Queue follows the FIFO principle, which means First In, First Out.

Example

A real-life example of a queue is a line of people waiting at a ticket counter. The person who comes first gets served first.

FIFO Principle

FIFO stands for First In, First Out. The element inserted first is removed first.

Example:

If we insert: 10 → 20 → 30

Then the first element removed will be: 10

Queue Operations

1. Enqueue

Enqueue is used to add an element to the rear end of the queue.

2. Dequeue

Dequeue is used to remove an element from the front end of the queue.

3. Peek

Peek is used to view the front element without removing it.

4. IsEmpty

IsEmpty checks whether the queue contains any element or not.

Types of Queue

  • Simple Queue
  • Circular Queue
  • Priority Queue
  • Double Ended Queue (Deque)

Applications of Queue

  • CPU Scheduling
  • Printer Queue
  • Call Center Systems
  • Network Data Handling
  • Keyboard and I/O Buffers

Advantages of Queue

  • Easy to implement.
  • Follows FIFO principle.
  • Useful for scheduling tasks.
  • Helps manage data in an organized way.

Disadvantages of Queue

  • Random access is not possible.
  • Searching an element can be time-consuming.
  • Fixed-size queues may cause overflow.
