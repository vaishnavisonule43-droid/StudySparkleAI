What is Recursion?

Recursion is a programming technique in which a function calls itself to solve a problem.

Definition: Recursion is a process where a function repeatedly calls itself until a specific condition is satisfied.

Example

A simple example of recursion is calculating the factorial of a number.

Example:

Factorial of 5 = 5 × 4 × 3 × 2 × 1 = 120

How Recursion Works?

A recursive function generally has two important parts:

  • Base Case: It stops the recursive calls.
  • Recursive Case: It calls the same function again with a smaller or simpler problem.
Important: Without a proper base case, recursion may continue indefinitely and cause a stack overflow.

Factorial Using Recursion

Factorial of a number n is the multiplication of all positive integers from 1 to n.

Formula:

factorial(n) = n × factorial(n - 1)

Base case: factorial(1) = 1

Example

factorial(4) → 4 × factorial(3) → 4 × 3 × factorial(2) → 4 × 3 × 2 × factorial(1) → 24

Types of Recursion

  • Direct Recursion
  • Indirect Recursion
  • Tail Recursion
  • Non-Tail Recursion

Advantages of Recursion

  • It makes complex problems easier to solve.
  • Code can be shorter and easier to understand.
  • Useful for tree and graph problems.
  • Useful for divide and conquer algorithms.

Disadvantages of Recursion

  • It can use more memory.
  • Recursive calls can be slower.
  • Incorrect recursion may cause stack overflow.
  • It can be difficult to understand for beginners.

Applications of Recursion

  • Tree Traversal
  • Graph Traversal
  • Factorial Calculation
  • Fibonacci Series
  • Searching and Sorting Algorithms
  • Divide and Conquer Algorithms
