🧪 Software Testing

Software Engineering Notes

📌 What is Software Testing?

Software Testing is the process of checking a software application to find errors, bugs and defects.

In simple words, testing checks whether the software works correctly according to the given requirements or not.

🎯 Objectives of Software Testing

  • Find errors and bugs in software.
  • Check whether requirements are satisfied.
  • Improve software quality.
  • Improve reliability and performance.
  • Make software safe and user-friendly.

📊 Levels of Software Testing

1️⃣ Unit Testing

Testing individual units or components of the software separately.

2️⃣ Integration Testing

Testing whether different modules work correctly together.

3️⃣ System Testing

Testing the complete software system as a whole.

4️⃣ Acceptance Testing

Testing whether the software satisfies customer or user requirements.

⬛ Black Box Testing

Black Box Testing checks the functionality of software without knowing its internal source code.

💡 Example: A tester enters username and password and checks whether login works correctly without looking at the program code.

⬜ White Box Testing

White Box Testing checks the internal structure, logic and source code of the software.

💡 Example: A developer checks whether all conditions, loops and statements in the program work correctly.

🔍 Verification and Validation

✔️ Verification

Checks whether the software is being developed correctly according to specifications.

✔️ Validation

Checks whether the final software satisfies the actual user needs.

⭐ Importance of Software Testing

  • Helps find bugs before software delivery.
  • Improves software quality.
  • Increases customer satisfaction.
  • Improves security and reliability.
  • Reduces future maintenance cost.

🎯 Quick Summary

Software Testing checks software for errors and verifies that it works according to requirements. It improves software quality, reliability, security and customer satisfaction.
