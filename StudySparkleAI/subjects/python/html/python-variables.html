🐍 Python Variables & Data Types

📘 What is a Variable?

A variable is a name used to store a value in a Python program. The value stored in a variable can be changed during program execution.

Example: 
name = "Vaishnavi"
age = 18

Here, name stores a text value and age stores a number.

💡 Creating Variables

In Python, we do not need to declare the type of a variable separately. We can directly assign a value to a variable using the assignment operator.

Example: 
x = 10
name = "Python"
price = 99.50

⭐ Rules for Naming Variables

  • A variable name can contain letters, numbers and underscore.
  • A variable name cannot start with a number.
  • A variable name cannot contain spaces.
  • Python variable names are case-sensitive.
  • Python keywords cannot be used as variable names.
Example: 
student_name = "Rahul"
age2 = 20
total_marks = 450

📚 What are Data Types?

A data type tells us what kind of value is stored in a variable. Python supports different types of data.

🔢 Main Data Types in Python

Data Type Meaning Example
int Integer numbers 25
float Decimal numbers 25.5
str Text or characters "Hello"
bool True or False value True
list Ordered collection of items [10, 20, 30]
tuple Ordered and unchangeable collection (10, 20, 30)
dict Collection of key-value pairs {"name": "Raj"}
set Collection of unique values {10, 20, 30}

🔤 Integer Data Type

The int data type is used to store whole numbers without decimal values.

Example: 
age = 18
marks = 85

🔢 Float Data Type

The float data type is used to store numbers containing decimal values.

Example: 
price = 99.50
percentage = 85.75

🔤 String Data Type

The str data type is used to store text. Strings are written inside single or double quotation marks.

Example: 
name = "Vaishnavi"
college = 'Sangamner College'

✅ Boolean Data Type

The bool data type represents one of two values: True or False.

Example: 
is_student = True
is_logged_in = False

📋 List Data Type

A list is an ordered collection of items. Lists are written using square brackets and their values can be changed.

Example: 
subjects = ["Python", "C", "DBMS"]

📦 Tuple Data Type

A tuple is an ordered collection of items that cannot be changed after it is created.

Example: 
numbers = (10, 20, 30)

🗂️ Dictionary Data Type

A dictionary stores data in the form of key-value pairs.

Example: 
student = {
    "name": "Vaishnavi",
    "age": 18
}

🔹 Set Data Type

A set is a collection of unique values. Duplicate values are not stored in a set.

Example: 
numbers = {10, 20, 30}

🔍 Checking Data Type

Python provides the type() function to check the data type of a value or variable.

Example: 
age = 18

print(type(age))

The output shows that the value stored in age is an integer.

📌 Quick Revision

  • A variable stores a value.
  • Python does not require separate variable type declaration.
  • Variable names are case-sensitive.
  • int stores whole numbers.
  • float stores decimal numbers.
  • str stores text.
  • bool stores True or False.
  • list stores an ordered collection of items.
  • tuple stores an ordered and unchangeable collection.
  • dict stores key-value pairs.
  • set stores unique values.
  • type() is used to check the data type.
