🐍 Python Functions

📘 What is a Function?

A function is a block of reusable code that performs a specific task. Functions help us avoid writing the same code again and again.

Example: 
def greet():
    print("Hello, Welcome to Python!")

greet()

Here, greet() is a function that displays a message.

⭐ Advantages of Functions

  • Functions reduce code repetition.
  • They make programs easier to understand.
  • They make code reusable.
  • They make debugging easier.
  • They divide a large program into smaller parts.

🔹 Creating a Function

In Python, a function is created using the def keyword.

Syntax: 
def function_name():
    statements
Example: 
def welcome():
    print("Welcome to StudySpark AI")

▶️ Calling a Function

After creating a function, we need to call it to execute its code.

Example: 
def welcome():
    print("Welcome!")

welcome()

The statement welcome() calls the function.

📥 Function with Parameters

Parameters are values received by a function. They allow us to pass data into a function.

Example: 
def greet(name):
    print("Hello", name)

greet("Vaishnavi")

📤 Function with Return Value

A function can return a result using the return statement.

Example: 
def add(a, b):
    return a + b

result = add(10, 20)

print(result)

The function returns the sum of the two numbers.

🔢 Function with Multiple Parameters

A function can have more than one parameter.

Example: 
def student_info(name, age):
    print("Name:", name)
    print("Age:", age)

student_info("Vaishnavi", 18)

🎯 Default Parameter

A default parameter has a value that is automatically used when no value is provided during the function call.

Example: 
def greet(name="Student"):
    print("Hello", name)

greet()
greet("Vaishnavi")

🔄 Positional Arguments

In positional arguments, values are passed according to the position of the parameters.

Example: 
def student(name, age):
    print(name)
    print(age)

student("Vaishnavi", 18)

🏷️ Keyword Arguments

Keyword arguments are passed by using the parameter names.

Example: 
def student(name, age):
    print(name)
    print(age)

student(age=18, name="Vaishnavi")

📦 Arbitrary Arguments

Arbitrary arguments allow a function to accept multiple values. The *args syntax is commonly used for this purpose.

Example: 
def subjects(*names):
    for name in names:
        print(name)

subjects("Python", "C", "DBMS")

🧠 Local and Global Variables

A local variable is created inside a function and is normally available only inside that function.

A global variable is created outside a function and can be accessed from different parts of the program.

Example: 
college = "Sangamner College"

def show():
    course = "BCA"
    print(college)
    print(course)

show()

🔁 Recursive Function

A recursive function is a function that calls itself. Recursion is useful for solving some problems by breaking them into smaller similar problems.

Example: 
def countdown(n):

    if n == 0:
        return

    print(n)
    countdown(n - 1)

countdown(5)

λ Lambda Function

A lambda function is a small anonymous function written in a single expression. It is created using the lambda keyword.

Example: 
square = lambda x: x * x

print(square(5))

📊 Built-in Functions

Python provides many built-in functions that can be used directly without creating them ourselves.

Function Purpose
print() Displays output.
len() Returns the length of an object.
type() Returns the data type.
max() Returns the largest value.
min() Returns the smallest value.
sum() Returns the sum of values.

💻 Practical Example

Example: 
def calculate_total(price, quantity):
    return price * quantity

total = calculate_total(100, 3)

print("Total:", total)

This function calculates the total price using price and quantity.

  • Functions make code reusable.
  • They improve program structure.
  • They reduce duplicate code.
  • They make large programs easier to manage.
  • They improve readability and maintenance.
