🐍 Python Strings

📘 What is a String?

A string is a sequence of characters used to store text in Python. Strings can contain letters, numbers, spaces and special characters.

Strings can be written using single quotes, double quotes or triple quotes.

Example: 
name = "Vaishnavi"
course = 'BCA'
message = """Welcome to Python"""

⭐ Creating a String

A string can be created by placing text inside quotation marks.

Example: 
name = "Python"
college = 'Sangamner College'

🔢 String Indexing

Each character in a string has a position called an index. Python uses zero-based indexing, so the first character has index 0.

Example: 
word = "Python"

print(word[0])
print(word[1])
print(word[5])

The characters are accessed using their index positions.

🔙 Negative Indexing

Python also supports negative indexing. The last character has index -1, the second-last has index -2, and so on.

Example: 
word = "Python"

print(word[-1])
print(word[-2])

✂️ String Slicing

String slicing is used to get a part of a string. The general form is start:end.

Example: 
word = "Python"

print(word[0:3])
print(word[2:6])

The ending index is not included in the selected part.

📏 Finding String Length

The len() function is used to find the number of characters in a string.

Example: 
name = "Python"

print(len(name))

➕ Joining Strings

Two or more strings can be joined using the + operator. This operation is called string concatenation.

Example: 
first_name = "Vaishnavi"
last_name = "Sonule"

full_name = first_name + " " + last_name

print(full_name)

🔁 Repeating Strings

A string can be repeated using the * operator.

Example: 
text = "Hi "

print(text * 3)

🔤 Changing Case of Strings

Python provides several methods to change the case of characters in a string.

Method Purpose
upper() Converts characters to uppercase.
lower() Converts characters to lowercase.
title() Converts the first character of each word to uppercase.
capitalize() Converts the first character of the string to uppercase.
Example: 
text = "python programming"

print(text.upper())
print(text.lower())
print(text.title())
print(text.capitalize())

🔍 Searching in a String

The find() method is used to find the position of a substring inside a string.

Example: 
text = "Python Programming"

print(text.find("Python"))

🔄 Replacing String Content

The replace() method is used to replace one part of a string with another.

Example: 
text = "I like C"

new_text = text.replace("C", "Python")

print(new_text)

✂️ Removing Extra Spaces

The strip() method removes extra spaces from the beginning and end of a string.

Example: 
text = "   Python   "

print(text.strip())

📋 Splitting a String

The split() method divides a string into a list using a specified separator.

Example: 
text = "Python,C,DBMS"

subjects = text.split(",")

print(subjects)

🔗 Joining String Values

The join() method combines multiple strings into one string using a separator.

Example: 
subjects = ["Python", "C", "DBMS"]

result = ", ".join(subjects)

print(result)

🔢 Checking String Content

Python provides different methods to check the contents of a string.

Method Purpose
isalpha() Checks whether all characters are alphabetic.
isdigit() Checks whether all characters are digits.
isalnum() Checks whether all characters are letters or numbers.
isspace() Checks whether all characters are whitespace.

⚠️ Strings are Immutable

Strings in Python are immutable. This means that individual characters of an existing string cannot be changed directly.

Example: 
text = "Python"

# A new string can be created instead
text = "Pythons"

print(text)

💻 Practical Example

Example: 
name = "Vaishnavi Sonule"

print("Name:", name)
print("Length:", len(name))
print("Uppercase:", name.upper())
print("Lowercase:", name.lower())

📚 Common String Methods

Method Use
upper() Converts text to uppercase.
lower() Converts text to lowercase.
strip() Removes spaces from both ends.
replace() Replaces text.
find() Finds the position of text.
split() Splits a string into parts.
join() Joins multiple strings.
len() Returns the length of a string.
