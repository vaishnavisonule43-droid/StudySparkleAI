🐍 Python Dictionaries

📘 What is a Dictionary?

A dictionary is a collection of data stored in key-value pairs.

Each key is used to access its corresponding value. Dictionaries are written using curly brackets { }.

Example: 
student = {
    "name": "Vaishnavi",
    "age": 18,
    "course": "BCA"
}

print(student)

⭐ Features of Dictionary

  • Dictionaries store data in key-value pairs.
  • Dictionaries are changeable or mutable.
  • Keys must be unique.
  • Values can be duplicated.
  • Keys are used to access values.
  • A dictionary can contain different data types.

🔑 Dictionary Key and Value

In a dictionary, the word before the colon is called a key and the data after the colon is called a value.

Example: 
student = {
    "name": "Vaishnavi",
    "age": 18
}

Here, name and age are keys. Vaishnavi and 18 are values.

📖 Accessing Dictionary Values

We can access a dictionary value by using its key.

Example: 
student = {
    "name": "Vaishnavi",
    "age": 18,
    "course": "BCA"
}

print(student["name"])
print(student["course"])

🔍 Using get() Method

The get() method is another way to access a value using its key.

Example: 
student = {
    "name": "Vaishnavi",
    "age": 18
}

print(student.get("name"))

➕ Adding a New Item

A new key-value pair can be added to a dictionary by using a new key.

Example: 
student = {
    "name": "Vaishnavi",
    "course": "BCA"
}

student["age"] = 18

print(student)

✏️ Changing a Dictionary Value

Since dictionaries are mutable, we can change an existing value.

Example: 
student = {
    "name": "Vaishnavi",
    "age": 18
}

student["age"] = 19

print(student)

❌ Removing an Item

The pop() method removes an item using its key.

Example: 
student = {
    "name": "Vaishnavi",
    "age": 18,
    "course": "BCA"
}

student.pop("age")

print(student)

🗑️ Using del

The del keyword can also be used to remove a specific dictionary item.

Example: 
student = {
    "name": "Vaishnavi",
    "age": 18
}

del student["age"]

print(student)

🧹 clear() Method

The clear() method removes all items from the dictionary.

Example: 
student = {
    "name": "Vaishnavi",
    "age": 18
}

student.clear()

print(student)

🔑 keys() Method

The keys() method returns all the keys present in a dictionary.

Example: 
student = {
    "name": "Vaishnavi",
    "age": 18,
    "course": "BCA"
}

print(student.keys())

📦 values() Method

The values() method returns all the values present in a dictionary.

Example: 
student = {
    "name": "Vaishnavi",
    "age": 18,
    "course": "BCA"
}

print(student.values())

🔄 items() Method

The items() method returns all key-value pairs from a dictionary.

Example: 
student = {
    "name": "Vaishnavi",
    "age": 18
}

print(student.items())

📏 len() Function

The len() function returns the number of key-value pairs in a dictionary.

Example: 
student = {
    "name": "Vaishnavi",
    "age": 18,
    "course": "BCA"
}

print(len(student))

🔎 Checking if a Key Exists

The in keyword is used to check whether a key exists in a dictionary.

Example: 
student = {
    "name": "Vaishnavi",
    "age": 18
}

if "name" in student:
    print("Key exists")

🔁 Loop Through a Dictionary

A loop can be used to access dictionary keys and values.

Example: 
student = {
    "name": "Vaishnavi",
    "age": 18,
    "course": "BCA"
}

for key in student:
    print(key)

🔄 Loop Through Values

Example: 
student = {
    "name": "Vaishnavi",
    "age": 18,
    "course": "BCA"
}

for value in student.values():
    print(value)

🔑 Loop Through Keys and Values

Example: 
student = {
    "name": "Vaishnavi",
    "age": 18,
    "course": "BCA"
}

for key, value in student.items():
    print(key, value)

📋 Common Dictionary Methods

Method Purpose
get() Returns the value of a key.
keys() Returns all keys.
values() Returns all values.
items() Returns key-value pairs.
update() Adds or changes dictionary items.
pop() Removes an item using its key.
clear() Removes all items.

🔄 update() Method

The update() method is used to add new items or change existing items.

Example: 
student = {
    "name": "Vaishnavi",
    "age": 18
}

student.update({"course": "BCA"})

print(student)

📦 Nested Dictionary

A dictionary can contain another dictionary inside it. This is called a nested dictionary.

Example: 
students = {
    "student1": {
        "name": "Vaishnavi",
        "age": 18
    },
    "student2": {
        "name": "Riya",
        "age": 19
    }
}

print(students["student1"]["name"])

💻 Practical Example

The following example stores student information using a dictionary.

Student Information: 
student = {
    "name": "Vaishnavi",
    "roll_no": 25,
    "course": "BCA",
    "marks": 85
}

print("Name:", student["name"])
print("Roll No:", student["roll_no"])
print("Course:", student["course"])
print("Marks:", student["marks"])

📚 Applications of Dictionaries

  • Storing employee information.
  • Storing product details.
  • Managing user information.
  • Representing structured data.
  • Working with JSON-like data.
