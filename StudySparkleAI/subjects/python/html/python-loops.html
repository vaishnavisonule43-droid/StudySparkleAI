🐍 Python Loops

📘 What is a Loop?

A loop is used to execute a block of code repeatedly. It helps us perform the same task multiple times without writing the same code again and again.

Example: 
for i in range(5):
    print(i)

This loop executes the print statement five times.

⭐ Types of Loops in Python

Python mainly provides two types of loops:

  • for loop
  • while loop

Python also provides loop control statements such as break, continue and pass.

🔹 for Loop

The for loop is used to iterate over a sequence such as a list, tuple, string or range of numbers.

Syntax: 
for variable in sequence:
    statement
Example: 
for i in range(1, 6):
    print(i)

🔢 Using range() with for Loop

The range() function generates a sequence of numbers. It is commonly used with the for loop.

Example: 
for i in range(1, 6):
    print(i)

The loop prints numbers from 1 to 5.

🔤 Loop through a String

A for loop can be used to access each character of a string one by one.

Example: 
name = "Python"

for letter in name:
    print(letter)

📋 Loop through a List

A for loop can be used to access each item in a list.

Example: 
subjects = ["Python", "C", "DBMS"]

for subject in subjects:
    print(subject)

🔹 while Loop

The while loop executes a block of code as long as the given condition is True.

Syntax: 
while condition:
    statement
Example: 
i = 1

while i <= 5:
    print(i)
    i = i + 1

🔄 Difference between for and while Loop

for Loop while Loop
Used to iterate over a sequence. Used to repeat code while a condition is True.
Useful when the number of iterations is known. Useful when repetition depends on a condition.
Commonly used with range(), lists and strings. Commonly used with conditions.

🛑 break Statement

The break statement is used to stop the loop immediately.

Example: 
for i in range(1, 6):

    if i == 3:
        break

    print(i)

The loop stops when the value of i becomes 3.

⏭️ continue Statement

The continue statement skips the current iteration and moves to the next iteration of the loop.

Example: 
for i in range(1, 6):

    if i == 3:
        continue

    print(i)

When i is 3, that iteration is skipped.

⏸️ pass Statement

The pass statement does nothing. It is used as a placeholder when a statement is required syntactically but no action is needed.

Example: 
for i in range(5):
    pass

🔁 Nested Loops

A loop inside another loop is called a nested loop. Nested loops are useful for working with multiple levels of data.

Example: 
for i in range(1, 4):

    for j in range(1, 4):
        print(i, j)

💻 Practical Example

Loops are commonly used for printing numbers, processing lists, reading data and performing repeated calculations.

Example: 
total = 0

for i in range(1, 6):
    total = total + i

print(total)

This program adds the numbers from 1 to 5.

📚 Advantages of Loops

  • Loops reduce repeated code.
  • They save time and effort.
  • They make programs shorter and easier to manage.
  • They are useful for processing collections of data.
  • They are commonly used in real-world programs.
