🐍 Python Lists & Tuples

📘 What is a List?

A list is a collection of multiple values stored in a single variable. Lists are ordered, changeable and allow duplicate values.

Lists are created using square brackets [ ].

Example: 
subjects = ["Python", "C", "DBMS"]

print(subjects)

⭐ Features of Lists

  • Lists are ordered.
  • Lists are changeable or mutable.
  • Lists allow duplicate values.
  • Lists can contain different data types.
  • Lists support indexing and slicing.

🔢 List Indexing

Each item in a list has an index number. The first item has index 0.

Example: 
subjects = ["Python", "C", "DBMS"]

print(subjects[0])
print(subjects[1])
print(subjects[2])

✂️ List Slicing

List slicing is used to get a part of a list.

Example: 
numbers = [10, 20, 30, 40, 50]

print(numbers[1:4])

➕ Adding Items to a List

The append() method adds an item at the end of a list.

Example: 
subjects = ["Python", "C"]

subjects.append("DBMS")

print(subjects)

📍 Inserting Items

The insert() method adds an item at a specific position in a list.

Example: 
subjects = ["Python", "DBMS"]

subjects.insert(1, "C")

print(subjects)

❌ Removing Items

The remove() method removes a specified item from a list.

Example: 
subjects = ["Python", "C", "DBMS"]

subjects.remove("C")

print(subjects)

🗑️ pop() Method

The pop() method removes and returns an item from a list. By default, it removes the last item.

Example: 
numbers = [10, 20, 30]

numbers.pop()

print(numbers)

🧹 clear() Method

The clear() method removes all items from a list.

Example: 
numbers = [10, 20, 30]

numbers.clear()

print(numbers)

🔄 Changing List Items

Since lists are mutable, their items can be changed after creation.

Example: 
subjects = ["Python", "C", "DBMS"]

subjects[1] = "Java"

print(subjects)

📊 Common List Methods

Method Purpose
append() Adds an item at the end.
insert() Adds an item at a specific position.
remove() Removes a specified item.
pop() Removes and returns an item.
clear() Removes all items.
sort() Sorts the list.
reverse() Reverses the order of items.
count() Counts occurrences of an item.

📦 What is a Tuple?

A tuple is an ordered collection of values. Unlike a list, a tuple cannot be changed after it is created.

Tuples are generally created using parentheses ( ).

Example: 
numbers = (10, 20, 30, 40)

print(numbers)

⭐ Features of Tuples

  • Tuples are ordered.
  • Tuples are immutable.
  • Tuples allow duplicate values.
  • Tuples support indexing.
  • Tuples support slicing.
  • Tuples can contain different data types.

🔢 Tuple Indexing

Tuple items can be accessed using their index numbers.

Example: 
numbers = (10, 20, 30)

print(numbers[0])
print(numbers[2])

✂️ Tuple Slicing

Slicing can also be used to get a part of a tuple.

Example: 
numbers = (10, 20, 30, 40, 50)

print(numbers[1:4])

📊 Tuple Methods

Since tuples cannot be changed, they have fewer methods than lists.

Method Purpose
count() Counts how many times a value occurs.
index() Returns the index of a value.

🔄 List vs Tuple

List Tuple
Lists are mutable. Tuples are immutable.
Lists use square brackets. Tuples usually use parentheses.
Lists have more methods. Tuples have fewer methods.
Lists are suitable for changeable data. Tuples are suitable for fixed data.

💻 Practical Example

List Example: 
marks = [75, 80, 85, 90]

marks.append(95)

print(marks)
Tuple Example: 
days = ("Monday", "Tuesday", "Wednesday")

print(days)

📚 Applications of Lists and Tuples

  • Storing student marks.
  • Storing subject names.
  • Storing product information.
  • Managing collections of data.
  • Processing data in Python programs.
