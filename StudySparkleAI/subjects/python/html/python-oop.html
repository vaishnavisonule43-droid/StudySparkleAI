🐍 Object-Oriented Programming in Python

📘 What is OOP?

OOP stands for Object-Oriented Programming. It is a programming approach based on objects and classes.

In OOP, data and functions are combined together inside objects. Python supports object-oriented programming.

Simple Example: 
class Student:
    name = "Vaishnavi"

student1 = Student()

print(student1.name)

⭐ What is a Class?

A class is a blueprint or template used to create objects. It defines the properties and behaviour of objects.

Example: 
class Student:
    name = "Vaishnavi"
    course = "BCA"

📦 What is an Object?

An object is an instance of a class. Objects are created using a class.

Example: 
class Student:
    name = "Vaishnavi"

student1 = Student()

print(student1.name)

🔗 Class and Object Example

class Student:
    name = "Vaishnavi"
    age = 18

student1 = Student()

print(student1.name)
print(student1.age)

⚙️ The __init__() Method

The __init__() method is a special method in Python. It is automatically called when a new object is created.

It is commonly used to initialize object data.

Example: 
class Student:

    def __init__(self, name, age):
        self.name = name
        self.age = age

student1 = Student("Vaishnavi", 18)

print(student1.name)
print(student1.age)

👤 What is self?

self refers to the current object of the class. It is used to access variables and methods belonging to that object.

Example: 
class Student:

    def __init__(self, name):
        self.name = name

student1 = Student("Vaishnavi")

print(student1.name)

🔧 Methods in a Class

A method is a function defined inside a class. It describes an action that an object can perform.

Example: 
class Student:

    def show(self):
        print("Student is studying")

student1 = Student()

student1.show()

📊 Attributes

Attributes are variables that store information about an object.

Example: 
class Student:

    def __init__(self, name, course):
        self.name = name
        self.course = course

student1 = Student("Vaishnavi", "BCA")

print(student1.name)
print(student1.course)

🧩 Main Concepts of OOP

The four main concepts of Object-Oriented Programming are:

  • Encapsulation
  • Inheritance
  • Polymorphism
  • Abstraction

🔒 1. Encapsulation

Encapsulation means combining data and methods inside a class and controlling access to the data.

Example: 
class Student:

    def __init__(self, name):
        self.name = name

    def show(self):
        print(self.name)

student1 = Student("Vaishnavi")

student1.show()

👨‍👩‍👧 2. Inheritance

Inheritance allows one class to use the properties and methods of another class.

The existing class is called the parent class and the new class is called the child class.

Example: 
class Animal:

    def sound(self):
        print("Animal makes sound")


class Dog(Animal):

    def bark(self):
        print("Dog barks")


dog1 = Dog()

dog1.sound()
dog1.bark()

🔄 3. Polymorphism

Polymorphism means "many forms". It allows the same method name to behave differently for different objects.

Example: 
class Dog:

    def sound(self):
        print("Dog barks")


class Cat:

    def sound(self):
        print("Cat meows")


dog = Dog()
cat = Cat()

dog.sound()
cat.sound()

🎭 4. Abstraction

Abstraction means hiding unnecessary implementation details and showing only the important features to the user.

For example, when we use a mobile phone, we use its buttons and applications without knowing all the internal working.

🏗️ Constructor

A constructor is a special method used to initialize an object. In Python, __init__() is commonly used as a constructor.

Example: 
class Student:

    def __init__(self, name):
        self.name = name

student1 = Student("Vaishnavi")

print(student1.name)

👨‍👩‍👧 Parent and Child Class

Term Meaning
Parent Class The class whose properties are inherited.

Object Instance of a class.
Method Function defined inside a class.
Attribute Variable associated with an object.

📊 Advantages of OOP

  • Code can be reused.
  • Programs are easier to organize.
  • Large programs can be divided into classes.
  • Data can be protected using encapsulation.
  • Inheritance reduces repeated code.
  • Programs become easier to maintain.

💻 Practical Example

The following example creates a Student class and stores student information. 

class Student:

    def __init__(self, name, course, marks):
        self.name = name
        self.course = course
        self.marks = marks

    def display(self):
        print("Name:", self.name)
        print("Course:", self.course)
        print("Marks:", self.marks)


student1 = Student("Vaishnavi", "BCA", 85)

student1.display()
