🐍 Exception Handling in Python

📘 What is an Exception?

An exception is an error that occurs while a Python program is running.

When an exception occurs, the normal flow of the program can stop if the error is not handled.

Example: 
a = 10
b = 0

print(a / b)

In this example, division by zero causes an exception.

⭐ What is Exception Handling?

Exception handling is a method of handling errors that occur during program execution.

Python mainly uses try, except, else and finally blocks for exception handling.

🧩 Why Use Exception Handling?

  • It prevents the program from stopping suddenly.
  • It helps handle runtime errors.
  • It makes programs more reliable.
  • It displays meaningful error messages.
  • It allows the program to continue when possible.

🔹 try Block

The try block contains the code that may produce an exception.

Example: 
try:
    print(10 / 0)

🔹 except Block

The except block is used to handle an exception that occurs inside the try block.

Example: 
try:
    print(10 / 0)

except:
    print("An error occurred")

🔹 try and except Example

try:
    number = int(input("Enter a number: "))
    print(10 / number)

except:
    print("Something went wrong")

🎯 Handling a Specific Exception

We can specify the type of exception that we want to handle.

For example, ZeroDivisionError occurs when a number is divided by zero.

Example: 
try:
    result = 10 / 0

except ZeroDivisionError:
    print("Cannot divide by zero")

🔢 ValueError

ValueError occurs when a function receives a value of the correct type but an inappropriate value.

Example: 
try:
    number = int("abc")

except ValueError:
    print("Invalid number")

🔤 TypeError

TypeError occurs when an operation is performed on an inappropriate data type.

Example: 
try:
    result = "10" + 5

except TypeError:
    print("Invalid data types")

📂 FileNotFoundError

FileNotFoundError occurs when Python tries to access a file that does not exist.

Example: 
try:
    file = open("abc.txt", "r")

except FileNotFoundError:
    print("File not found")

🔹 Multiple except Blocks

A program can have multiple except blocks to handle different types of exceptions.

Example: 
try:
    number = int(input("Enter a number: "))
    result = 10 / number

except ValueError:
    print("Please enter a valid number")

except ZeroDivisionError:
    print("Cannot divide by zero")

🔹 else Block

The else block runs when no exception occurs in the try block.

Example: 
try:
    number = int(input("Enter a number: "))
    result = 10 / number

except ZeroDivisionError:
    print("Cannot divide by zero")

else:
    print("Result:", result)

🔹 finally Block

The finally block runs whether an exception occurs or not.

It is commonly used for cleanup operations such as closing a file.

Example: 
try:
    print(10 / 2)

except ZeroDivisionError:
    print("Cannot divide by zero")

finally:
    print("Program completed")

📊 try, except, else and finally

Block Purpose
try Contains code that may cause an exception.
except Handles the exception.
else Runs when no exception occurs.
finally Runs whether an exception occurs or not.

🚨 Common Python Exceptions

Exception Meaning
ZeroDivisionError Division by zero.
ValueError Invalid value is given.
TypeError Invalid operation between data types.
IndexError Invalid list or sequence index.
KeyError Dictionary key does not exist.
FileNotFoundError Requested file does not exist.

🔢 IndexError Example

IndexError occurs when we try to access an index that does not exist in a list.

Example: 
numbers = [10, 20, 30]

try:
    print(numbers[5])

except IndexError:
    print("Invalid index")

🔑 KeyError Example

KeyError occurs when we try to access a dictionary key that does not exist.

Example: 
student = {
    "name": "Vaishnavi",
    "course": "BCA"
}

try:
    print(student["age"])

except KeyError:
    print("Key not found")

📢 Raising an Exception

The raise keyword is used to manually generate an exception.

Example: 
age = 15

if age < 18:
    raise ValueError("Age must be 18 or above")

💻 Practical Example

The following program takes two numbers and safely performs division. 

try:

    num1 = int(input("Enter first number: "))
    num2 = int(input("Enter second number: "))

    result = num1 / num2

except ValueError:
    print("Please enter numbers only")

except ZeroDivisionError:
    print("Second number cannot be zero")

else:
    print("Result:", result)

finally:
    print("Thank you")

📚 Advantages of Exception Handling

  • Improves program reliability.
  • Prevents unexpected program termination.
  • Makes error messages easier to understand.
  • Helps handle different errors separately.
  • Makes programs easier to maintain.
