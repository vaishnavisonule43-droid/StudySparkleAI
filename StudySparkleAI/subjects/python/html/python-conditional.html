🐍 Python Conditional Statements

📘 What are Conditional Statements?

Conditional statements are used to make decisions in a Python program. They execute different blocks of code depending on whether a condition is True or False.

Example: 
age = 18

if age >= 18:
    print("You are eligible to vote.")

⭐ Types of Conditional Statements

Python mainly provides the following conditional statements:

  • if statement
  • if-else statement
  • if-elif-else statement
  • Nested if statement
  • Conditional Expression

🔹 if Statement

The if statement is used to execute a block of code when a given condition is True.

Syntax: 
if condition:
    statement
Example: 
marks = 75

if marks >= 40:
    print("Pass")

🔹 if-else Statement

The if-else statement is used when we want to execute one block when the condition is True and another block when the condition is False.

Syntax: 
if condition:
    statement1
else:
    statement2
Example: 
marks = 35

if marks >= 40:
    print("Pass")
else:
    print("Fail")

🔹 if-elif-else Statement

The if-elif-else statement is used when there are multiple conditions to check.

Syntax: 
if condition1:
    statement1
elif condition2:
    statement2
else:
    statement3
Example: 
marks = 75

if marks >= 80:
    print("Grade A")
elif marks >= 60:
    print("Grade B")
else:
    print("Grade C")

🔗 Multiple elif Conditions

We can use more than one elif statement when we need to check several conditions.

Example: 
marks = 85

if marks >= 90:
    print("Excellent")
elif marks >= 75:
    print("Very Good")
elif marks >= 60:
    print("Good")
elif marks >= 40:
    print("Pass")
else:
    print("Fail")

📌 Nested if Statement

A nested if statement means using one if statement inside another if statement.

Example: 
age = 20
has_id = True

if age >= 18:
    if has_id:
        print("Entry allowed")

💡 Conditional Expression

A conditional expression is a short way to write a simple if-else condition in one line.

Example: 
age = 20

result = "Adult" if age >= 18 else "Minor"

print(result)

🔍 Conditions with Comparison Operators

Conditional statements commonly use comparison operators such as greater than, less than, equal to and not equal to.

Operator Meaning Example
== Equal to 10 == 10
!= Not equal to 10 != 5
> Greater than 10 > 5
< Less than 5 < 10
>= Greater than or equal to 10 >= 10
<= Less than or equal to 5 <= 10

🧠 Conditions with Logical Operators

Logical operators can be used to combine multiple conditions.

  • and: Both conditions must be True.
  • or: At least one condition must be True.
  • not: Reverses the result of a condition.
Example: 
age = 20

if age >= 18 and age <= 60:
    print("Eligible")

⚠️ Importance of Indentation

Python uses indentation to define a block of code. The statements inside an if, elif or else block must be properly indented.

Correct Example: 
if age >= 18:
    print("Adult")

The print statement is indented, so it belongs to the if block.

💻 Real-Life Example

Conditional statements can be used in real-life applications such as checking age, marks, login details, eligibility and payment status.

Example: 
marks = 65

if marks >= 40:
    print("Student passed the exam")
else:
    print("Student failed the exam")

📚 Advantages of Conditional Statements

  • They help programs make decisions.
  • They allow different actions for different conditions.
  • They make programs more useful and flexible.
  • They are useful for checking user input.
  • They are commonly used in real-world applications.

📌 Quick Revision

  • Conditional statements are used for decision making.
  • The if statement checks a condition.
  • The else block executes when the if condition is False.
  • The elif statement checks additional conditions.
  • A nested if means an if statement inside another if statement.
  • Conditional expressions provide a short form of if-else.
  • Python uses indentation to define code blocks.
