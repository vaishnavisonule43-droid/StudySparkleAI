🌐 Introduction to Web Technology

Learn the basics of websites, web pages and the internet.

1. What is Web Technology?

Web Technology refers to the tools and techniques used to create and access websites and web applications through the internet.

Example

Google, YouTube and Amazon are examples of websites that use web technologies.

2. What is the Internet?

The Internet is a worldwide network that connects computers and other devices. It allows people to communicate and share information.

Example

We use the internet to send emails, watch videos and search for information.

3. What is the World Wide Web (WWW)?

The World Wide Web is a collection of linked web pages and resources that we access through the internet using a web browser.

Remember

The Internet is the network, while the WWW is a collection of web pages and resources available through that network.

4. What is a Website?

A website is a collection of related web pages available under one domain name.

Example

Wikipedia is a website that contains many pages of information.

5. What is a Web Page?

A web page is a single document displayed in a web browser. It can contain text, images, videos and links.

Example

Home, About Us and Contact Us can be separate pages of one website.

6. What is a Web Browser?

A web browser is software used to open and view websites on the internet.

Examples

  • Google Chrome
  • Mozilla Firefox
  • Microsoft Edge
  • Safari

7. What is a Web Server?

A web server is a computer or software that stores, processes and delivers website content when users request it.

Example

When you open a website, its server sends the requested page or data to your browser.

8. What is a URL?

URL stands for Uniform Resource Locator. It is the address used to locate a resource on the web.

Example

https://www.example.com

9. Types of Websites

Static Website

A static website displays fixed content that usually changes only when its files are edited.

Example

A simple personal portfolio website.

Dynamic Website

A dynamic website can display changing content based on user actions, stored data or other conditions.

Example

Social networking websites and online shopping websites.

10. Front-End and Back-End

Front-End

The front-end is the part of a website that users see and interact with.

Technologies

HTML, CSS and JavaScript.

Back-End

The back-end handles server-side operations, application logic and database communication.

Technologies

Java, PHP, Python, Node.js and databases such as MySQL.

11. Basic Structure of an HTML Page

HTML is used to create the structure of a web page. Here is a simple HTML example. 

<!DOCTYPE html>
<html lang="en">
<head>
    <title>My First Website</title>
</head>
<body>
    <h1>Welcome to My Website</h1>
    <p>This is my first web page.</p>
</body>
</html>

12. Advantages of Web Technology

  • Information can be accessed easily.
  • Websites can be opened on different devices.
  • It supports online communication.
  • It helps businesses provide online services.
  • It makes sharing information easier.

13. Applications of Web Technology

  • Education and online learning.
  • Online shopping and banking.
  • Social networking.
  • Online booking systems.
  • Business and information websites.
