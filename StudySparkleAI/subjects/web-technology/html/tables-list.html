HTML Tables & Lists

Learn Tables and Lists with Simple Examples

1. Introduction to HTML Tables

An HTML table is used to display data in rows and columns. Tables are useful for displaying student marks, product details, timetables and other structured information.

Important Table Tags

  • table: Creates a table.
  • tr: Creates a table row.
  • th: Creates a header cell.
  • td: Creates a data cell.
  • caption: Adds a table title.

2. Basic HTML Table

This example creates a table containing student names and courses.

<table border="1">
    <tr>
        <th>Name</th>
        <th>Course</th>
    </tr>

    <tr>
        <td>Rahul</td>
        <td>BCA</td>
    </tr>

    <tr>
        <td>Priya</td>
        <td>BBA</td>
    </tr>
</table>
Explanation:
  • The table tag creates the table.
  • The tr tag creates each row.
  • The th tag displays column headings.
  • The td tag displays the actual data.

3. Table with Caption

The caption tag adds a title to a table.

<table border="1">
    <caption>Student Details</caption>

    <tr>
        <th>Roll No.</th>
        <th>Name</th>
    </tr>

    <tr>
        <td>1</td>
        <td>Amit</td>
    </tr>
</table>

4. Colspan Attribute

The colspan attribute allows one cell to cover multiple columns. 

<table border="1">
    <tr>
        <th colspan="2">Student Details</th>
    </tr>

    <tr>
        <td>Name</td>
        <td>Rahul</td>
    </tr>
</table>

5. Rowspan Attribute

The rowspan attribute allows one cell to cover multiple rows. 

<table border="1">
    <tr>
        <th>Name</th>
        <th>Subject</th>
    </tr>

    <tr>
        <td rowspan="2">Rahul</td>
        <td>HTML</td>
    </tr>

    <tr>
        <td>CSS</td>
    </tr>
</table>
Remember:
  • colspan: Combines cells horizontally across columns.
  • rowspan: Combines cells vertically across rows.

6. Introduction to HTML Lists

HTML lists are used to display related items in an organized way. HTML provides ordered lists, unordered lists and description lists.

7. Ordered List

An ordered list displays items in a sequence, usually with numbers. It uses the ol and li tags. 

<ol>
    <li>Wake up</li>
    <li>Study</li>
    <li>Go to college</li>
</ol>

Output

  1. Wake up
  2. Study
  3. Go to college

8. Ordered List Types

The type attribute changes the numbering style of an ordered list. 

<ol type="A">
    <li>HTML</li>
    <li>CSS</li>
</ol>

<ol type="I">
    <li>First</li>
    <li>Second</li>
</ol>
  • type="1": 1, 2, 3
  • type="A": A, B, C
  • type="a": a, b, c
  • type="I": I, II, III
  • type="i": i, ii, iii

9. Unordered List

An unordered list displays items with bullets by default. It uses the ul and li tags. 

<ul>
    <li>HTML</li>
    <li>CSS</li>
    <li>JavaScript</li>
</ul>

Output

  • HTML
  • CSS
  • JavaScript

10. Unordered List Styles

CSS can change the bullet style of an unordered list. 

<ul style="list-style-type: square;">
    <li>HTML</li>
    <li>CSS</li>
</ul>

<ul style="list-style-type: circle;">
    <li>JavaScript</li>
    <li>Python</li>
</ul>
  • disc: Filled circular bullets.
  • circle: Hollow circular bullets.
  • square: Square bullets.
  • none: No bullets.

11. Nested Lists

A nested list is a list placed inside another list item. 

<ul>
    <li>Frontend
        <ul>
            <li>HTML</li>
            <li>CSS</li>
            <li>JavaScript</li>
        </ul>
    </li>

    <li>Backend</li>
</ul>

12. Description List

A description list displays terms and their descriptions. It uses dl, dt and dd tags. 

<dl>
    <dt>HTML</dt>
    <dd>Used to structure web pages.</dd>

    <dt>CSS</dt>
    <dd>Used to style web pages.</dd>
</dl>
  • dl: Creates the description list.
  • dt: Specifies a term.
  • dd: Provides the term's description.

13. Difference Between Tables and Lists

HTML Tables HTML Lists
Display data in rows and columns. Display related items in a sequence or group.
Use table, tr, th and td tags. Use ol, ul, li and related tags.
Useful for marksheets and schedules. Useful for steps and item collections.

14. Advantages of Tables and Lists

  • Organize information clearly.
  • Make web page content easier to read.
  • Tables help compare structured data.
  • Lists show steps and related items.
  • Nested lists organize information into levels.

Quick Revision

  • table creates a table.
  • tr creates a row.
  • th creates a heading cell.
  • td creates a data cell.
  • colspan spans columns.
  • rowspan spans rows.
  • ol creates an ordered list.
  • ul creates an unordered list.
  • li creates a list item.
  • dl, dt and dd create a description list.
