JavaScript Notes

Learn JavaScript with Simple Explanations and Examples

1. What is JavaScript?

JavaScript is a programming language used to make web pages interactive. It can respond to button clicks, validate forms, change page content and create animations.

Example

HTML creates a button, CSS styles it, and JavaScript can make it respond when clicked.

2. Features of JavaScript

  • Makes web pages interactive.
  • Responds to user actions.
  • Can change HTML content and CSS styles.
  • Can validate user input in forms.
  • Runs in modern web browsers.

3. How to Add JavaScript to HTML

Internal JavaScript

JavaScript can be written inside a script tag in an HTML file.

<!DOCTYPE html>
<html>
<body>

<h1>My Website</h1>

<script>
    alert("Welcome to StudySpark AI!");
</script>

</body>
</html>

External JavaScript

JavaScript can also be written in a separate .js file.

<script src="script.js"></script>

Write this line in HTML to connect the external JavaScript file.

4. JavaScript Variables

Variables store data that a program can use. JavaScript provides let, const and var for declaring variables. 

let studentName = "Rahul";
let age = 20;

const college = "Sangamner College";

console.log(studentName);
console.log(age);
console.log(college);
  • let: Declares a variable that can be reassigned.
  • const: Declares a binding that cannot be reassigned.
  • var: An older way to declare variables.
  • console.log(): Displays output in the browser console.

5. JavaScript Data Types

Data types describe the kind of value stored in a variable.

let name = "Amit";       // String
let age = 20;            // Number
let isStudent = true;    // Boolean
let marks;               // Undefined
let result = null;       // Null
  • String: Text data.
  • Number: Numeric values.
  • Boolean: True or false.
  • Undefined: A variable declared without an assigned value.
  • Null: An intentional absence of a value.
  • Object: A collection of related data or properties.

6. JavaScript Operators

Operators perform calculations and comparisons.

let a = 10;
let b = 5;

console.log(a + b);  // Addition
console.log(a - b);  // Subtraction
console.log(a * b);  // Multiplication
console.log(a / b);  // Division
console.log(a > b);  // Comparison

7. Conditional Statements

Conditional statements execute different code depending on whether a condition is true or false. 

let marks = 75;

if (marks >= 35) {
    console.log("Pass");
} else {
    console.log("Fail");
}
Explanation:

If marks are 35 or more, the output is Pass. Otherwise, the output is Fail.

8. JavaScript Loops

Loops repeat a block of code while a condition is satisfied or for a specified number of iterations. 

for (let i = 1; i <= 5; i++) {
    console.log(i);
}

This loop prints the numbers from 1 to 5.

9. JavaScript Functions

A function is a reusable block of code that performs a task when it is called. 

function greet() {
    console.log("Hello Student!");
}

greet();
Explanation:

The function named greet displays a message when it is called.

10. JavaScript Events

Events are actions or occurrences that JavaScript can respond to, such as a button click or a keyboard input. 

<button onclick="showMessage()">
    Click Me
</button>

<script>
function showMessage() {
    alert("Button clicked!");
}
</script>

When the user clicks the button, the function displays an alert message.

11. DOM Manipulation

DOM stands for Document Object Model. It represents the HTML page as objects that JavaScript can access and change. 

<p id="message">Hello!</p>

<script>
document.getElementById("message").textContent =
    "Welcome to StudySpark AI!";
</script>

This code changes the paragraph text on the web page.

12. JavaScript Arrays

An array stores multiple values in a single variable. 

let subjects = ["HTML", "CSS", "JavaScript"];

console.log(subjects[0]);
console.log(subjects[1]);
console.log(subjects[2]);

Array indexing starts at 0, so the first item is at index 0.

13. JavaScript Objects

An object stores related information as key-value pairs. 

let student = {
    name: "Rahul",
    course: "BCA",
    age: 20
};

console.log(student.name);
console.log(student.course);

14. Form Validation

JavaScript can check user input before a form is submitted. For example, it can check whether a required field is empty. 

<input type="text" id="username"
       placeholder="Enter your name">

<button onclick="checkName()">
    Submit
</button>

<script>
function checkName() {
    let name =
        document.getElementById("username").value;

    if (name.trim() === "") {
        alert("Please enter your name.");
    } else {
        alert("Welcome, " + name + "!");
    }
}
</script>

15. Advantages of JavaScript

  • Makes web pages interactive.
  • Responds to user actions.
  • Can update page content without reloading the entire page.
  • Supports form validation.
  • Works with HTML and CSS.

Quick Revision

  • Variables store data.
  • if-else statements make decisions.
  • Loops repeat code.
  • Functions contain reusable code.
  • Events respond to user actions.
  • DOM allows JavaScript to access and change page content.
  • Arrays store multiple values.
