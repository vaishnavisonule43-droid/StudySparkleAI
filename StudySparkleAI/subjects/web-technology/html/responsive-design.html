Responsive Web Design

Learn how to create websites that work on mobile, tablet and desktop.

1. What is Responsive Web Design?

Responsive Web Design is a method of designing websites that automatically adjust to different screen sizes.

A responsive website works properly on mobile phones, tablets, laptops and desktop computers.

Example: A website changes its layout to fit a mobile screen instead of displaying the desktop layout in a small size.

2. Need for Responsive Design

  • It makes websites mobile-friendly.
  • It improves the user experience.
  • It makes content easy to read.
  • It reduces unnecessary horizontal scrolling.
  • It supports different screen sizes.

3. Viewport

The viewport is the visible area of a webpage on a device. The viewport meta tag helps a webpage fit the device's width.

Example

<meta name="viewport"
content="width=device-width, initial-scale=1.0">
Remember: Add the viewport meta tag inside the HTML head section.

4. Flexible Layout

A flexible layout uses relative sizes, such as percentages, instead of fixed widths wherever appropriate.

Example

.container {
    width: 90%;
    margin: auto;
}

Here, the container takes 90% of the available width.

5. Responsive Images

Responsive images adjust their size to fit the available space without overflowing their container.

Example

img {
    max-width: 100%;
    height: auto;
}
Output: The image can shrink to fit its container while maintaining its original aspect ratio.

6. CSS Media Queries

Media queries apply different CSS styles depending on conditions such as the screen width.

Example

body {
    background-color: white;
}

@media (max-width: 600px) {
    body {
        background-color: lightblue;
    }
}
Output: When the viewport width is 600 pixels or less, the page background becomes light blue.

7. Using Flexbox

Flexbox is a CSS layout system that helps arrange elements in rows or columns.

Example

.container {
    display: flex;
    flex-wrap: wrap;
    gap: 15px;
}

The flex-wrap property allows items to move onto another line when there is not enough space.

8. Using CSS Grid

CSS Grid is a layout system used to arrange elements in rows and columns.

Example

.container {
    display: grid;
    grid-template-columns: repeat(2, 1fr);
    gap: 15px;
}

This example creates two equal-width columns.

9. Complete Responsive Website Example

This example creates a simple webpage that adjusts its content layout for smaller screens. 

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport"
          content="width=device-width, initial-scale=1.0">

    <title>Responsive Website</title>

    <style>
        * {
            box-sizing: border-box;
        }

        body {
            font-family: Arial, sans-serif;
            margin: 0;
            padding: 20px;
        }

        .container {
            display: flex;
            gap: 15px;
        }

        .box {
            flex: 1;
            padding: 25px;
            background-color: lightblue;
            text-align: center;
        }

        @media (max-width: 600px) {
            .container {
                flex-direction: column;
            }
        }
    </style>
</head>

<body>
    <h1>My Responsive Website</h1>

    <div class="container">
        <div class="box">First Box</div>
        <div class="box">Second Box</div>
    </div>
</body>
</html>
Output: On wider screens, the two boxes appear side by side. On screens 600 pixels wide or less, they appear one below the other.

10. Advantages of Responsive Design

  • Works on different screen sizes.
  • Improves mobile browsing.
  • Makes content easier to read.
  • Provides a better user experience.
  • Reduces the need for separate mobile websites.
