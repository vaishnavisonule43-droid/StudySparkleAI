CSS Notes

Learn CSS with Simple Explanations and Examples

1. What is CSS?

CSS stands for Cascading Style Sheets. It is used to style HTML web pages. CSS controls colours, fonts, spacing, borders, layouts and animations.

Example

HTML creates a heading, while CSS changes its colour, size and appearance.

2. Features of CSS

  • CSS adds colours and styles to web pages.
  • It controls font size and font style.
  • It helps create attractive page layouts.
  • It supports transitions and animations.
  • It helps make websites responsive on different devices.

3. Basic CSS Syntax

A CSS rule contains a selector and a declaration block.

h1 {
    color: purple;
    font-size: 30px;
}
  • h1: Selector.
  • color: Property.
  • purple: Property value.
  • font-size: Controls the text size.

4. Types of CSS

1. Inline CSS

Inline CSS is written inside an HTML element using the style attribute.

<p style="color: red;">
    Hello World
</p>

2. Internal CSS

Internal CSS is written inside a style tag in the HTML document's head section.

<head>
    <style>
        p {
            color: blue;
        }
    </style>
</head>

3. External CSS

External CSS is written in a separate .css file and connected using a link tag.

<link rel="stylesheet" href="style.css">

Remember

StudySpark AI uses external CSS files to keep HTML content and design separate.

5. CSS Selectors

Selectors identify which HTML elements should receive a style.

/* Element selector */
p {
    color: blue;
}

/* Class selector */
.card {
    background: white;
}

/* ID selector */
#title {
    color: purple;
}

/* Universal selector */
* {
    box-sizing: border-box;
}
  • Element selector: Selects elements by tag name.
  • Class selector: Uses a dot, such as .card.
  • ID selector: Uses a hash, such as #title.
  • Universal selector: Uses * to select all elements.

6. CSS Colours and Backgrounds

CSS colours can be used for text, backgrounds and borders.

body {
    background-color: #f5f3ff;
}

h1 {
    color: purple;
}

.card {
    background: white;
}

7. Fonts and Text Styling

CSS controls how text looks on a web page.

p {
    font-family: Arial, sans-serif;
    font-size: 16px;
    font-weight: bold;
    text-align: center;
}

8. CSS Box Model

The CSS box model describes how an element occupies space. It consists of content, padding, border and margin.

  • Content: The actual text or image.
  • Padding: Space around the content, inside the border.
  • Border: The line around the padding and content.
  • Margin: Space outside the border.
.card {
    padding: 20px;
    border: 2px solid purple;
    margin: 15px;
}

9. CSS Borders and Shadows

Borders create outlines, while shadows add depth to elements.

.card {
    border: 1px solid #ddd;
    border-radius: 12px;
    box-shadow: 0 5px 15px
        rgba(0, 0, 0, 0.1);
}

10. CSS Layout with Flexbox

Flexbox helps arrange elements in a row or column.

.container {
    display: flex;
    justify-content: center;
    align-items: center;
    gap: 20px;
}

11. CSS Hover Effect

The hover selector applies styles when the pointer is over an element.

.button {
    background: purple;
    color: white;
    transition: 0.3s ease;
}

.button:hover {
    background: blue;
    transform: translateY(-3px);
}

12. CSS Animations

CSS animations change styles over time without requiring JavaScript.

@keyframes fadeIn {
    from {
        opacity: 0;
        transform: translateY(15px);
    }

    to {
        opacity: 1;
        transform: translateY(0);
    }
}

.card {
    animation: fadeIn 0.7s ease;
}

13. Responsive CSS

Responsive CSS helps a website adjust to different screen sizes, such as mobile phones, tablets and computers. 

.container {
    width: 90%;
    margin: auto;
}

@media (max-width: 600px) {
    .container {
        width: 95%;
    }
}

14. Advantages of CSS

  • Makes web pages attractive.
  • Keeps design separate from HTML content.
  • Allows consistent styling across pages.
  • Supports responsive layouts.
  • Provides transitions and animations.

Quick Revision

  • CSS stands for Cascading Style Sheets.
  • CSS is used to style HTML pages.
  • Three types: Inline, Internal and External CSS.
  • Selectors target HTML elements.
  • The box model contains content, padding, border and margin.
  • Flexbox helps arrange elements.
  • Media queries help create responsive designs.
