HTML Notes

Learn HTML from Basics with Simple Examples

1. What is HTML?

HTML stands for HyperText Markup Language. It is used to create the structure of web pages. HTML tells the browser how to display headings, paragraphs, images, links, tables and forms.

Example

HTML is used to create the structure of a website, such as its heading, text and links.

2. Features of HTML

  • HTML is easy to learn.
  • It is used to create web pages.
  • It uses tags to organize content.
  • It works with CSS and JavaScript.
  • HTML files can be opened in a web browser.

3. Basic Structure of HTML

Every basic HTML document contains the following elements:

<!DOCTYPE html>
<html>
<head>
    <title>My First Website</title>
</head>
<body>
    <h1>Welcome to StudySpark AI</h1>
    <p>This is my first web page.</p>
</body>
</html>
Explanation:
  • DOCTYPE: Declares an HTML5 document.
  • html: Contains the complete HTML page.
  • head: Contains page information.
  • title: Sets the browser tab title.
  • body: Contains the visible page content.
  • h1: Displays a main heading.
  • p: Displays a paragraph.

4. What are HTML Tags?

HTML tags are keywords written inside angle brackets. They tell the browser what type of content to display.

Examples:

  • <h1> — Main heading
  • <p> — Paragraph
  • <br> — Line break
  • <hr> — Horizontal line
  • <img> — Image
  • <a> — Link

5. Types of HTML Tags

Container Tags

These generally have an opening tag and a closing tag. 

<p>Hello World</p>
<h1>Welcome</h1>

Void Tags

These tags do not need a separate closing tag. 

<br>
<hr>
<img src="photo.jpg" alt="Photo">

6. HTML Headings

HTML provides six heading levels, from <h1> to <h6>. H1 is the highest-level heading and H6 is the lowest-level heading. 

<h1>Heading 1</h1>
<h2>Heading 2</h2>
<h3>Heading 3</h3>
<h4>Heading 4</h4>
<h5>Heading 5</h5>
<h6>Heading 6</h6>

7. HTML Paragraph

The <p> tag is used to display a paragraph on a web page. 

<p>HTML is used to create web pages.</p>

8. HTML Links

The <a> tag creates a hyperlink. The href attribute specifies the destination. 

<a href="https://www.google.com">
    Open Google
</a>

9. HTML Images

The <img> tag displays an image. The src attribute specifies the image location, and alt provides alternative text. 

<img src="flower.jpg" alt="Beautiful flower" width="300">

10. HTML Lists

Ordered List

Displays list items with numbers by default.

<ol>
    <li>HTML</li>
    <li>CSS</li>
    <li>JavaScript</li>
</ol>

Unordered List

Displays list items with bullets by default.

<ul>
    <li>HTML</li>
    <li>CSS</li>
    <li>JavaScript</li>
</ul>

11. HTML Tables

The <table> tag is used to display data in rows and columns. 

<table border="1">
    <tr>
        <th>Name</th>
        <th>Course</th>
    </tr>
    <tr>
        <td>Rahul</td>
        <td>BCA</td>
    </tr>
</table>
Important table tags:
  • <table> — Creates a table.
  • <tr> — Creates a table row.
  • <th> — Creates a header cell.
  • <td> — Creates a data cell.

12. HTML Forms

Forms collect information from users, such as their name, email address and password. 

<form>
    <label for="name">Name:</label>
    <input type="text" id="name" name="name">
    <button type="submit">Submit</button>
</form>

13. HTML Attributes

Attributes provide additional information about HTML elements. They are usually written in the opening tag.

  • href: Specifies a link destination.
  • src: Specifies a resource location.
  • alt: Provides alternative image text.
  • id: Gives an element a unique identifier.
  • class: Groups elements for CSS or JavaScript.

14. Advantages of HTML

  • Easy to learn and use.
  • Free and supported by web browsers.
  • Helps structure web page content.
  • Works with CSS and JavaScript.
  • Useful for creating websites and web applications.

Quick Revision

  • HTML stands for HyperText Markup Language.
  • HTML creates the structure of a web page.
  • Headings use H1 to H6 tags.
  • Paragraphs use the P tag.
  • Links use the A tag.
  • Images use the IMG tag.
  • Tables use TABLE, TR, TH and TD tags.
  • Forms collect user information.
