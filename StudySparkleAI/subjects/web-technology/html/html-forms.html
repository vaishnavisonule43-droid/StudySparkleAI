HTML Forms

Learn Form Elements with Simple Examples

1. What is an HTML Form?

An HTML form is used to collect information from users. For example, a website can use a form to collect a person's name, email address, password and feedback.

Examples of Forms

  • Login form
  • Registration form
  • Contact form
  • Feedback form
  • Online application form

2. Basic Structure of a Form

The <form> tag creates a form. Input elements are placed inside it. 

<form>
    <label for="name">Name:</label>
    <input type="text" id="name" name="name">

    <button type="submit">Submit</button>
</form>

3. Important Form Attributes

  • action: Specifies where form data should be sent.
  • method: Specifies how data is sent, commonly GET or POST.
  • name: Identifies a form field when its data is submitted.
  • required: Makes a field compulsory.
  • placeholder: Displays a hint inside an input field.

4. Text Input

The text input is used to accept short text, such as a person's name. 

<label for="username">Name:</label>
<input type="text"
       id="username"
       name="username"
       placeholder="Enter your name">

5. Password Input

The password input hides the characters as the user types. 

<label for="password">Password:</label>
<input type="password"
       id="password"
       name="password">

6. Email Input

The email input is designed for email addresses and provides basic browser validation when the form is submitted. 

<label for="email">Email:</label>
<input type="email"
       id="email"
       name="email"
       placeholder="name@example.com">

7. Radio Buttons

Radio buttons allow the user to select one option from a group. 

<p>Select your course:</p>

<input type="radio" id="bca"
       name="course" value="BCA">
<label for="bca">BCA</label>

<input type="radio" id="bba"
       name="course" value="BBA">
<label for="bba">BBA</label>

Remember

Radio buttons in the same group use the same name, allowing the user to select one option.

8. Checkboxes

Checkboxes allow the user to select multiple options. 

<p>Select your skills:</p>

<input type="checkbox" id="html" name="skills" value="HTML">
<label for="html">HTML</label>

<input type="checkbox" id="css" name="skills" value="CSS">
<label for="css">CSS</label>

<input type="checkbox" id="js" name="skills" value="JavaScript">
<label for="js">JavaScript</label>

9. Dropdown List

A dropdown list displays options that the user can choose from. 

<label for="city">Select City:</label>

<select id="city" name="city">
    <option value="">Choose a city</option>
    <option value="pune">Pune</option>
    <option value="nashik">Nashik</option>
    <option value="mumbai">Mumbai</option>
</select>

10. Textarea

A textarea is used to enter longer text, such as comments or feedback. 

<label for="feedback">Feedback:</label>

<textarea id="feedback"
          name="feedback"
          rows="4"
          cols="30"
          placeholder="Write your feedback"></textarea>

11. Submit and Reset Buttons

A submit button submits a form. A reset button restores the form fields to their initial values. 

<button type="submit">Submit</button>
<button type="reset">Reset</button>

12. Required Fields and Validation

HTML provides basic form validation. The required attribute prevents submission when a compulsory field is empty. 

<form>
    <label for="fullName">Name:</label>
    <input type="text"
           id="fullName"
           name="fullName"
           required>

    <label for="userEmail">Email:</label>
    <input type="email"
           id="userEmail"
           name="userEmail"
           required>

    <button type="submit">Submit</button>
</form>

13. Complete Registration Form Example

This example combines several form elements into one page. Copy the code into an HTML file and open it in your browser. 

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>Registration Form</title>
</head>

<body>
    <h1>Student Registration</h1>

    <form>
        <label for="name">Name:</label>
        <input type="text" id="name"
               name="name" required>
        <br><br>

        <label for="email">Email:</label>
        <input type="email" id="email"
               name="email" required>
        <br><br>

        <label for="course">Course:</label>
        <select id="course" name="course">
            <option value="BCA">BCA</option>
            <option value="BBA">BBA</option>
        </select>
        <br><br>

        <button type="submit">Register</button>
        <button type="reset">Clear</button>
    </form>
</body>
</html>

Important Note

This example shows the form structure and basic browser validation. To save registration details, the form needs a backend or a form-processing service.

14. Advantages of HTML Forms

  • Collects information from users.
  • Used for login and registration pages.
  • Supports different input types.
  • Provides basic browser validation.
  • Can send data to a server when properly configured.

Quick Revision

  • <form> creates a form.
  • type="text" accepts text.
  • type="password" hides typed characters.
  • type="radio" selects one option in a group.
  • type="checkbox" allows multiple selections.
  • <select> creates a dropdown.
  • <textarea> accepts longer text.
  • required makes a field compulsory.
  • type="submit" submits the form.
