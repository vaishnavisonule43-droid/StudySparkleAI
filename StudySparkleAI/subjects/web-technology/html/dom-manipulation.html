DOM Manipulation

Learn how JavaScript changes HTML elements and webpage content.

1. What is DOM Manipulation?

DOM stands for Document Object Model. It represents an HTML document as a tree of objects.

DOM Manipulation means using JavaScript to change the content, style, or structure of a webpage.

Example: JavaScript can change a heading, change its colour, or add a new paragraph to a webpage.

2. Selecting HTML Elements

JavaScript can select HTML elements using their ID, class, or HTML tag name.

Using getElementById()

It selects an element using its unique ID.

document.getElementById("heading");

Using querySelector()

It selects the first element matching a CSS selector.

document.querySelector(".message");

Using getElementsByClassName()

It selects elements that have the given class name.

document.getElementsByClassName("item");

3. Changing HTML Content

JavaScript can change the text displayed inside an HTML element by using the textContent property. 

<h2 id="heading">Hello Student</h2>

<script>
document.getElementById("heading").textContent =
    "Welcome to StudySpark AI";
</script>
Remember: textContent changes the text inside an element.

4. Changing CSS Styles

JavaScript can change the appearance of an HTML element using the style property. 

<h2 id="title">Hello World</h2>

<script>
const title = document.getElementById("title");

title.style.color = "purple";
title.style.fontSize = "30px";
title.style.backgroundColor = "lightyellow";
</script>
Output: The heading becomes purple, its font size increases, and its background becomes light yellow.

5. DOM Events

An event is an action that happens on a webpage, such as a mouse click or keyboard input.

Common DOM events include:

  • click: When an element is clicked.
  • mouseover: When the mouse moves over an element.
  • keydown: When a keyboard key is pressed.
  • change: When an input value changes.

Example of a Click Event

<button id="myButton">Click Me</button>

<script>
document.getElementById("myButton").addEventListener(
    "click",
    function() {
        alert("Button clicked!");
    }
);
</script>
Output: When the user clicks the button, an alert message appears.

6. Creating New HTML Elements

JavaScript can create new HTML elements using createElement().

The appendChild() method adds the new element inside another element. 

<div id="container"></div>

<script>
const paragraph = document.createElement("p");

paragraph.textContent = "This is a new paragraph.";

document.getElementById("container").appendChild(paragraph);
</script>
Output: A new paragraph is created and added inside the container.

7. Removing HTML Elements

JavaScript can remove an HTML element from the webpage using the remove() method. 

<p id="message">This paragraph will be removed.</p>

<script>
document.getElementById("message").remove();
</script>
Output: The paragraph is removed from the webpage.

8. Changing CSS Classes

The classList property helps JavaScript add, remove, or toggle CSS classes on an HTML element. 

const box = document.getElementById("box");

box.classList.add("active");
box.classList.remove("active");
box.classList.toggle("active");
  • add(): Adds a CSS class.
  • remove(): Removes a CSS class.
  • toggle(): Adds the class if absent, or removes it if present.

9. Advantages of DOM Manipulation

  • It changes webpage content dynamically.
  • It allows interactive webpages.
  • It can change colours and styles.
  • It can create and remove HTML elements.
  • It improves the user experience.
