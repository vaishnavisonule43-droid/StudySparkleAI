Cryptography

Learn how data is protected using encryption.

📘 Introduction

Cryptography is an important part of Cyber Security. It protects information by using mathematical methods and algorithms.

It helps keep messages, passwords and online transactions secure from unauthorized people.

📖 1. Definition of Cryptography

Cryptography is the method of protecting information by converting it into a form that unauthorized people cannot easily understand.

Example: Encrypting a message before sending it over the internet.

🔑 2. Important Terms in Cryptography

1. Plaintext

Plaintext is the original readable message or data before encryption.

Example: HELLO

2. Ciphertext

Ciphertext is the unreadable or transformed data produced after encryption.

Example: A coded form of the word HELLO.

3. Encryption

Encryption converts plaintext into ciphertext using an algorithm and a key.

4. Decryption

Decryption converts ciphertext back into readable data using the required key.

5. Key

A key is information used by a cryptographic algorithm to encrypt or decrypt data.

6. Algorithm

An algorithm is a set of mathematical steps used to perform cryptographic operations.

⚙️ 3. How Cryptography Works

Step 1: Create a Message

The sender creates the original readable message.

Step 2: Encryption

A cryptographic algorithm and key transform the message into ciphertext.

Step 3: Send the Data

The ciphertext is sent to the receiver.

Step 4: Decryption

The receiver uses the required key to recover the original message.

Plaintext → Encryption → Ciphertext → Decryption → Plaintext

🧩 4. Types of Cryptography

1. Symmetric Key Cryptography

Symmetric cryptography uses the same secret key for encryption and decryption.

Example: AES.

Advantage: It is generally fast for encrypting large amounts of data.

Limitation: The secret key must be shared securely.

2. Asymmetric Key Cryptography

Asymmetric cryptography uses a pair of related keys: a public key and a private key.

Example: RSA.

Advantage: It supports secure key exchange and digital signatures.

Limitation: It can be slower than symmetric encryption for large data.

3. Hashing

Hashing converts data into a fixed-length hash value. A secure hash function is designed to make it impractical to recover the original data from the hash.

Example: SHA-256.

Use: Checking data integrity and storing password verifiers securely when used with suitable password-hashing methods.

📊 5. Difference Between Symmetric and Asymmetric Cryptography

Symmetric Asymmetric
Uses one shared secret key. Uses a public and a private key.
Generally faster for bulk data encryption. Often requires more computation.
Secret key sharing must be protected. Public key can be shared openly, while the private key stays secret.
Example: AES. Example: RSA.

🎯 6. Objectives of Cryptography

1. Confidentiality

It keeps information secret from unauthorized people.

2. Integrity

It helps detect unauthorized changes to data.

3. Authentication

It helps verify the identity of a user or the origin of information.

4. Non-repudiation

Digital signatures can provide evidence that helps prevent a signer from falsely denying a signed digital message or document.

💻 7. Applications of Cryptography

  • Online banking and digital payments.
  • Secure websites using HTTPS.
  • Protecting confidential messages.
  • Securing stored files and databases.
  • Digital signatures and certificates.
  • Secure communication between devices.
  • Verifying data integrity.

⭐ 8. Advantages of Cryptography

  • Protects confidential information.
  • Supports secure online communication.
  • Helps detect data modification.
  • Supports authentication and digital signatures.
  • Improves security for online transactions.

⚠️ 9. Limitations of Cryptography

  • Lost keys can make encrypted data difficult to recover.
  • Weak algorithms can create security risks.
  • Keys must be stored and managed securely.
  • Encryption alone cannot prevent every cyber attack.
  • Some cryptographic operations require extra computing resources.

📝 10. Conclusion

Cryptography helps protect information through encryption, decryption, hashing and digital signatures. It is widely used to maintain privacy, data integrity and secure communication in the digital world.
