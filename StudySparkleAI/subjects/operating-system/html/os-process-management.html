⚙️ Process Management in Operating System

1. What is a Process?

A process is a program that is currently being executed by the computer.

When a program is loaded into memory and starts running, it becomes a process.

Example:

When we open a web browser, the browser program becomes a process while it is running.

2. What is Process Management?

Process Management is the function of an Operating System that manages the creation, execution and termination of processes.

It also manages CPU time and resources among different processes.

3. Need of Process Management

Process Management is needed to manage multiple processes efficiently and make proper use of the CPU.

It helps to:

  • Manage running processes.
  • Allocate CPU to processes.
  • Create and terminate processes.
  • Manage process resources.
  • Allow multiple processes to run efficiently.

4. Process States

During its execution, a process passes through different states.

  • New: The process is being created.
  • Ready: The process is ready and waiting for CPU time.
  • Running: The process is currently being executed by the CPU.
  • Waiting: The process is waiting for an input/output operation or another event.
  • Terminated: The process has completed its execution.
Process State Flow:

New → Ready → Running → Waiting → Ready → Running → Terminated

5. Process Control Block (PCB)

Process Control Block (PCB) is a data structure used by the Operating System to store important information about a process.

Every process has its own PCB.

6. Information Stored in PCB

  • Process ID
  • Process State
  • Program Counter
  • CPU Registers
  • CPU Scheduling Information
  • Memory Management Information
  • Input/Output Status Information

7. Process Scheduling

Process Scheduling is the method used by the Operating System to select a process from the ready queue and assign the CPU to it.

The main goal is to use the CPU efficiently and provide good system performance.

8. CPU Scheduling Algorithms

CPU Scheduling Algorithms are used to decide which process should get the CPU next.

  • FCFS: First Come First Serve. The process that arrives first gets the CPU first.
  • SJF: Shortest Job First. The process with the shortest execution time is selected first.
  • Priority Scheduling: The process with higher priority is selected first.
  • Round Robin: Each process gets a fixed amount of CPU time called a time quantum.

9. Process Creation

Process creation means creating a new process for execution.

A process may create another process to perform a particular task.

Example:

When we open a new application, the Operating System creates a new process for that application.

10. Process Termination

Process termination means stopping a process after it has completed its task or when it needs to be stopped because of an error.

The Operating System releases the resources used by the terminated process.

11. Context Switching

Context Switching is the process of saving the state of one process and loading the state of another process.

It allows the CPU to switch between different processes.

Example:

If the CPU stops one process and starts another process, the Operating System saves the first process information and loads the second process information.

12. Process Synchronization

Process Synchronization is used to coordinate multiple processes when they access shared data or resources.

It helps prevent incorrect results and data inconsistency.

13. Process Communication

Process Communication allows processes to exchange information and data with each other.

It is also called Inter-Process Communication (IPC).

14. Advantages of Process Management

  • Improves CPU utilization.
  • Manages multiple processes efficiently.
  • Provides proper CPU scheduling.
  • Helps in process synchronization.
  • Manages process resources.
  • Improves overall system performance.

15. Real-Life Example

Suppose we are using a laptop and running a browser, music player and text editor at the same time.

The Operating System manages all these processes and gives CPU time and other resources to each process.

Example:

Browser → Process 1
Music Player → Process 2
Text Editor → Process 3

The Operating System manages all three processes.

16. Summary

Process Management is an important function of an Operating System. It manages the creation, execution, scheduling, synchronization and termination of processes. It helps the CPU and other resources to be used efficiently.
