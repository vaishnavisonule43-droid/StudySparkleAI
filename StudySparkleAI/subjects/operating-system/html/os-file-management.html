File Management

1. What is File Management?

File Management is an important function of an Operating System that manages files and folders stored on a computer.

In simple words, File Management helps the user to create, store, organize, access, modify and delete files.

2. Need of File Management

  • It organizes files and folders.
  • It helps users find files easily.
  • It controls access to files.
  • It manages storage space.
  • It protects files from unauthorized access.

3. Functions of File Management

  • File Creation: Creates new files.
  • File Deletion: Removes unwanted files.
  • File Access: Allows users and programs to access files.
  • File Modification: Allows changes to file contents.
  • File Naming: Gives names to files.
  • File Organization: Organizes files into folders/directories.
  • File Protection: Controls who can access a file.

4. What is a File?

A file is a collection of related data stored on a storage device with a specific name.

Examples:
Student.txt
Result.pdf
Photo.jpg
Program.c

5. What is a Directory?

A directory is a location used to store and organize files and other directories.

In simple words, a directory is like a folder that contains files.

Example:
Documents → Notes → OS Notes.pdf

6. File Attributes

File attributes are information about a file maintained by the Operating System.

  • Name: Name of the file.
  • Type: Type or extension of the file.
  • Size: Amount of storage used by the file.
  • Location: Where the file is stored.
  • Date and Time: Creation or modification information.
  • Protection: Access permissions of the file.

7. File Operations

The Operating System provides different operations for managing files.

  • Create
  • Open
  • Read
  • Write
  • Close
  • Rename
  • Delete

8. File Access Methods

File access methods describe how data is accessed from a file.

  • Sequential Access
  • Direct Access
  • Indexed Access

9. Sequential Access

In sequential access, data is accessed one after another in a specific order.

Example: Reading a text file from the first line to the last line.

10. Direct Access

In direct access, data can be accessed directly from any required location without reading all previous data.

Example: Directly opening a specific record from a database file.

11. Indexed Access

In indexed access, an index is used to find the required data quickly.

Example: A book index helps us quickly find a particular topic or page.

12. File Types

13. File Protection

File protection means protecting files from unauthorized access, modification or deletion.

  • Read permission
  • Write permission
  • Execute permission
  • User authentication

14. File Allocation

File allocation is the method used by the Operating System to store files on disk.

The main file allocation methods are:

  • Contiguous Allocation
  • Linked Allocation
  • Indexed Allocation

15. Contiguous Allocation

In contiguous allocation, a file is stored in consecutive blocks of the disk.

Example:
File → Block 10 → Block 11 → Block 12 → Block 13

16. Linked Allocation

In linked allocation, the blocks of a file can be stored at different locations. Each block contains a link to the next block.

Example:
Block 5 → Block 18 → Block 9 → Block 25

17. Indexed Allocation

In indexed allocation, an index block stores the addresses of all blocks belonging to a file.

Example:
Index Block → 7, 15, 21, 30

18. File System

A file system is a method used by an Operating System to organize, store and manage files on a storage device.

Examples of file systems include:

  • FAT32
  • NTFS
  • ext4
  • APFS

19. Advantages of File Management

  • Files are organized properly.
  • Files can be accessed easily.
  • Storage space is managed efficiently.
  • Files can be protected using permissions.
  • It makes file operations easier for users.

20. Real-Life Example

File Management is similar to organizing books in a library. Books are kept in different sections and can be found using their names or categories. Similarly, an Operating System organizes files into folders and manages their storage.

21. Summary

File Management is the process of managing files and folders in a computer system. It includes file creation, deletion, access, modification, protection, organization and storage. It helps the Operating System manage files efficiently and allows users to access their data easily.
