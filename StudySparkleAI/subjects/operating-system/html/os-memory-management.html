Memory Management

1. What is Memory Management?

Memory Management is an important function of an Operating System that manages the main memory (RAM) of a computer.

In simple words, it decides which process gets memory, how much memory it gets, and when the memory is released.

2. Need of Memory Management

  • It keeps track of memory usage.
  • It allocates memory to processes.
  • It releases memory after a process finishes.
  • It prevents processes from using each other's memory.
  • It improves the efficient use of RAM.

3. Main Functions of Memory Management

  • Memory Allocation: Gives memory to processes.
  • Memory Deallocation: Frees memory after use.
  • Memory Protection: Protects one process from another.
  • Memory Tracking: Keeps information about used and free memory.
  • Memory Sharing: Allows processes to share memory when required.

4. Memory Allocation

Memory allocation means assigning a portion of main memory to a process when it needs memory for execution.

Example: If a process needs 100 MB of memory, the Operating System finds a suitable free memory area and assigns it to the process.

5. Memory Deallocation

Memory deallocation means releasing the memory occupied by a process after the process completes its execution.

Example: When a program is closed, the memory used by that program is released and can be used by another program.

6. Contiguous Memory Allocation

In contiguous memory allocation, a process is given a continuous block of memory.

The two main types are:

  • Fixed Partitioning
  • Variable Partitioning

7. Fixed Partitioning

In fixed partitioning, the main memory is divided into fixed-size partitions. Each partition can hold one process.

Example: If memory is divided into four partitions, a maximum of four processes can be loaded at the same time.

Disadvantage: It can cause internal fragmentation.

8. Variable Partitioning

In variable partitioning, memory is divided according to the size required by each process.

This uses memory more efficiently than fixed partitioning, but it may create external fragmentation.

9. Fragmentation

Fragmentation means memory is wasted because of the way memory is allocated.

There are two types:

  • Internal Fragmentation
  • External Fragmentation

10. Internal Fragmentation

Internal fragmentation occurs when the allocated memory block is larger than the memory required by the process.

Example: A process needs 70 MB but gets a 100 MB block. The remaining 30 MB inside that block is wasted.

11. External Fragmentation

External fragmentation occurs when enough free memory is available in total, but it is divided into small non-contiguous blocks.

Example: There may be 100 MB free memory, but it is divided into 20 MB + 30 MB + 50 MB blocks. A process requiring one continuous 100 MB block cannot use it.

12. Paging

Paging is a memory management technique in which physical memory is divided into fixed-size blocks called Frames and logical memory is divided into fixed-size blocks called Pages.

  • Pages belong to logical memory.
  • Frames belong to physical memory.
  • Pages can be stored in different frames.
  • Paging helps reduce external fragmentation.

13. Segmentation

Segmentation divides a program into logical parts called segments.

Examples of segments are:

  • Code segment
  • Data segment
  • Stack segment

14. Virtual Memory

Virtual Memory is a technique that allows a computer to run programs that are larger than the available physical RAM.

It uses a part of secondary storage such as an SSD or hard disk as an extension of RAM.

Example: If a computer has limited RAM but needs more memory to run a program, the Operating System can use part of storage as virtual memory.

15. Swapping

Swapping is a technique in which a process is temporarily moved from main memory to secondary storage and later brought back into main memory when required.

Simple Flow:

Main Memory → Secondary Storage → Main Memory

16. Page Replacement

When memory is full and a new page is required, the Operating System removes an existing page from memory and brings the required page into memory.

Common page replacement algorithms are:

  • FIFO (First In First Out)
  • Optimal Page Replacement
  • LRU (Least Recently Used)

17. Memory Management Techniques

Technique Main Idea
Contiguous Allocation Process gets one continuous memory block
Paging Memory is divided into pages and frames
Segmentation Program is divided into logical segments
Virtual Memory Uses secondary storage as an extension of RAM
Swapping Moves processes between RAM and storage

18. Advantages of Memory Management

  • Uses memory efficiently.
  • Allows multiple processes to run.
  • Protects memory from unauthorized access.
  • Reduces memory wastage.
  • Improves system performance.

19. Real-Life Example

Think of RAM as a study table. Different books represent different programs. Memory management decides where each book should be kept, which book can be removed, and where a new book should be placed.

20. Summary

Memory Management is the process of managing the main memory of a computer. It includes memory allocation, deallocation, protection, paging, segmentation, virtual memory and swapping. Good memory management helps the Operating System use RAM efficiently and run multiple processes smoothly.
