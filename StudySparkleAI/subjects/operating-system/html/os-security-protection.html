Security & Protection

1. What is Security?

Security in an Operating System means protecting the computer system, data and resources from unauthorized access and harmful activities.

In simple words, security makes sure that only authorized users can access the system and its data.

2. What is Protection?

Protection is the mechanism used by an Operating System to control access to system resources such as files, memory, CPU and devices.

In simple words, protection decides who can access which resource and what operations they can perform.

3. Need of Security & Protection

  • Protects user data.
  • Prevents unauthorized access.
  • Protects system resources.
  • Prevents data modification by unauthorized users.
  • Improves system reliability.

4. Difference Between Security and Protection

Security Protection
Protects the system from external and internal threats. Controls access to system resources.
Deals with threats and unauthorized access. Deals with permissions and access control.
Example: Password and antivirus. Example: File read/write permissions.

5. Goals of Security

The main goals of Operating System security are:

  • Confidentiality: Keeps information private.
  • Integrity: Prevents unauthorized modification of data.
  • Availability: Makes resources available to authorized users.

6. Authentication

Authentication is the process of verifying the identity of a user before allowing access to the system.

Examples:
Username and Password
PIN
Fingerprint
Face Recognition

7. Authorization

Authorization is the process of deciding what an authenticated user is allowed to access or perform.

Example: A student may be allowed to read a file but may not be allowed to delete or modify it.

8. Access Control

Access Control is a mechanism that controls which users or processes can access particular resources.

  • Read
  • Write
  • Execute
  • Delete

9. File Protection

File Protection prevents unauthorized users from reading, modifying or deleting files.

Example: A private document can be given permission so that only its owner can read or modify it.

10. User Accounts

An Operating System provides user accounts to identify different users and control their access to system resources.

  • Administrator Account
  • Standard User Account
  • Guest Account

11. Password Protection

Password protection uses a password to prevent unauthorized users from accessing an account or system.

A strong password should be difficult to guess and should not be shared with others.

12. Malware

Malware is malicious software designed to damage a computer, steal information or perform unauthorized activities.

Common types include:

  • Virus
  • Worm
  • Trojan Horse
  • Ransomware
  • Spyware

13. Virus

A virus is a malicious program that can attach itself to files or programs and spread when the infected file or program is used.

14. Firewall

A Firewall is a security mechanism that monitors and controls network traffic based on security rules.

Simple Example: A firewall can block unwanted network connections while allowing authorized communication.

15. Antivirus

Antivirus software detects, prevents and removes many types of malicious software from a computer.

16. Encryption

Encryption is the process of converting readable data into an encoded form so that unauthorized people cannot easily understand it.

Simple Flow:

Original Data → Encryption → Encrypted Data
Encrypted Data → Decryption → Original Data

17. System Protection

System Protection prevents processes or users from accessing resources in an unauthorized way.

  • Memory protection
  • File protection
  • Process protection
  • Device protection

18. Common Security Threats

Threat Description
Virus Malicious program that can spread through files or programs
Worm Malware that can spread across networks
Trojan Malicious software disguised as a legitimate program
Spyware Software that secretly collects information
Ransomware Malware that can restrict access to data and demand payment

19. Security Mechanisms

  • Authentication
  • Authorization

  • Encryption

  • Antivirus
  • Backup

20. Advantages of Security & Protection

  • Protects important data.
  • Prevents unauthorized access.
  • Protects system resources.
  • Reduces security risks.
  • Improves user privacy.
  • Increases system reliability.

21. Real-Life Example

Consider a mobile phone protected by a PIN or fingerprint. Authentication checks whether the person is the correct user, while permissions control which apps or data can be accessed. This is similar to Security and Protection in an Operating System.

22. Summary

Security and Protection are important functions of an Operating System. Security protects the system from threats and unauthorized access, while protection controls access to system resources. Authentication, authorization, access control, encryption, firewall and antivirus are commonly used to improve system security.
