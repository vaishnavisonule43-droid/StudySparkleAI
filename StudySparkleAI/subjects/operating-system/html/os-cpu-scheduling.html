CPU Scheduling

1. What is CPU Scheduling?

CPU Scheduling is the process of selecting a process from the ready queue and giving the CPU to that process for execution.

In simple words, CPU scheduling decides which process will use the CPU next.

Example: If P1, P2 and P3 are waiting for CPU, the operating system decides which process should execute first.

2. Need of CPU Scheduling

  • It keeps the CPU busy.
  • It reduces waiting time.
  • It reduces response time.
  • It improves CPU utilization.
  • It provides fair CPU access to processes.

3. Types of CPU Scheduling

CPU scheduling is mainly divided into two types:

  • Preemptive Scheduling
  • Non-Preemptive Scheduling

4. Preemptive Scheduling

In preemptive scheduling, the operating system can stop a running process and give the CPU to another process.

Example: Round Robin and Preemptive Priority Scheduling.

5. Non-Preemptive Scheduling

In non-preemptive scheduling, once a process gets the CPU, it keeps the CPU until it finishes or enters a waiting state.

Example: FCFS and Non-Preemptive SJF.

6. CPU Scheduling Algorithms

Common CPU scheduling algorithms are:

  • First Come First Serve (FCFS)
  • Shortest Job First (SJF)
  • Priority Scheduling
  • Round Robin (RR)

7. First Come First Serve (FCFS)

FCFS is a scheduling algorithm in which the process that arrives first gets the CPU first.

Example:

If the order of processes is P1 → P2 → P3, then P1 executes first, followed by P2 and P3.

Advantages:

  • Simple and easy to understand.
  • Easy to implement.

Disadvantage:

  • It can cause long waiting time.

8. Shortest Job First (SJF)

In SJF, the process having the shortest CPU burst time is selected first.

Example: If P1 needs 8 ms, P2 needs 3 ms and P3 needs 5 ms, then P2 will execute first.

Advantages:

  • Reduces average waiting time.
  • Good for batch systems.

Disadvantage:

  • Long processes may have to wait for a long time.

9. Priority Scheduling

In Priority Scheduling, each process is assigned a priority. The process with the higher priority gets the CPU first.

Example: If P1 has priority 3, P2 has priority 1 and P3 has priority 2, then the process with the highest priority is selected according to the system's priority convention.

Advantages:

  • Important processes can be executed first.
  • Useful for priority-based systems.

Disadvantage:

  • Low-priority processes may wait for a long time.

10. Round Robin (RR)

Round Robin is a preemptive scheduling algorithm. Each process gets a fixed amount of CPU time called Time Quantum.

Example: If the time quantum is 2 ms, each process gets the CPU for 2 ms one by one.

Advantages:

  • Fair scheduling.
  • Good response time.
  • Suitable for time-sharing systems.

Disadvantage:

  • Too small time quantum can cause many context switches.

11. Comparison of Scheduling Algorithms

Algorithm Type Main Idea
FCFS Non-Preemptive First process executes first
SJF Usually Non-Preemptive Shortest job executes first
Priority Preemptive / Non-Preemptive Higher-priority process executes first
Round Robin Preemptive Each process gets fixed time

12. Important Terms

  • Waiting Time: Time spent by a process waiting in the ready queue.
  • Turnaround Time: Total time from process arrival to its completion.
  • Response Time: Time from request/arrival until the process gets CPU for the first time.
  • Time Quantum: Fixed amount of CPU time given to a process in Round Robin scheduling.

13. Advantages of CPU Scheduling

  • Improves CPU utilization.
  • Reduces waiting time.
  • Improves system performance.
  • Provides better response time.
  • Allows multiple processes to share the CPU.

14. Real-Life Example

CPU scheduling is similar to people waiting for service at a counter. The system decides who should be served first according to the scheduling rule.

15. Summary

CPU Scheduling is an important function of an operating system. It decides which process gets the CPU next. FCFS, SJF, Priority and Round Robin are common CPU scheduling algorithms. Good scheduling improves CPU utilization and system performance.
