💾 Backup & Recovery

Learn how database data is backed up and recovered after failure.

📌 What is Database Backup?

Definition: Database backup is a copy of database data that is stored safely so that it can be used when the original data is lost or damaged.

🔄 What is Database Recovery?

Definition: Database recovery is the process of restoring the database to a correct state after a failure or data loss.

⭐ Need of Backup and Recovery

  • Protects important data.
  • Prevents permanent data loss.
  • Helps after system failure.
  • Helps recover deleted or damaged data.
  • Provides data safety.

📚 Types of Database Backup

1. Full Backup

A full backup copies the complete database.

2. Incremental Backup

It stores only the data changed after the previous backup.

3. Differential Backup

It stores the data changed after the last full backup.

⚠️ Types of Database Failures

  • System failure
  • Hardware failure
  • Software failure
  • Power failure
  • Disk failure
  • Human error

🛠️ Recovery Techniques

1. Log-Based Recovery

The system keeps a record of database changes in a log. The log is used to recover the database after failure.

2. Checkpoint

A checkpoint saves the current database state. It helps to make recovery faster.

3. Backup Recovery

The database is restored using a previously created backup.

💡 Simple Example

Suppose a college database contains student records. If the computer crashes and the data is lost, the college can use the backup to restore the student records.

✅ Advantages

  • Protects data from loss.
  • Helps restore data quickly.
  • Improves data safety.
  • Reduces the effect of system failure.
  • Provides reliable database management.
