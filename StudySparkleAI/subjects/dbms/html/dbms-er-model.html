🔗 ER Model

Learn about Entity Relationship Model in DBMS.

📖 What is ER Model?

ER Model stands for Entity Relationship Model. It is used to show the data and relationships between different entities in a database.

Simple Meaning: ER Model is a simple way to design and understand a database using entities, attributes and relationships.

👤 Entity

An entity is a real-world object about which we store data.

Examples:

  • Student
  • Teacher
  • Employee
  • Product
  • Customer
Simple Meaning: Entity means a real-world object.

🏷️ Attribute

An attribute is a property or detail of an entity.

Example:

For a Student entity, Student ID, Name, Age and Class are attributes.

Simple Meaning: Attribute means the information or details of an entity.

🔄 Relationship

A relationship shows how two or more entities are connected with each other.

Example:

A Student enrolls in a Course.

Simple Meaning: Relationship shows the connection between entities.

📐 ER Diagram

An ER Diagram is a graphical representation of entities, attributes and relationships in a database.

Example:

Student → Enrolls → Course

  • Student = Entity
  • Course = Entity
  • Enrolls = Relationship

🧩 Components of ER Model

  • Entity: Real-world object.
  • Attribute: Property of an entity.
  • Relationship: Connection between entities.
  • ER Diagram: Graphical representation of the database.

🔢 Types of Relationships

1. One-to-One (1:1)

One entity is related to only one entity.

2. One-to-Many (1:M)

One entity can be related to many entities.

3. Many-to-Many (M:M)

Many entities can be related to many other entities.

⭐ Advantages of ER Model

  • Easy to understand.
  • Helps in database design.
  • Shows relationships clearly.
  • Reduces confusion while designing a database.
  • Helps developers understand the database structure.

📝 Simple Example

In a college database, Student and Course can be entities.

Student Name, Student ID and Course Name are attributes. The relationship can be "Student enrolls in Course".

In short: Entity → Object | Attribute → Details | Relationship → Connection
