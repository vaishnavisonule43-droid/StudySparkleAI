📊 Data Models

Learn about different types of data models in DBMS.

📖 What is a Data Model?

A data model is a way of showing how data is stored, organized and connected in a database.

Simple Meaning: A data model shows the structure of data and the relationship between different data.

🌳 1. Hierarchical Data Model

In the hierarchical model, data is arranged in the form of a tree structure.

Example:

A college can have Departments, and each Department can have Students.

Simple Meaning:

Data is arranged like a tree with parent and child.

🔗 2. Network Data Model

In the network model, data is connected like a network. One record can be connected to many other records.

Example:

A student can join many courses and one course can have many students.

Simple Meaning:

Data can have many connections with other data.

📋 3. Relational Data Model

In the relational model, data is stored in the form of tables.

Example:

A Student table can contain Student ID, Name, Class and Marks.

Simple Meaning:

Data is stored in rows and columns like a table.

🧩 4. Object-Oriented Data Model

In this model, data is stored in the form of objects. It uses concepts of object-oriented programming.

Example:

A Student object can contain name, age, course and other information.

Simple Meaning:

Data is stored as objects containing data and functions.

📊 Types of Data Models

  • Hierarchical: Data is arranged like a tree.
  • Network: Data has many connections.
  • Relational: Data is stored in tables.
  • Object-Oriented: Data is stored as objects.

⭐ Advantages of Data Models

  • They organize data properly.
  • They show relationships between data.
  • They make database design easier.
  • They help in managing data efficiently.
