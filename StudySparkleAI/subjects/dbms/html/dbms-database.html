🗃️ Database

Learn the basic concepts of database in DBMS.

📖 What is a Database?

A database is a collection of organized data that can be easily stored, accessed and managed.

Simple Meaning: A database is a place where data is stored in an organized way.

💡 Example of Database

A college database can store information about students, teachers, courses and marks.

Example:

  • Student ID
  • Student Name
  • Class
  • Marks
  • Contact Number

⭐ Characteristics of Database

  • Data is organized properly.
  • Data can be easily accessed.
  • Data can be updated when required.
  • Data can be stored safely.
  • Duplicate data can be reduced.

📊 Types of Database

1. Relational Database

Data is stored in tables with rows and columns.

2. Hierarchical Database

Data is arranged in a tree-like structure.

3. Network Database

Data is connected with multiple relationships.

4. Object-Oriented Database

Data is stored in the form of objects.

🧩 Components of Database

  • Table: Stores data in rows and columns.
  • Record: A single row in a table.
  • Field: A column that stores a specific type of data.
  • Key: Helps to identify records.

🎯 Importance of Database

  • Stores large amounts of data.
  • Makes data easy to find.
  • Helps to update data easily.
  • Provides better data security.
  • Reduces data duplication.

🔄 Database and DBMS

A database is a collection of stored data. A DBMS is software used to create, manage and access that database.

Example: Student records are the database, while MySQL can be used to manage those records.

📝 Simple Example

Suppose a college has information about 1000 students. This information can be stored in a database.

The college can use a DBMS to add new students, update student information and find student records.
