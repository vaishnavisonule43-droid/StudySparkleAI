🔄 Transaction Management

Learn how database transactions are managed safely.

📖 What is a Transaction?

A transaction is a group of operations performed on a database to complete a particular task.

Simple Meaning: A transaction is a complete database operation or task.

💡 Example of Transaction

Suppose money is transferred from Account A to Account B. The system must deduct money from A and add money to B.

Both operations should be completed successfully.

Simple Meaning: A transaction should complete the whole task correctly.

⭐ ACID Properties

ACID properties help to make database transactions reliable and safe.

1. Atomicity

A transaction is completed fully or not completed at all.

2. Consistency

A transaction keeps the database in a correct state.

3. Isolation

Multiple transactions can work without interfering with each other.

4. Durability

Once a transaction is completed, the changes are saved permanently.

🔄 Transaction States

1. Active

The transaction is currently running.

2. Partially Committed

The transaction has completed its operations but changes are not yet permanently saved.

3. Committed

The transaction is completed successfully and changes are saved.

4. Failed

The transaction cannot continue because of an error or failure.

5. Aborted

The transaction is cancelled and its changes are undone.

✅ COMMIT

COMMIT is used to permanently save the changes made by a transaction.

Simple Meaning: COMMIT means save the changes permanently.

↩️ ROLLBACK

ROLLBACK is used to cancel the changes made by a transaction and return the database to its previous state.

Simple Meaning: ROLLBACK means undo the changes.

🔐 Concurrency Control

Concurrency control manages multiple transactions running at the same time.

It helps to prevent incorrect data and maintains database consistency.

Simple Meaning: It safely manages many transactions at the same time.

⚠️ Problems in Concurrent Transactions

  • Lost Update: One update may overwrite another update.
  • Dirty Read: A transaction reads uncommitted data.
  • Incorrect Summary: A calculation may use changing data.

🎯 Importance of Transaction Management

  • Keeps database data correct.
  • Prevents data loss.
  • Maintains data consistency.
  • Handles transaction failures.
  • Allows multiple users to work safely.

📊 Summary

  • Transaction: A group of database operations.
  • ACID: Atomicity, Consistency, Isolation, Durability.
  • COMMIT: Saves changes permanently.
  • ROLLBACK: Undoes changes.
  • Concurrency Control: Manages multiple transactions safely.
