💻 SQL

Learn the basic SQL commands used in DBMS.

📖 What is SQL?

SQL stands for Structured Query Language. It is used to create, manage and retrieve data from a database.

Simple Meaning: SQL is a language used to communicate with a database.

🎯 Uses of SQL

  • Create databases and tables.
  • Insert data into tables.
  • Update existing data.
  • Delete data.
  • Retrieve required data.

🏗️ 1. DDL - Data Definition Language

DDL commands are used to create and change the structure of database objects such as tables.

Main Commands:

  • CREATE: Creates a database or table.
  • ALTER: Changes the structure of a table.
  • DROP: Deletes a table or database object.
  • TRUNCATE: Removes all records from a table.
Simple Meaning: DDL is used to create and change the structure of a database.

📝 2. DML - Data Manipulation Language

DML commands are used to add, change and delete data from a table.

Main Commands:

  • INSERT: Adds new data.
  • UPDATE: Changes existing data.
  • DELETE: Removes data.
Simple Meaning: DML is used to manage the data stored in tables.

🔍 3. DQL - Data Query Language

DQL is used to retrieve data from a database.

Main Command:

  • SELECT: Retrieves data from a table.
Simple Meaning: DQL is mainly used to get data from the database.

🔐 4. DCL - Data Control Language

DCL commands are used to control access and permissions in a database.

Main Commands:

  • GRANT: Gives permission to a user.
  • REVOKE: Removes permission from a user.
Simple Meaning: DCL controls who can access database objects.

🔄 5. TCL - Transaction Control Language

TCL commands are used to manage transactions in a database.

Main Commands:

  • COMMIT: Saves the transaction permanently.
  • ROLLBACK: Cancels changes made in a transaction.
  • SAVEPOINT: Creates a point to which we can roll back.
Simple Meaning: TCL controls database transactions.

💡 Simple SQL Example

Create Table:

CREATE TABLE Student (ID, Name, Marks);

Insert Data:

INSERT INTO Student VALUES (1, 'Rahul', 80);

View Data:

SELECT * FROM Student;

Simple Meaning: SQL commands tell the database what operation we want to perform.

📊 SQL Commands Summary

  • DDL: CREATE, ALTER, DROP, TRUNCATE
  • DML: INSERT, UPDATE, DELETE
  • DQL: SELECT
  • DCL: GRANT, REVOKE
  • TCL: COMMIT, ROLLBACK, SAVEPOINT
