📋 Normalization

Learn how data is organized properly in DBMS.

📖 What is Normalization?

Normalization is the process of organizing data in a database to reduce duplicate data and improve data consistency.

Simple Meaning: Normalization means arranging data properly and reducing unnecessary duplicate data.

🎯 Need of Normalization

Normalization is used to make the database clean, organized and easy to manage.

  • Reduces duplicate data.
  • Improves data consistency.
  • Makes database easier to manage.
  • Reduces storage space.
  • Prevents data problems during insert, update and delete.

1️⃣ First Normal Form (1NF)

A table is in 1NF when every column contains only single and atomic values.

Example:

A Student table should not store multiple phone numbers in one cell.

Simple Meaning: One cell should contain only one value.

2️⃣ Second Normal Form (2NF)

A table is in 2NF when it is already in 1NF and every non-key attribute fully depends on the Primary Key.

Simple Meaning: Every non-key column should depend on the complete Primary Key.

3️⃣ Third Normal Form (3NF)

A table is in 3NF when it is already in 2NF and non-key attributes do not depend on other non-key attributes.

Simple Meaning: Non-key data should depend only on the Primary Key.

4️⃣ Boyce-Codd Normal Form (BCNF)

BCNF is a stronger version of 3NF. A table is in BCNF when every determinant is a Candidate Key.

Simple Meaning: Every attribute that determines another attribute should be a Candidate Key.

📝 Simple Example of Normalization

Suppose a Student table contains Student ID, Student Name, Course Name and Teacher Name.

If the same course and teacher information is repeated for many students, it creates duplicate data.

Normalization separates the data into different related tables to reduce this duplication.

⭐ Advantages of Normalization

  • Reduces data duplication.
  • Improves data consistency.
  • Saves storage space.
  • Makes database structure better.
  • Makes data easier to maintain.

⚠️ Disadvantages of Normalization

  • Creates more tables.
  • Queries may become more complex.
  • More table joins may be required.
  • Database design can take more time.

📊 Normal Forms Summary

  • 1NF: One value in one cell.
  • 2NF: Full dependency on Primary Key.
  • 3NF: No dependency between non-key attributes.
  • BCNF: Every determinant is a Candidate Key.
