Java Exception Handling

Understand errors and exceptions with simple Java examples.

1. What is an Exception?

An exception is an event that interrupts the normal flow of a program while it is running.

Example: Dividing an integer by zero causes an ArithmeticException.

2. What is Exception Handling?

Exception handling is a way to handle runtime problems so that a program can respond to them appropriately.

  • It helps prevent unexpected program termination in handled cases.
  • It separates error-handling code from normal code.
  • It helps display meaningful error messages.

3. Types of Exceptions

Checked Exceptions

These are checked by the compiler. They must be caught or declared where required by Java.

Example: IOException

Unchecked Exceptions

These are exceptions that are not required to be caught or declared by the compiler.

Example: ArithmeticException, NullPointerException.

4. The try and catch Blocks

The try block contains code that may throw an exception. The catch block handles a matching exception.

class Main {
    public static void main(String[] args) {
        try {
            int result = 10 / 0;
            System.out.println(result);
        } catch (ArithmeticException e) {
            System.out.println("Cannot divide by zero");
        }

        System.out.println("Program continues");
    }
}

Output:

Cannot divide by zero
Program continues

5. The finally Block

The finally block generally executes whether an exception occurs or not. It is commonly used for cleanup work.

class Main {
    public static void main(String[] args) {
        try {
            System.out.println("Inside try block");
        } catch (Exception e) {
            System.out.println("Exception occurred");
        } finally {
            System.out.println("Finally block executed");
        }
    }
}

Output:

Inside try block
Finally block executed

6. The throw Keyword

The throw keyword is used to explicitly throw an exception from code.

class Main {
    public static void main(String[] args) {
        int age = 15;

        try {
            if (age < 18) {
                throw new IllegalArgumentException(
                    "Age must be 18 or above"
                );
            }

            System.out.println("Eligible");
        } catch (IllegalArgumentException e) {
            System.out.println(e.getMessage());
        }
    }
}

Output:

Age must be 18 or above

7. The throws Keyword

The throws keyword declares exceptions that a method may pass to its caller.

import java.io.IOException;

class Main {
    static void checkFile() throws IOException {
        throw new IOException("File error");
    }

    public static void main(String[] args) {
        try {
            checkFile();
        } catch (IOException e) {
            System.out.println(e.getMessage());
        }
    }
}

Output:

File error

8. Multiple catch Blocks

Multiple catch blocks can handle different exception types. Put more specific exception types before more general types.

class Main {
    public static void main(String[] args) {
        try {
            int[] numbers = {10, 20};
            System.out.println(numbers[5]);
        } catch (ArithmeticException e) {
            System.out.println("Arithmetic error");
        } catch (ArrayIndexOutOfBoundsException e) {
            System.out.println("Invalid array index");
        }
    }
}

Output:

Invalid array index

9. Difference Between throw and throws

  • throw: Used to explicitly throw an exception.
  • throws: Used in a method declaration to declare possible exceptions.
  • throw: Followed by an exception object.
  • throws: Followed by exception class names.

10. Advantages of Exception Handling

  • Helps manage runtime problems.
  • Prevents abrupt termination in handled cases.
  • Provides meaningful error messages.
  • Keeps normal code separate from error-handling code.
  • Makes programs easier to maintain.
