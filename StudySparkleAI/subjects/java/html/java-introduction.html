1. What is Java?

Java is a high-level, object-oriented programming language. It is used to develop desktop applications, web applications and Android applications.

2. History of Java

Java was developed by James Gosling and his team at Sun Microsystems. It was officially released in 1995. Today, Java is maintained by Oracle and other contributors.

3. Features of Java

  • Simple: Java syntax is easy to learn compared with many lower-level languages.
  • Object-Oriented: Java uses classes and objects.
  • Platform Independent: Java bytecode can run on systems with a compatible JVM.
  • Secure: Java provides security features for running programs.
  • Robust: Java supports exception handling and memory management.
  • Multithreaded: Java can perform multiple tasks concurrently.

4. Uses of Java

  • Desktop software development
  • Web application development
  • Android application development
  • Banking and business applications
  • Enterprise software systems

5. Java Program Example

This program displays Hello World on the screen.

class Main {
    public static void main(String[] args) {
        System.out.println("Hello World");
    }
}

Output

Hello World

6. Important Terms

JDK: Java Development Kit contains tools needed to develop Java programs.

JRE: Java Runtime Environment provides the components needed to run Java applications.

JVM: Java Virtual Machine executes Java bytecode.

Bytecode: Intermediate code generated when Java source code is compiled.
