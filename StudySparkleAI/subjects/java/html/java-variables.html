Java Variables and Data Types

Java Programming Notes | StudySpark AI

1. What is a Variable?

A variable is a named memory location used to store data in a program. Its value can be used and changed during program execution.

Example

int age = 18;

Here, age is a variable that stores the value 18.

2. Rules for Naming Variables

  • A variable name can contain letters, digits, underscore and dollar sign.
  • A variable name cannot start with a digit.
  • Spaces are not allowed in variable names.
  • Java keywords cannot be used as variable names.
  • Variable names are case-sensitive. For example, age and Age are different.

Examples

Valid: age, studentName, marks1, _count

Invalid: 1age, student name, class

3. Types of Variables

Local Variable

A local variable is declared inside a method or block. It must be initialized before it is used.

Instance Variable

An instance variable is declared inside a class but outside methods and constructors. Each object has its own instance variables.

Static Variable

A static variable is declared using the static keyword. It belongs to the class and is shared by its instances.

4. What is a Data Type?

A data type tells Java what kind of value a variable can store, such as an integer, decimal number, character or true/false value.

5. Primitive Data Types

Java has eight primitive data types.

  • byte: Stores small whole numbers.
  • short: Stores whole numbers in a short integer range.
  • int: Stores whole numbers.
  • long: Stores large whole numbers.
  • float: Stores decimal numbers with single precision.
  • double: Stores decimal numbers with double precision.
  • char: Stores a single UTF-16 code unit.
  • boolean: Stores true or false.

6. Non-Primitive Data Types

Non-primitive types refer to objects. Common examples include String, arrays and classes.

  • String: Stores a sequence of characters.
  • Array: Stores multiple values of the same declared element type.
  • Class: Defines the structure and behaviour of objects.

7. Java Program Example

This program demonstrates variables and data types.

class Main {
    public static void main(String[] args) {
        int age = 18;
        double percentage = 85.5;
        char grade = 'A';
        boolean passed = true;
        String name = "Student";

        System.out.println(name);
        System.out.println(age);
        System.out.println(percentage);
        System.out.println(grade);
        System.out.println(passed);
    }
}

Output

Student

85.5

A

true

8. Difference Between Variable and Data Type

Variable: A named storage location used to hold a value.

Data Type: Specifies the kind of value that can be stored in a variable.

Example: int marks = 90;

int is the data type, marks is the variable name, and 90 is the value.
