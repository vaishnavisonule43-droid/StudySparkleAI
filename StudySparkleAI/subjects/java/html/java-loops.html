1. What Is a Loop?

A loop is used to execute a block of code repeatedly while a condition is satisfied or for a specified number of iterations.

Types of Loops in Java

  • for loop
  • while loop
  • do-while loop
  • Enhanced for loop (for-each)

2. for Loop

A for loop is useful when we know how many times we want to repeat a block of code.

Syntax

for (initialization; condition; update) { }

class Main {
    public static void main(String[] args) {
        for (int i = 1; i <= 5; i++) {
            System.out.println(i);
        }
    }
}

3. while Loop

A while loop checks the condition before executing the loop body. If the condition is false initially, the body will not execute.

Syntax

while (condition) { }

class Main {
    public static void main(String[] args) {
        int i = 1;

        while (i <= 5) {
            System.out.println(i);
            i++;
        }
    }
}

4. do-while Loop

A do-while loop executes the loop body at least once because the condition is checked after the body.

Syntax

do { } while (condition);

class Main {
    public static void main(String[] args) {
        int i = 1;

        do {
            System.out.println(i);
            i++;
        } while (i <= 5);
    }
}

5. Enhanced for Loop

The enhanced for loop, also called the for-each loop, is used to access elements of an array or collection one by one. 

class Main {
    public static void main(String[] args) {
        int[] numbers = {10, 20, 30};

        for (int number : numbers) {
            System.out.println(number);
        }
    }
}

Output

10

20

30

6. break Statement

The break statement immediately terminates the nearest enclosing loop. 

class Main {
    public static void main(String[] args) {
        for (int i = 1; i <= 5; i++) {
            if (i == 3) {
                break;
            }

            System.out.println(i);
        }
    }
}

Output

1

2

7. continue Statement

The continue statement skips the remaining statements in the current iteration and moves to the next iteration. 

class Main {
    public static void main(String[] args) {
        for (int i = 1; i <= 5; i++) {
            if (i == 3) {
                continue;
            }

            System.out.println(i);
        }
    }
}

8. Difference Between while and do-while

while loop: Checks the condition before executing the loop body. It may execute zero times.

do-while loop: Checks the condition after executing the body. It executes at least once.

9. Infinite Loop

An infinite loop continues forever when its stopping condition never becomes false, unless the program is interrupted or exits another way. 

while (true) {
    System.out.println("Running");
}

Note: This example keeps printing until the program is stopped.

10. Importance of Loops

  • They reduce repeated code.
  • They help process arrays and collections.
  • They perform repetitive calculations.
  • They make programs easier to manage.
