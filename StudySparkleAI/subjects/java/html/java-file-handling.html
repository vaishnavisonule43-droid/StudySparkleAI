Java File Handling

Learn how to create, write, read and delete files in Java.

1. What is File Handling?

File handling means creating, reading, writing and managing files using a program.

Example: A program can save student details in a text file and read them later.

2. Important Classes

  • File – represents a file or directory path.
  • FileWriter – writes characters to a file.
  • FileReader – reads characters from a file.
  • BufferedReader – reads text efficiently using a buffer.
  • Scanner – can read text from a file.

3. Creating a File

The File class and its createNewFile() method can be used to create a new file.

import java.io.File;
import java.io.IOException;

class Main {
    public static void main(String[] args) {
        try {
            File file = new File("student.txt");

            if (file.createNewFile()) {
                System.out.println("File created");
            } else {
                System.out.println("File already exists");
            }
        } catch (IOException e) {
            System.out.println("An error occurred");
        }
    }
}

Possible output when the file is new:

File created
The output depends on whether the file already exists. The file is created in the program's working directory.

4. Writing to a File

FileWriter can write text into a file. The try-with-resources statement closes the writer automatically.

import java.io.FileWriter;
import java.io.IOException;

class Main {
    public static void main(String[] args) {
        try (FileWriter writer = new FileWriter("student.txt")) {
            writer.write("Welcome to Java");
            System.out.println("Data written successfully");
        } catch (IOException e) {
            System.out.println("An error occurred");
        }
    }
}

Output:

Data written successfully
By default, this FileWriter constructor overwrites the existing file contents. To append instead, use new FileWriter("student.txt", true).

5. Reading from a File

FileReader and BufferedReader can read text from a file line by line.

import java.io.BufferedReader;
import java.io.FileReader;
import java.io.IOException;

class Main {
    public static void main(String[] args) {
        try (BufferedReader reader =
                 new BufferedReader(new FileReader("student.txt"))) {

            String line;

            while ((line = reader.readLine()) != null) {
                System.out.println(line);
            }

        } catch (IOException e) {
            System.out.println("Unable to read file");
        }
    }
}

If the file contains:

Welcome to Java

Output:

Welcome to Java

6. Appending Data to a File

Appending means adding new content at the end of an existing file without removing its previous contents.

import java.io.FileWriter;
import java.io.IOException;

class Main {
    public static void main(String[] args) {
        try (FileWriter writer =
                 new FileWriter("student.txt", true)) {

            writer.write("\nJava is easy");
            System.out.println("Data appended successfully");

        } catch (IOException e) {
            System.out.println("An error occurred");
        }
    }
}

Output:

Data appended successfully

7. Checking File Information

The File class provides methods to check file properties such as existence, name and size.

import java.io.File;

class Main {
    public static void main(String[] args) {
        File file = new File("student.txt");

        System.out.println(file.exists());
        System.out.println(file.getName());
        System.out.println(file.length());
    }
}

Example output if the file exists and contains 15 bytes:

true
student.txt
15
The file size depends on its actual contents and character encoding. The output above is only an example.

8. Deleting a File

The delete() method attempts to delete the file. It returns true if the deletion succeeds.

import java.io.File;

class Main {
    public static void main(String[] args) {
        File file = new File("student.txt");

        if (file.delete()) {
            System.out.println("File deleted");
        } else {
            System.out.println("File could not be deleted");
        }
    }
}

Possible output when deletion succeeds:

File deleted
Run this example only when you intend to delete the specified file. Check the path carefully before deleting.

9. Advantages of File Handling

  • Stores data permanently for later use.
  • Allows programs to read saved information.
  • Makes it possible to update stored data.
  • Helps manage text and other file-based information.
  • Supports data exchange between program runs.

10. Important Points to Remember

  • File represents a file or directory path.
  • FileWriter writes text.
  • FileReader reads characters.
  • BufferedReader can read text line by line.
  • File operations may throw an IOException.
  • Try-with-resources closes supported resources automatically.
