1. What Are Conditional Statements?

Conditional statements are used to make decisions in a program. They execute different blocks of code depending on whether a condition is true or false.

Types of Conditional Statements

  • if statement
  • if-else statement
  • if-else-if ladder
  • Nested if statement
  • switch statement
  • Conditional (ternary) operator

2. if Statement

The if statement executes a block of code only when the given condition is true.

Syntax

if (condition) { /* code */ }

class Main {
    public static void main(String[] args) {
        int age = 20;

        if (age >= 18) {
            System.out.println("Eligible to vote");
        }
    }
}

Output

Eligible to vote

3. if-else Statement

The if-else statement executes one block if the condition is true and another block if it is false. 

class Main {
    public static void main(String[] args) {
        int marks = 35;

        if (marks >= 40) {
            System.out.println("Pass");
        } else {
            System.out.println("Fail");
        }
    }
}

Output

Fail

4. if-else-if Ladder

An if-else-if ladder checks multiple conditions in order. The first true condition's block is executed. 

class Main {
    public static void main(String[] args) {
        int marks = 75;

        if (marks >= 90) {
            System.out.println("Grade A");
        } else if (marks >= 70) {
            System.out.println("Grade B");
        } else if (marks >= 40) {
            System.out.println("Grade C");
        } else {
            System.out.println("Fail");
        }
    }
}

Output

Grade B

5. Nested if Statement

A nested if statement is an if statement written inside another if statement. 

class Main {
    public static void main(String[] args) {
        int age = 20;
        boolean hasId = true;

        if (age >= 18) {
            if (hasId) {
                System.out.println("Entry allowed");
            }
        }
    }
}

Output

Entry allowed

6. switch Statement

The switch statement selects a block of code based on the value of an expression. 

class Main {
    public static void main(String[] args) {
        int day = 2;

        switch (day) {
            case 1:
                System.out.println("Monday");
                break;

            case 2:
                System.out.println("Tuesday");
                break;

            case 3:
                System.out.println("Wednesday");
                break;

            default:
                System.out.println("Invalid day");
        }
    }
}

Output

Tuesday

break: Ends the current switch case.

default: Executes when no case matches.

7. Conditional (Ternary) Operator

The ternary operator is a short way to choose between two values based on a condition.

Syntax

condition ? value1 : value2

class Main {
    public static void main(String[] args) {
        int number = 8;

        String result =
            number % 2 == 0 ? "Even" : "Odd";

        System.out.println(result);
    }
}

Output

Even

8. Difference Between if-else and switch

if-else: Useful for checking ranges, multiple conditions and complex logical expressions.

switch: Useful when selecting between different cases based on one expression's value.

9. Importance of Conditional Statements

  • They help a program make decisions.
  • They execute code based on conditions.
  • They help validate user input.
  • They are useful for grading and eligibility checks.
  • They control the flow of a program.
