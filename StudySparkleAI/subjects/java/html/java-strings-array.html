Java Strings and Arrays

Learn Strings and Arrays in Java with simple examples.

1. What is a String?

A String is a sequence of characters. It is used to store text such as names, addresses and messages.

class Main {
    public static void main(String[] args) {
        String name = "Rahul";
        System.out.println(name);
    }
}

Output:

Rahul

2. Common String Methods

Java provides built-in methods to work with strings.

  • length() – returns the number of characters.
  • toUpperCase() – converts text to uppercase.
  • toLowerCase() – converts text to lowercase.
  • charAt(index) – returns a character at an index.
  • equals() – compares the contents of strings.
  • contains() – checks whether text contains a sequence.
class Main {
    public static void main(String[] args) {
        String text = "Java Programming";

        System.out.println(text.length());
        System.out.println(text.toUpperCase());
        System.out.println(text.toLowerCase());
        System.out.println(text.charAt(0));
        System.out.println(text.contains("Java"));
    }
}

Output:

16
JAVA PROGRAMMING
java programming
J
true
Remember: String indexing starts at 0. Java Strings are immutable, which means their contents cannot be changed directly after creation.

3. Comparing Strings

Use equals() to compare string contents. The == operator checks whether two references point to the same object.

class Main {
    public static void main(String[] args) {
        String a = new String("Java");
        String b = new String("Java");

        System.out.println(a.equals(b));
        System.out.println(a == b);
    }
}

Output:

true
false

4. What is an Array?

An array stores multiple values of the same data type in a single variable. Its size is fixed after creation.

class Main {
    public static void main(String[] args) {
        int[] marks = {70, 80, 90};

        System.out.println(marks[0]);
        System.out.println(marks[1]);
        System.out.println(marks[2]);
    }
}

Output:

70
80
90
Array indexing starts at 0. Therefore, the first element is at index 0, and the last element is at index length - 1.

5. Types of Arrays

One-Dimensional Array

A one-dimensional array stores elements in a single sequence.

int[] numbers = {10, 20, 30};

Two-Dimensional Array

A two-dimensional array stores data in rows and columns.

class Main {
    public static void main(String[] args) {
        int[][] matrix = {
            {1, 2},
            {3, 4}
        };

        System.out.println(matrix[0][1]);
        System.out.println(matrix[1][0]);
    }
}

Output:

2
3

6. Traversing an Array Using a for Loop

Traversing means accessing each element of an array one by one.

class Main {
    public static void main(String[] args) {
        int[] numbers = {10, 20, 30, 40};

        for (int i = 0; i < numbers.length; i++) {
            System.out.println(numbers[i]);
        }
    }
}

Output:

10
20
30
40

7. Enhanced for Loop

The enhanced for loop makes it easy to access each element without manually managing an index.

class Main {
    public static void main(String[] args) {
        int[] numbers = {5, 10, 15};

        for (int number : numbers) {
            System.out.println(number);
        }
    }
}

Output:

5
10
15

8. Advantages of Strings and Arrays

  • Strings make text storage and processing easier.
  • String methods simplify common text operations.
  • Arrays store multiple values under one variable name.
  • Array elements can be accessed using indexes.
  • Loops help process array elements efficiently.
