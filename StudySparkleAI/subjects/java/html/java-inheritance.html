Java Inheritance

Learn inheritance in Java with easy explanations and examples.

1. What is Inheritance?

Inheritance is an object-oriented programming feature in which one class acquires accessible fields and methods from another class.

Example: A Dog class can inherit common properties and methods from an Animal class.

2. Important Keywords

  • extends – used when a class inherits from another class.
  • super – refers to the parent-class part of an object.
  • implements – used when a class implements an interface.

3. Single Inheritance

In single inheritance, one child class inherits from one parent class.

class Animal {
    void eat() {
        System.out.println("Animal eats food");
    }
}

class Dog extends Animal {
    void bark() {
        System.out.println("Dog barks");
    }
}

class Main {
    public static void main(String[] args) {
        Dog d = new Dog();
        d.eat();
        d.bark();
    }
}

Output:

Animal eats food
Dog barks

4. Multilevel Inheritance

In multilevel inheritance, a class inherits from a child class, forming a chain of inheritance.

class Animal {
    void eat() {
        System.out.println("Eating");
    }
}

class Dog extends Animal {
    void bark() {
        System.out.println("Barking");
    }
}

class Puppy extends Dog {
    void play() {
        System.out.println("Playing");
    }
}

class Main {
    public static void main(String[] args) {
        Puppy p = new Puppy();
        p.eat();
        p.bark();
        p.play();
    }
}

Output:

Eating
Barking
Playing

5. Hierarchical Inheritance

In hierarchical inheritance, multiple child classes inherit from the same parent class.

class Animal {
    void eat() {
        System.out.println("Eating");
    }
}

class Dog extends Animal {
    void bark() {
        System.out.println("Barking");
    }
}

class Cat extends Animal {
    void meow() {
        System.out.println("Meowing");
    }
}

class Main {
    public static void main(String[] args) {
        Dog d = new Dog();
        Cat c = new Cat();

        d.eat();
        d.bark();

        c.eat();
        c.meow();
    }
}

Output:

Eating
Barking
Eating
Meowing

6. Multiple Inheritance in Java

Java does not support multiple inheritance through classes. A class cannot extend two classes at the same time. However, Java supports multiple inheritance of type through interfaces.

interface A {
    void showA();
}

interface B {
    void showB();
}

class Demo implements A, B {
    public void showA() {
        System.out.println("Interface A");
    }

    public void showB() {
        System.out.println("Interface B");
    }

    public static void main(String[] args) {
        Demo d = new Demo();
        d.showA();
        d.showB();
    }
}

Output:

Interface A
Interface B

7. The super Keyword

The super keyword can be used to access accessible parent-class members and to call a parent-class constructor.

class Parent {
    void display() {
        System.out.println("Parent class");
    }
}

class Child extends Parent {
    void display() {
        super.display();
        System.out.println("Child class");
    }
}

class Main {
    public static void main(String[] args) {
        Child c = new Child();
        c.display();
    }
}

Output:

Parent class
Child class

8. Method Overriding

Method overriding occurs when a child class provides its own implementation of an inherited instance method with a compatible method signature.

class Animal {
    void sound() {
        System.out.println("Animal makes a sound");
    }
}

class Dog extends Animal {
    @Override
    void sound() {
        System.out.println("Dog barks");
    }
}

class Main {
    public static void main(String[] args) {
        Dog d = new Dog();
        d.sound();
    }
}

Output:

Dog barks

9. Advantages of Inheritance

  • It supports code reuse.
  • It reduces repeated code.
  • It makes programs easier to organize.
  • It supports method overriding and runtime polymorphism.
  • It helps represent parent-child relationships.

10. Important Points to Remember

  • extends is used for class inheritance.
  • Java classes support single, multilevel and hierarchical inheritance.
  • Multiple inheritance through classes is not supported.
  • Interfaces can be used to implement multiple inheritance of type.
  • super can access accessible parent members.
  • Method overriding allows a child class to redefine an inherited method.
