Java Methods

Learn methods in Java with simple explanations and examples.

1. What is a Method?

A method is a block of code that performs a specific task. We can call a method whenever we need to perform that task.

Example: A method can calculate the sum of two numbers.

2. Method Syntax

A method generally contains a return type, method name, parameters and a body.

returnType methodName(parameters) {
    // code to execute
}

3. Types of Methods

Predefined Methods

These methods are already provided by Java libraries.

Example: System.out.println() and Math.sqrt().

User-Defined Methods

These methods are created by the programmer according to the program's requirements.

4. Method Without Parameters and Return Value

This method does not accept any values and does not return a result.

class Main {
    static void greet() {
        System.out.println("Hello Student!");
    }

    public static void main(String[] args) {
        greet();
    }
}

Output:

Hello Student!

5. Method With Parameters

Parameters allow us to pass values to a method.

class Main {
    static void add(int a, int b) {
        System.out.println(a + b);
    }

    public static void main(String[] args) {
        add(10, 20);
    }
}

Output:

30
Here, a and b are parameters. The values 10 and 20 are arguments.

6. Method With a Return Value

A method with a return type sends a result back to the calling code using the return statement.

class Main {
    static int square(int n) {
        return n * n;
    }

    public static void main(String[] args) {
        int result = square(5);
        System.out.println(result);
    }
}

Output:

25

7. Static and Instance Methods

Static Method

A static method belongs to the class. We can call it using the class name without creating an object.

Instance Method

An instance method belongs to an object. We normally create an object to call it.

class Student {
    static void showCollege() {
        System.out.println("ABC College");
    }

    void showName() {
        System.out.println("Rahul");
    }

    public static void main(String[] args) {
        Student.showCollege();

        Student s = new Student();
        s.showName();
    }
}

Output:

ABC College
Rahul

8. Method Overloading

Method overloading means creating multiple methods with the same name but different parameter lists.

class Main {
    static int add(int a, int b) {
        return a + b;
    }

    static int add(int a, int b, int c) {
        return a + b + c;
    }

    public static void main(String[] args) {
        System.out.println(add(2, 3));
        System.out.println(add(2, 3, 4));
    }
}

Output:

5
9
Method overloading can use different numbers or types of parameters. Changing only the return type is not enough.

9. Advantages of Methods

  • Methods reduce repeated code.
  • They make programs easier to understand.
  • They make code easier to test and maintain.
  • They divide a large program into smaller tasks.
  • Methods can be called whenever required.

10. Important Points to Remember

  • void means the method does not return a value.
  • return sends a result back to the caller.
  • Parameters receive values passed to a method.
  • Static methods can be called using the class name.
  • Method overloading uses different parameter lists.
