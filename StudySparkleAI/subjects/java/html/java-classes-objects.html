Java Classes and Objects

Understand classes, objects and constructors with easy examples.

1. What is a Class?

A class is a blueprint or template used to create objects. It defines the data and methods that its objects can have.

Example: A Student class can contain student name, roll number and a method to display student details. 
class Student {
    String name;
    int rollNo;

    void display() {
        System.out.println(name);
        System.out.println(rollNo);
    }
}

2. What is an Object?

An object is an instance of a class. It can store data and use the methods defined in its class.

Example: If Student is a class, Rahul and Priya can be objects of that class. 
class Student {
    String name;

    public static void main(String[] args) {
        Student s1 = new Student();

        s1.name = "Rahul";

        System.out.println(s1.name);
    }
}

Output:

Rahul

3. Creating Multiple Objects

We can create multiple objects from the same class. Each object can store its own instance data.

class Student {
    String name;

    public static void main(String[] args) {
        Student s1 = new Student();
        Student s2 = new Student();

        s1.name = "Rahul";
        s2.name = "Priya";

        System.out.println(s1.name);
        System.out.println(s2.name);
    }
}

Output:

Rahul
Priya

4. What is a Constructor?

A constructor is a special member used to initialize an object. It has the same name as the class and does not have a return type.

Default Constructor

If no constructor is written in a class, Java provides a default constructor. It initializes fields to their default values.

Parameterized Constructor

A parameterized constructor accepts values when an object is created.

class Student {
    String name;
    int age;

    Student(String n, int a) {
        name = n;
        age = a;
    }

    void display() {
        System.out.println(name);
        System.out.println(age);
    }

    public static void main(String[] args) {
        Student s1 = new Student("Rahul", 19);
        s1.display();
    }
}

Output:

Rahul
19

5. What is the this Keyword?

The this keyword refers to the current object. It is often used to distinguish instance variables from parameters having the same names.

class Student {
    String name;

    Student(String name) {
        this.name = name;
    }

    void display() {
        System.out.println(name);
    }

    public static void main(String[] args) {
        Student s1 = new Student("Priya");
        s1.display();
    }
}

Output:

Priya
Here, this.name refers to the object's instance variable, while name refers to the constructor parameter.

6. Instance Variables and Methods

An instance variable stores data for each object. An instance method performs an operation using the object's data.

class Rectangle {
    int length = 10;
    int breadth = 5;

    void area() {
        System.out.println(length * breadth);
    }

    public static void main(String[] args) {
        Rectangle r = new Rectangle();
        r.area();
    }
}

Output:

50

7. Class vs Object

  • Class: A blueprint used to create objects.
  • Object: An instance created from a class.
  • Class: Defines variables and methods.
  • Object: Uses those variables and methods.

8. Advantages of Classes and Objects

  • They organize code into logical units.
  • They help represent real-world entities.
  • They support code reuse.
  • They make large programs easier to maintain.
  • They are important building blocks of object-oriented programming.
