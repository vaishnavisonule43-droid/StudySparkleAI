📚 C Tokens

1. What are C Tokens?

Tokens are the smallest individual units of a C program. A C program is made up of different types of tokens.

2. Definition

C Token: A token is the smallest meaningful element of a C program.

3. Types of C Tokens

There are six main types of tokens in C:

  • Keywords
  • Identifiers
  • Constants
  • String Literals
  • Operators
  • Special Symbols

4. Keywords

Keywords are reserved words in C. They have a special meaning and cannot be used as variable names.

Examples:

int, float, char, if, else, for, while, return

5. Identifiers

Identifiers are names given to variables, functions, arrays and other elements of a program.

Examples:

studentName
totalMarks
age

6. Constants

Constants are fixed values that do not change during program execution.

Examples:

10
25.5
'A'

7. String Literals

A string literal is a group of characters written inside double quotation marks.

Example:

"Hello World"
"C Programming"

8. Operators

Operators are symbols used to perform operations on data and variables.

Examples:

+    -    *    /    =    ==

9. Special Symbols

Special symbols are characters used for different purposes in a C program.

Examples:

( )    { }    [ ]    ;    ,    #

10. Example of C Tokens

C Program:

int age = 20;

Tokens:
int → Keyword
age → Identifier
= → Operator
20 → Constant
; → Special Symbol

11. Rules for Identifiers

  • Identifier can contain letters, digits and underscore.
  • It cannot start with a digit.
  • Spaces are not allowed.
  • Keywords cannot be used as identifiers.
  • C is case-sensitive.

12. Example of Valid Identifiers

  • studentName
  • total_marks
  • age
  • number1

13. Example of Invalid Identifiers

  • 1student
  • student name
  • float
  • total-marks

14. Summary

C tokens are the smallest meaningful elements of a C program. The main types are keywords, identifiers, constants, string literals, operators and special symbols.
