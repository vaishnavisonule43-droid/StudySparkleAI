📚 Introduction to C Programming

1. What is C Programming?

C is a general-purpose programming language used to create different types of software and applications.

It is a simple, fast and powerful programming language.

2. Definition of C

C Programming: C is a general-purpose, structured programming language used to develop software, applications and system programs.

3. History of C

C language was developed by Dennis Ritchie at Bell Laboratories.

It was developed in the early 1970s.

4. Features of C

  • Simple and easy to learn.
  • Fast and efficient.
  • Structured programming language.
  • Portable language.
  • Supports functions.
  • Supports pointers.
  • Supports dynamic memory allocation.
  • Used for system programming.

5. Applications of C

  • Operating systems.
  • Embedded systems.
  • System software.
  • Compilers.
  • Games.
  • Database systems.
  • Application software.

6. Basic Structure of C Program

A C program contains different parts such as header files, main function and statements.

Example:

#include <stdio.h>

int main() {
    printf("Hello World");
    return 0;
}

7. Header File

A header file contains predefined functions and information used in a C program.

Example: stdio.h is used for input and output functions like printf() and scanf().

8. main() Function

The main() function is the starting point of a C program. Program execution starts from the main() function.

9. printf() Function

printf() is used to display output on the screen.

Example:

printf("Hello World");

10. scanf() Function

scanf() is used to take input from the user.

Example:

int age;
scanf("%d", &age);

11. C Program Example

#include <stdio.h>

int main() {
    printf("Welcome to C Programming");
    return 0;
}

12. Advantages of C

  • Easy to learn.
  • Fast execution.
  • Portable.
  • Easy to write programs.
  • Supports functions and pointers.
  • Useful for system programming.

13. Disadvantages of C

  • Does not support classes and objects.
  • No automatic garbage collection.
  • Pointers can make programs difficult.
  • Less secure than some modern languages.

14. Summary

C is a simple, fast and powerful programming language. It is widely used for system software, operating systems, embedded systems and many other applications.
