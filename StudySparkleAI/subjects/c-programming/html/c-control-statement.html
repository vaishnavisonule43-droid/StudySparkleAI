📚 Control Statements in C

1. What are Control Statements?

Control statements are used to control the flow and execution of a C program.

They decide which statement should execute, how many times it should execute and when it should stop.

2. Definition

Control Statement: A control statement is a statement used to control the order of execution of statements in a program.

3. Types of Control Statements

Control statements in C are mainly divided into three types:

  • Sequential Control Statement
  • Decision or Selection Control Statement
  • Looping or Iteration Control Statement
  • Jump Control Statement

4. Sequential Control Statement

In sequential control, statements are executed one after another in the same order in which they are written.

Example:

int a = 10;
int b = 20;
int sum = a + b;
printf("%d", sum);

5. Decision / Selection Control Statement

Decision statements are used to make a choice based on a condition.

  • if statement
  • if-else statement
  • else-if ladder
  • nested if
  • switch statement

6. if Statement

The if statement executes a block of code when the given condition is true.

if (age >= 18) {
    printf("Eligible to vote");
}

7. if-else Statement

The if-else statement executes one block when the condition is true and another block when the condition is false.

if (marks >= 40) {
    printf("Pass");
}
else {
    printf("Fail");
}

8. else-if Ladder

The else-if ladder is used to check multiple conditions one by one.

if (marks >= 75)
    printf("Distinction");
else if (marks >= 60)
    printf("First Class");
else if (marks >= 40)
    printf("Pass");
else
    printf("Fail");

9. Nested if

A nested if means using one if statement inside another if statement.

if (age >= 18) {
    if (hasID == 1) {
         printf("Allowed");
    }
}

10. switch Statement

The switch statement is used to select one option from many choices.

switch (choice) {
    case 1:
         printf("Monday");
         break;

    case 2:
         printf("Tuesday");
         break;

    default:
         printf("Invalid");
}

11. Looping / Iteration Control Statement

Looping statements are used to execute the same block of code repeatedly.

  • for loop
  • while loop
  • do-while loop

12. for Loop

The for loop is used when we know how many times the statements need to be repeated.

for (i = 1; i <= 5; i++) {
    printf("%d", i);
}

13. while Loop

The while loop repeats statements as long as the condition is true.

while (i <= 5) {
    printf("%d", i);
    i++;
}

14. do-while Loop

The do-while loop executes the statements at least once and then checks the condition.

do {
    printf("%d", i);
    i++;
} while (i <= 5);

15. Jump Control Statements

Jump statements are used to change the normal flow of program execution.

  • break
  • continue
  • goto
  • return

16. break Statement

The break statement is used to stop a loop or switch statement immediately.

for (i = 1; i <= 5; i++) {
    if (i == 3)
         break;
}

17. continue Statement

The continue statement skips the current iteration and moves to the next iteration of the loop.

for (i = 1; i <= 5; i++) {
    if (i == 3)
         continue;
    printf("%d", i);
}

18. goto Statement

The goto statement transfers program control to a labelled statement.

goto end;

end:
printf("End of program");

19. return Statement

The return statement is used to return a value from a function and end its execution.

return 0;

20. Summary

Control statements control the flow of a C program. They include sequential statements, decision statements, loops and jump statements.
