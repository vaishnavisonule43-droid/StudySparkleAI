📚 Variables & Constants in C

1. What is a Variable?

A variable is a named memory location used to store a value in a C program.

The value of a variable can be changed during program execution.

2. Definition of Variable

Variable: A variable is a name given to a memory location that stores a value which can change.

3. Syntax of Variable

Syntax:

data_type variable_name;

Example:

int age;
float marks;
char grade;

4. Assigning Value to a Variable

We can assign a value to a variable using the assignment operator (=).

Example:

int age = 20;
float marks = 85.5;

5. Rules for Naming Variables

  • Variable name can contain letters, digits and underscore.
  • Variable name cannot start with a digit.
  • Spaces are not allowed in variable names.
  • Keywords cannot be used as variable names.
  • C language is case-sensitive.

6. Examples of Valid Variables

  • age
  • studentName
  • total_marks
  • number1

7. Examples of Invalid Variables

  • 1age
  • student name
  • float
  • total-marks

8. What is a Constant?

A constant is a fixed value that cannot be changed during program execution.

9. Definition of Constant

Constant: A constant is a value that remains the same throughout the execution of a program.

10. Types of Constants

  • Integer Constants
  • Floating-point Constants
  • Character Constants
  • String Constants

11. Examples of Constants

Integer: 10

Float: 25.5

Character: 'A'

String: "Hello"

12. Constant using #define

The #define preprocessor directive can be used to create a constant value.

Example:

#define PI 3.14

Here, PI is a constant value.

13. Variable vs Constant

Variable Constant
Value can be changed. Value cannot be changed.
Used for changing data. Used for fixed data.
Example: int age = 20; Example: #define PI 3.14

14. Example Program

#include <stdio.h>

#define PI 3.14

int main() {
    int age = 20;
    printf("Age = %d", age);
    printf("PI = %f", PI);

    return 0;
}

15. Summary

A variable stores a value that can be changed during program execution. A constant stores a fixed value that cannot be changed.
