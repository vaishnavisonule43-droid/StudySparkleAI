📚 Input & Output in C

1. What is Input?

Input means giving data to the computer. In C, input is usually taken from the user using the scanf() function.

2. What is Output?

Output means displaying the result on the screen. In C, output is usually displayed using the printf() function.

3. Definition

Input: Input is the data given by the user to the program.

Output: Output is the result displayed by the program.

4. printf() Function

The printf() function is used to display text, values and results on the screen.

Example:

printf("Hello World");

Output:
Hello World

5. scanf() Function

The scanf() function is used to take input from the user through the keyboard.

Example:

int age;
scanf("%d", &age);

6. Format Specifiers

Format specifiers tell C what type of data is being read or displayed.

Format Specifier Data Type Example
%d int 10
%f float 10.5
%lf double 25.55
%c char 'A'
%s string "Hello"

7. Integer Input

%d is used to take an integer value from the user.

int age;
scanf("%d", &age);

8. Float Input

%f is used to take a floating-point value.

float marks;
scanf("%f", &marks);

9. Character Input

%c is used to take a single character as input.

char grade;
scanf(" %c", &grade);

10. String Input

%s can be used to read a word or string.

char name[20];
scanf("%s", name);

11. Escape Sequences

Escape sequences are special characters used inside strings.

Escape Sequence Meaning
\n New line
\t Tab space
\\ Backslash
\" Double quote

12. Example Program

#include <stdio.h>

int main() {
    int age;

    printf("Enter your age: ");
    scanf("%d", &age);

    printf("Your age is %d", age);

    return 0;
}

13. Difference Between Input and Output

Input Output
Data is given to the program. Result is received from the program.
Usually uses scanf(). Usually uses printf().
Example: Enter age. Example: Display age.

14. Summary

Input is the data given by the user to the program, while output is the result displayed by the program. The main functions used for input and output in C are scanf() and printf().
