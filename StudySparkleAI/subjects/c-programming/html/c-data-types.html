📚 Data Types in C

1. What is a Data Type?

A data type tells the compiler what type of data a variable can store.

For example, a variable can store an integer, decimal number or character.

2. Definition

Data Type: A data type specifies the type of data that a variable can store in a C program.

3. Types of Data Types in C

C data types are mainly divided into four types:

  • Basic Data Types
  • Derived Data Types
  • User-defined Data Types
  • Void Data Type

4. Basic Data Types

Basic data types are used to store simple values.

Data Type Used For Example
int Whole numbers 10
float Decimal numbers 10.5
double Large decimal values 25.6789
char Single character 'A'

5. int Data Type

int is used to store whole numbers without decimal points.

Example:

int age = 20;

6. float Data Type

float is used to store decimal numbers.

Example:

float marks = 85.5;

7. double Data Type

double is used to store decimal numbers with more precision than float.

Example:

double price = 1250.75;

8. char Data Type

char is used to store a single character.

Example:

char grade = 'A';

9. Derived Data Types

Derived data types are created from basic data types.

  • Array
  • Pointer
  • Function

10. User-defined Data Types

User-defined data types are created by the programmer according to the requirements of the program.

  • Structure
  • Union
  • Enumeration (enum)
  • typedef

11. Void Data Type

void means that there is no value or no data type. It is commonly used with functions that do not return any value.

Example:

void display() {
    printf("Hello");
}

12. Example Program

#include <stdio.h>

int main() {
    int age = 20;
    float marks = 85.5;
    char grade = 'A';

    printf("%d", age);
    printf("%f", marks);
    printf("%c", grade);

    return 0;
}

13. Advantages of Data Types

  • Tell the compiler what type of data is stored.
  • Help to allocate memory properly.
  • Improve program efficiency.
  • Help to perform correct operations on data.

14. Summary

Data types specify what kind of data a variable can store. The main types of C data types are basicm derived, user-defined and void data types.
